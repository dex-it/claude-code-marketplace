# Архив: дизайны и планы прошлых работ

Каталог замороженный. Здесь лежат датированные дизайн-документы (`specs/`) и планы реализации (`plans/`) уже выполненных работ - запись о том, что решили и на каком основании, в момент решения. **Нормой репозитория эти файлы не являются и источником истины ни по одному правилу не выступают.**

Действующая норма живёт в других местах:

| Что нужно | Куда идти |
|---|---|
| Правила разработки, конвенции, чек-лист перед коммитом | [CLAUDE.md](../../CLAUDE.md) |
| Устройство skill, пороги размера и `description` | [SKILL_FRAMEWORK.md](../SKILL_FRAMEWORK.md) |
| Устройство агента, фазы, `model` / `effort`, handoff | [AGENT_FRAMEWORK.md](../AGENT_FRAMEWORK.md) |
| Устройство команды | [COMMAND_FRAMEWORK.md](../COMMAND_FRAMEWORK.md) |
| Что реально гейтит проверка | `tools/validate-*.js` |

## Как читать файлы отсюда

Каждый файл верен на свою дату в имени, и с тех пор норма могла уйти вперёд. Известные расхождения на 27.07.2026, приведены как образцы класса, а не как полный список:

- `plans/2026-07-15-oracle-closure.md`: «до 500 строк допустимо» для process-skill. Действующий порог и его дом - `SKILL_FRAMEWORK.md` «Размер skill» плюс парная константа валидатора.
- `specs/2026-07-27-artifact-review-skill-design.md` и `plans/2026-07-27-artifact-review-skill.md`: «`CLAUDE.md` до субагентов не доезжает». По живой документации ([sub-agents](https://code.claude.com/docs/en/sub-agents), «What loads at startup», сверено 27.07.2026) иерархия `CLAUDE.md` входит в стартовый контекст субагента; не получают её только встроенные `Explore` и `Plan`. Решение вынести правило ревью в skill от этого в силе - у него есть другие основания, - но приведённая там причина неверна.

## Почему файлы не правятся

Правка датированного плана переписывает историю: пропадает след того, из какого понимания выросло решение, и разбор прошлого PR перестаёт сходиться с его же артефактами. Расхождение чинится **в нормативном доме**, а сюда, при необходимости, добавляется строка в список выше.

Из этого правила следует и второе: на файл отсюда нельзя ссылаться как на основание. Ссылка на архив уместна только как на историю решения («так решили тогда, потому что ...»).

## Объём и контекст

В контекст сессии каталог не попадает - ни постоянно, ни по срабатыванию. Это зафиксировано отдельно в инвентаризации миграции ([claude5-context-inventory.md](../migration/claude5-context-inventory.md), категория 1), поэтому его размер не входит в метрику миграции и сокращать его «ради процента» смысла нет.
