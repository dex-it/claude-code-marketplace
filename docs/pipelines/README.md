# Конвейеры

Дом описаний конвейеров: как каждый устроен изнутри - узлы, служебные скиллы, данные на рёбрах,
следы на диске. Один конвейер - одна папка.

| Конвейер | Папка | Состояние |
|---|---|---|
| аналитика (требования зоны 1) | [analytics/](analytics/) | схема принята, реализация идёт |
| архитектура | - | отдельный конвейер, вход - готовый набор требований; не начат |

**Что здесь лежит и чего не лежит.** Здесь - **архитектура исполнения**: кто что вызывает, что кому
передаёт, что остаётся на диске. Нормативная схема аналитики - что за единицы, в каком порядке и по
каким проверкам - живёт отдельно, в [../pipeline/PIPELINE.md](../pipeline/PIPELINE.md), и остаётся
источником истины; описание здесь читается **после** неё и ей не противоречит. Разойдутся - правится
описание, а не схема.
