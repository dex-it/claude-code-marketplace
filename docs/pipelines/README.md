# Конвейеры

Дом конвейеров: у каждого своя папка, и в ней все его документы - нормативная основа, схема работы,
состав реализации, архитектура исполнения. Один конвейер - одна папка.

| Конвейер | Папка | Состояние |
|---|---|---|
| аналитика (требования зоны 1) | [analytics/](analytics/) | схема принята, реализация идёт |
| архитектура | - | отдельный конвейер, вход - готовый набор требований; не начат |

**Порядок чтения внутри папки** одинаков для всех: `NORMS.md` - чем подпёрто, `PIPELINE.md` - как
работает, `IMPLEMENTATION.md` - чем исполняется, `ARCHITECTURE.md` - как собрано. Источник истины -
схема (`PIPELINE.md`); описание исполнения читается после неё и ей не противоречит. Разойдутся -
правится описание, а не схема.
