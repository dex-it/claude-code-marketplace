# Конвейеры

Дом конвейеров: у каждого своя папка, и в ней все его документы - нормативная основа, схема работы,
состав реализации, архитектура исполнения. Один конвейер - одна папка.

| Конвейер | Папка | Состояние |
|---|---|---|
| требования (зона требований) | [analytics/](analytics/) | схема принята, реализация идёт |
| дизайн (требования -> одобренный дизайн) | [architecture/](architecture/) | облегчённый объём - README + один конспективный `PIPELINE.md`, без `NORMS.md`/`IMPLEMENTATION.md`/`ARCHITECTURE.md` (см. README.md папки) |

Раскладка того, что конвейеры производят (носители, уровни артефакта, ключи путей, оракулы,
трассировка), общая для всех конвейеров: [../CORPUS.md](../CORPUS.md).

**Порядок чтения внутри папки** одинаков для полного объёма (`analytics/`): `NORMS.md` - чем
подпёрто, `PIPELINE.md` - как работает, `IMPLEMENTATION.md` - чем исполняется, `ARCHITECTURE.md` -
как собрано. Источник истины - схема (`PIPELINE.md`); описание исполнения читается после неё и ей
не противоречит. Разойдутся - правится описание, а не схема. Папка облегчённого объёма несёт только
`PIPELINE.md` - остальные три документа backlog, порядок чтения к ней не применим до их появления.
