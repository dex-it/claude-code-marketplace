# Доменная модель каталога: словарь

**status:** review
**дата:** 2026-08-22
**назначение:** одно имя - один смысл во всех артефактах каталога. Термин, употреблённый в skill,
агенте, команде или нормативном документе, имеет ровно одну запись здесь.

**Как читать колонки.** «Дом» - файл, где живёт нормативное определение; словарь его не дублирует, а
адресует. Пустой дом означает, что термин в обиходе есть, а нормативного определения нет: такая
строка - долг, и она названа в разделе «Термины без дома». «Не путать с» отделяет термин от
соседнего, с которым его смешивают на практике.

Расхождения между носителями сведены не молча: то, что нельзя свести без решения, вынесено в раздел
«Расхождения, требующие решения» - в тексте словаря на их месте стоит ссылка на пункт `D-N`.

## Исполнение: как ведётся работа

| Термин | Значение | Дом | Не путать с |
|---|---|---|---|
| Движок | зона-агностичный цикл доведения до конца: стоп-линия, леджер, режимы, возобновление, делегирование узлам | `dex-sdlc:engine` | трек |
| Трек | порядок конкретной зоны: фазы, гейты, состав узлов, DoD; носитель - `dex-skill-<зона>-track` | `plugins/ai-sdlc/dex-sdlc/README.md`, «Три слоя» | движок, зона |
| Узел | субагент-специалист, делающий одну работу: вход -> `status` | `plugins/ai-sdlc/dex-sdlc/README.md`, «Три слоя»; рантайм-контракт - `dex-skill-node-contract:node-contract` | агент-одиночка (см. `D-2`) |
| Зона | область SDLC, у которой есть собственный порядок работ и свой трек | нет (см. `D-1`) | уровень артефакта |
| Фаза | шаг агента как контракт: Goal / Input / Output / Exit criteria / Gate | `docs/AGENT_FRAMEWORK.md`, глоссарий | процедура, шаг инструкции |
| Handoff | передача работы между узлами: сигнатура в `description` + словарь полей выхода | `docs/AGENT_FRAMEWORK.md`, «Inter-agent handoff»; поля - `node-contract` | вызов инструмента |
| Режим (`mode`) | `interactive` - у исполнителя есть канал к оператору; `autonomous` - канала нет. Нет поля -> `autonomous`. Вниз не наследуется | `node-contract`, п.11 | право пропустить бизнес-решение |
| Статус исхода (`status`) | `complete` / `blocked` / `partial` - первое поле выхода узла, машинно различимый исход | `node-contract` | вердикт оракула |
| Возврат наверх | передача нехватки вызывающему; для субагента это всегда оркестратор, а не пользователь | `docs/AGENT_FRAMEWORK.md` | вопрос оператору |
| Auto-ledger | состояние прогона движка вне рабочего дерева; живёт один прогон, контракт - буквальные строки статуса | `dex-sdlc:engine` | decision-log |
| Decision-log | журнал принятых решений в корпусе проекта, версионируется вместе с ним | `node-contract`, «Журнал решений» | auto-ledger |
| Graceful degradation | продолжение работы по запасному пути с называнием недоступности в выходе; проверку не отменяет | `node-contract` | молчаливый пропуск шага |

## Расхождения, требующие решения

Каждый пункт: где, в чём механизм, что предлагается. Пока пункт открыт, словарь фиксирует оба
употребления и не выбирает за пользователя.

**`D-1`. «Зона» и «уровень артефакта» - два числовых ряда, которые пересекаются номерами.**

- **Где**: `plugins/ai-sdlc/dex-sdlc/README.md` - «`/feature` - конвейер требований зоны 1», «`/design`
  - архитектурная сессия зоны 2»; `docs/product/brd.md` и этот файл - уровни 0/1/2/3.
- **В чём**: «зона 1» - требования фичи, а «уровень 1» - тоже фича, но «зона 2» - дизайн, тогда как
  «уровень 2» - реализация; при этом уровня 0 (продукт) в ряду зон нет вовсе. Числа совпадают
  частично, и читающий переносит смысл с одного ряда на другой.
- **Что предлагается**: держать ряды раздельно и явно - «зона» перестаёт нумероваться, называется
  по имени (`зона требований`, `зона дизайна`), номер остаётся только у уровня артефакта. Правка
  затрагивает тела треков и README движка, поэтому вынесена решением, а не сделана здесь.

**`D-2`. «Узел» определён как субагент, но требование стандартного I/O предъявлено и одиночке.**

- **Где**: `plugins/ai-sdlc/dex-sdlc/README.md` - «Узел - субагент-специалист: одна работа: вход ->
  `status`»; `docs/AGENT_FRAMEWORK.md:91` - «Агент-одиночка обязан иметь стандартный I/O ровно так
  же, как узел конвейера»; `docs/AGENT_FRAMEWORK.md:365` - «pre-load безусловного process-skill
  (узлу нужен всегда); опускается у не-узлов».
- **В чём**: одно и то же слово несёт то роль в цепочке (тогда «не-узел» существует и `skills:`
  опускается), то свойство агента (тогда «не-узлов» нет, потому что I/O требуется от всех). Признак,
  по которому агент относят к узлам, нигде не назван - и от него зависит содержимое frontmatter.
- **Что предлагается**: закрыть тем же решением, что уже открыто по `node-contract` (расхождение
  зафиксировано ранее и не решено). До решения словарь называет узлом роль в цепочке, а требование
  стандартного I/O относит ко всем агентам.

**`D-3`. «Гейт» покрывает и проверку качества, и остановку человека.**

- **Где**: `docs/AGENT_FRAMEWORK.md`, глоссарий - Gate как условие перехода фазы;
  `docs/pipelines/analytics/PIPELINE.md` - гейты качества по двум слоям оракулов и отдельно две
  безусловные остановки оператора.
- **В чём**: гейт качества исполняется инструментом и человека не требует, остановка оператора
  требует решения человека и в `autonomous` неисполнима. Общее слово даёт прочтение «фаза закрылась
  без вопросов - значит, апрув получен».
- **Что предлагается**: словарь уже развёл записи («Гейт» и «Остановка оператора»); правка тел
  артефактов - когда термин будет вычищен пофайлово при касании, отдельным сквозняком не идём.

## Термины без дома

Употребляются в артефактах, нормативного определения нет. Строка закрывается либо заведением дома,
либо признанием термина обиходным и изъятием из нормативных текстов.

- **зона** - см. `D-1`; определения нет ни в одном носителе, только употребление.
- **стоп-линия** - названа в описании движка как его часть, отдельного определения нет.
- **дирижёр гейта** - фигурирует в `node-contract` и в конвейере требований как тот, кто ставит
  метку; как роль не определён (это трек, оркестратор или отдельный узел).
- **заглушка трека** - в README движка объяснено как «перенос прежнего текста без переработки»;
  критерий, по которому заглушка становится полным треком, не назван.
