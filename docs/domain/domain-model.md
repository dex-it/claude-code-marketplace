# Доменная модель каталога: словарь

**status:** review
**дата:** 2026-08-22
**назначение:** одно имя - один смысл во всех артефактах каталога. Термин, употреблённый в skill,
агенте, команде или нормативном документе, имеет ровно одну запись здесь.

**Как читать колонки.** «Дом» - файл, где живёт нормативное определение; словарь его не дублирует, а
адресует. Пустой дом означает, что термин в обиходе есть, а нормативного определения нет: такая
строка - долг, и она названа в разделе «Термины без дома». «Не путать с» отделяет термин от
соседнего, с которым его смешивают на практике.

Расхождения между носителями сведены не молча: то, что нельзя свести без решения, вынесено в раздел
«Расхождения, требующие решения» - в тексте словаря на их месте стоит ссылка на пункт `D-N`.

## Исполнение: как ведётся работа

| Термин | Значение | Дом | Не путать с |
|---|---|---|---|
| Движок | цикл доведения до конца: стоп-линия, леджер, режимы, возобновление, делегирование узлам. Агностично правило-тело: порядок зоны движок не несёт, но справочник зон для резолва голого входа принадлежит ядру (`references/zone-registry.md`) | `dex-sdlc:engine` | трек |
| Трек | порядок конкретной зоны: фазы, гейты, состав узлов, DoD; носитель - `dex-skill-<зона>-track` | `plugins/ai-sdlc/dex-sdlc/README.md`, «Три слоя» | движок, зона |
| Узел | роль агента в цепочке: его вызывает трек или другой агент, выход читает вызывающий. Стандартный I/O обязателен для всех агентов, pre-load `node-contract` - только у узла | `docs/AGENT_FRAMEWORK.md`, глоссарий; рантайм-контракт - `dex-skill-node-contract:node-contract` | сорт агента |
| Зона | область работ со своим порядком; носитель порядка - `dex-skill-<зона>-track`. Называется именем предмета (`требований`, `дизайна`), номера не несёт | `dex-sdlc:engine`, «Костяк» | уровень артефакта |
| Фаза | шаг агента как контракт: Goal / Input / Output / Exit criteria / Gate | `docs/AGENT_FRAMEWORK.md`, глоссарий | процедура, шаг инструкции |
| Handoff | передача работы между узлами: сигнатура в `description` + словарь полей выхода | `docs/AGENT_FRAMEWORK.md`, «Inter-agent handoff»; поля - `node-contract` | вызов инструмента |
| Режим (`mode`) | `interactive` - у исполнителя есть канал к оператору; `autonomous` - канала нет. Нет поля -> `autonomous`. Вниз не наследуется | `node-contract`, п.11 | право пропустить бизнес-решение |
| Статус исхода (`status`) | `complete` / `blocked` / `partial` - первое поле выхода узла, машинно различимый исход | `node-contract` | вердикт оракула |
| Возврат наверх | передача нехватки вызывающему; для субагента это всегда оркестратор, а не пользователь | `docs/AGENT_FRAMEWORK.md` | вопрос оператору |
| Стоп-линия | граница автономии по «обратимость x радиус действия»: необратимое или массовое (force-push в общую ветку, перезапись данных стенда, ротация секретов) требует подтверждения даже в `autonomous`; обратимое точечное идёт без спроса | `dex-sdlc:engine`, «Стоп-линия» | остановка оператора (там развилка решения, здесь необратимость действия) |
| Дирижёр | исполнитель, ведущий порядок зоны: ставит метку на гейте, пишет журнал решений, выдаёт номера, считает круги правок. Через движок это трек зоны, вне движка - оркестратор или главный поток | `node-contract`, преамбула «Правило стыка» | узел (исполняет одну работу); ревьюер (судит артефакт, зоной не ведёт) |
| Auto-ledger | состояние прогона движка вне рабочего дерева; живёт один прогон, контракт - буквальные строки статуса | `dex-sdlc:engine` | decision-log |
| `DoR` / `DoD` | условие старта и наблюдаемый выход единицы работы движка: `DoR` - что верно, чтобы начинать (входные артефакты взяли порог допуска, факты сверены, потребители разведаны, тест-инфра есть), `DoD` - чеклист наблюдаемых фактов, которыми работа закрыта | `dex-sdlc:engine`, шаг 3 | порог допуска артефакта; `DoR` спринта в `dex-skill-agile` |
| Decision-log | журнал принятых решений в корпусе проекта, версионируется вместе с ним | `node-contract`, «Журнал решений» | auto-ledger |
| Graceful degradation | продолжение работы по запасному пути с называнием недоступности в выходе; проверку не отменяет | `node-contract` | молчаливый пропуск шага |

## Принятые решения по расхождениям

Пункты `D-1..D-3` закрыты; записи оставлены, потому что называют, что именно было сведено и куда
смотреть при следующем употреблении термина.

**`D-1`. Зона и уровень артефакта - разные ряды; нумеруется только уровень.** Зоны называются именем
предмета (`зона требований`, `зона дизайна`), номер зоны изъят из нормативных текстов. Дом
определения - `dex-sdlc:engine`, раздел «Костяк». Исторические коды прогонов `Z1-*` / `Z2-*` и имена
файлов кейсов в `tests/` сохранены: это идентификаторы записей журнала, а не термины; легенда - в
`tests/README.md`.

**`D-2`. Узел - роль в цепочке, а не сорт агента.** Агент становится узлом там, где его вызывает
трек или другой агент с handoff, и его выход читает вызывающий. Стандартный I/O обязателен для всех
агентов; pre-load `node-contract` через `skills:` - только у узла. Дом - глоссарий
`docs/AGENT_FRAMEWORK.md`.

**`D-3`. Гейт и остановка оператора - разные вещи.** Гейт исполняет инструмент и человека не
требует; остановку назначает трек зоны там, где цена ошибки лежит вне артефакта, и в `autonomous`
она неисполнима. Оба термина определены в глоссарии `docs/AGENT_FRAMEWORK.md`.

## Термины без дома

Употребляются в артефактах, нормативного определения нет. Строка закрывается либо заведением дома,
либо признанием термина обиходным и изъятием из нормативных текстов.

Открытых строк нет: `стоп-линия`, `дирижёр` и `полнота трека` получили дом (строки выше).
