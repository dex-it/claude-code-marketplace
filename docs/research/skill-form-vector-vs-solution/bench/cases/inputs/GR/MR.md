# MR !238: Выпуск на линию, комплектация машин, незакрытые путевые листы, отчёт по выходным

## Описание

Закрываем задачи спринта по автопарку:

- **FLEET-104** Комплектация машин (аптечка, огнетушитель, знак аварийной остановки, трос...). Механик присылает
  актуальную комплектацию машины целиком - заменяем на присланную. Новая таблица `vehicle_equipment`.
- **FLEET-107** Выпуск на линию: диспетчер выпускает машину, только если у водителя есть действующий допуск к классу
  машины (допуск действует по указанную в нём дату включительно) и последний предрейсовый осмотр машины не старше
  12 часов и без блокирующих замечаний. Осмотры приходят с планшетов механиков (синхронизация уже есть).
- **FLEET-109** Отчёт для службы безопасности: поездки в выходные и праздники за месяц (контроль личного
  использования), самые длинные сверху.
- **FLEET-112** Список путевых листов, не закрытых больше суток, с фильтром по машине. SQL взят из дашборда
  диспетчерской, где он работает давно.
- **FLEET-115** Поле «Марка, модель» укорочено до 40 символов - столько вмещает графа печатного путевого листа
  (длинные названия моделей принтер обрезал на середине).

Миграция `VehicleEquipmentAndModelLength` сгенерирована `dotnet ef migrations add`, выкатывается на prod обычным
pipeline (bundle).

Проверено локально: выпуск на линию на тестовой машине, список незакрытых листов по всему парку; миграция
применена на dev-базе.
