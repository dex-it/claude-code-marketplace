# MR !87: Партии проб - карточка, закрытие, переразметка, процент соответствия

## Описание

- **LAB-140** Карточка партии: приборы, пробы, число результатов и признак превышения нормы по каждой пробе.
- **LAB-141** Список партий с постраничным выводом (новые сверху).
- **LAB-143** Закрытие партии: пробы «в анализе» переводятся в «готово», партии проставляется дата отчёта.
  Закрыть партию с пробами без результатов нельзя.
- **LAB-144** Планирование отбора: пробоотборщик выбирает день и время по местным часам объекта.
- **LAB-146** Переразметка пробы: лаборант присылает итоговый список тегов.
- **LAB-147** Процент соответствия партии (доля проб, у которых все показатели в норме) - для дашборда.
- Карточка объекта: пробы за последние N дней (`SampleRepository.GetRecentBySiteAsync`).

Проверено на стенде: карточка партии на 120 проб, закрытие партии, переразметка.
