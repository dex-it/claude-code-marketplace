# MR !4210: карточка заказа, выгрузка корзины и аудит для админки

- OrderCard: карточка одного заказа со всеми позициями и платежами для экрана оператора.
- CartLookup: товары корзины по списку id с фронта (от одного до нескольких тысяч id).
- CustomerOrders: постраничный список заказов клиента, страницы нумеруются с 1.
- AuditWriter: запись события аудита по действию оператора.

Изменённые файлы: Services/OrderCard.cs, Services/CartLookup.cs, Services/CustomerOrders.cs, Workers/AuditWriter.cs.
Остальные файлы каталога - существующий код проекта, в MR не менялись.
