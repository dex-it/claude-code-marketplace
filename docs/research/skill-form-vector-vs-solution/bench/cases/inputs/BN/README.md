# VetClinic.Procedures

Процедурный кабинет ветклиники «Лапа» (один филиал).

Стек: .NET 8, EF Core 8.0.x, Npgsql.EntityFrameworkCore.PostgreSQL 8.0.x, PostgreSQL 16.

## Правила данных

- Моменты событий (создание записи, заметки персонала) храним в UTC - `timestamp with time zone`.
- Расписание процедурного кабинета ведётся по настенным часам кабинета, как в бумажном журнале, с которым
  его сверяют: колонка `timestamp without time zone`, значение ни в какой пояс не пересчитывается.
- Строки расходников процедуры можно удалять, пока процедура не закрыта (это черновик списания);
  после закрытия (`Closed`) - нельзя.
- Номер микрочипа уникален (ISO 11784, 15 цифр).
