# VetClinic.Records

Сервис медкарт ветклиники «Лапа»: клиенты, питомцы, аллергии, визиты.

Стек: .NET 8, EF Core 8.0.x, Npgsql.EntityFrameworkCore.PostgreSQL 8.0.x, PostgreSQL 16.

## Правила данных

- Клиенты и записи медкарты (питомцы, аллергии, визиты) **физически не удаляются**: по требованию
  ветнадзора история хранится 5 лет. «Удалить» = `IsDeleted = true` + `DeletedAt`. Глобальные фильтры
  в `ClinicDbContext` скрывают удалённые записи; восстановление делает поддержка через админку.
- Схема БД меняется только миграциями EF Core (`src/VetClinic.Records/Migrations`).

## Выкладка

См. `.gitlab-ci.yml`. CI собирает из миграций идемпотентный SQL-скрипт, DBA просматривает его и
запускает джобу `db-migrate` в окно обслуживания (приложение на это время остановлено), затем `deploy`
поднимает 3 реплики. В проде приложение ходит в БД под ролью `vet_app`: у неё только права на чтение
и запись данных (DML), прав на изменение схемы (DDL) нет.
