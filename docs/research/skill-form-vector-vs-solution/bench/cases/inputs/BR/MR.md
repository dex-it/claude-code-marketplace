# MR !214: Стационар - боксы, госпитализации, назначения, выписка со счётом

## Зачем

Стационар ведёт учёт на бумаге и в Excel. Переносим в систему: боксы отделений, госпитализации,
план назначений, выписку со счётом, отчёт по занятости.

## Что сделано

- `Domain/Inpatient.cs` - новые сущности `Box`, `Stay`, `MedicationOrder`, `Observation`.
- `Data/ClinicDbContext.cs` - конфигурация новых сущностей; выведенные из эксплуатации боксы скрыты
  глобальным фильтром; госпитализацию с назначениями нельзя удалить (`Restrict`).
- `Services/WardService.cs` - список пациентов отделения, длительные госпитализации (больше 14 дней)
  для обхода главврача, карточка бокса, карточка последней госпитализации питомца, замена плана
  назначений врачом, вывод бокса из эксплуатации, выписка со счётом.
- `Services/InpatientReportService.cs` - занятость отделения с сортировкой по столбцу, выбранному на
  экране; история госпитализаций питомца.
- `Api/InpatientEndpoints.cs` - эндпоинты.
- `Program.cs` - миграции применяются при старте приложения, чтобы больше не забывать запускать
  `db-migrate`.
- Миграция `AddInpatient` сгенерирована `dotnet ef migrations add` без ручных правок (в MR не показана).
