# VetClinic.Hospital

Сервис стационара ветклиники «Лапа».

Стек: .NET 8, EF Core 8.0.x, Npgsql.EntityFrameworkCore.PostgreSQL 8.0.x, PostgreSQL 16.

## Правила стационара

- Бокс вмещает до `Capacity` животных: помёт или животные одного владельца содержатся вместе.
- Бокс выводят из эксплуатации (ремонт, карантин) в любой момент, в том числе когда в нём ещё лежат
  пациенты - их переводят в другие боксы в течение дня. Выведенный бокс не предлагается при поступлении,
  но все госпитализированные пациенты должны оставаться в списках отделения, пока их не выписали.
- Назначения - часть медкарты и физически не удаляются: отменённое назначение получает `CancelledAt`
  (история назначений нужна при разборе осложнений).
- Стоимость стационара = число календарных дней пребывания, **включая день поступления и день
  выписки**, × суточный тариф бокса.
- Выписку оформляет только врач (политика авторизации `Vet`). Администраторы ресепшена видят списки,
  но не выписывают.

## Выкладка

См. `.gitlab-ci.yml`. Схема меняется только миграциями EF Core; CI собирает из них идемпотентный
SQL-скрипт, DBA просматривает его и запускает джобу `db-migrate` под ролью `vet_migrator`. Приложение
в проде работает под ролью `vet_app` (только DML, без прав на DDL), 3 реплики, rolling update.
