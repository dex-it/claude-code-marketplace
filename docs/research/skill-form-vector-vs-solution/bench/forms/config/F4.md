# .NET Config Hygiene - чек-лист

Пункт называет ситуацию, которую изменение проверяет; решение - по документации .NET версии из манифеста проекта.

- Staging агрессивнее Production: лимиты Staging не выше Production, если причина не записана рядом
- Имя настройки без единицы
- Валидация конфигурации при старте
- Валидатор опций и его регистрация
- `IOptions` при требовании менять значение на лету
- Кросс-полевой инвариант опций
- Non-nullable свойство опций без значения из конфигурации: модификатор `required` к валидации опций отношения не имеет; отсутствие значения ловит валидация опций на старте (`ValidateDataAnnotations` или валидатор + `ValidateOnStart`), не `required`
- Единица измерения в имени настройки
- Значение по умолчанию в каждом env-файле: env-файл несёт только отличия от дефолта
- Секреты в appsettings в репозитории
