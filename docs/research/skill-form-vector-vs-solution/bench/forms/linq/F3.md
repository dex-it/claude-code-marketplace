# LINQ и коллекции - чек-лист

Пункт называет ситуацию, которую изменение проверяет; решение - по документации .NET / EF Core версии из манифеста проекта.

- Материализация в начале цепочки
- Полная сущность для списка
- Проверка наличия через `Count() > 0`: сколько строк считает запрос, чтобы ответить «есть или нет»
- Запрос в цикле
- `Contains` по большому списку в запросе: EF Core 8 передаёт список одним параметром; в Npgsql `list.Contains(x)` - `x = ANY(@p)`; сколько параметров и запросов даёт `Contains` по списку в версии проекта
- `GroupBy` с материализацией внутри `Select`
- Сортировка после проекции
- `List.Contains` в горячем цикле
- Поиск по списку в цикле
- Повторный обход `IEnumerable`
- `Distinct()` на объектах
- Дубли во входном списке id: повторяются ли id во входе и что получит повторённый id
- `[0]` / `First()` после фильтра
- `Average` / `Min` / `Max` на коллекции, которая бывает пустой
- Материализация в каждой ветке динамического запроса
