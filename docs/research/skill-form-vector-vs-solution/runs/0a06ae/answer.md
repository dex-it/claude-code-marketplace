Решения:
- **(а) и (б), карточка заказа и выгрузка заказов клиента.** Заказы читаются без отслеживания изменений (`AsNoTracking`), позиции и платежи подгружаются через `Include`. Запрос разбит на отдельные SQL-запросы (`AsSplitQuery`), чтобы позиции и платежи не перемножались в одном JOIN — это важно при тысячах заказов. Выгрузка отсортирована по `CreatedAt`, затем по `Id`. Удалённые заказы отсекает уже существующий фильтр `HasQueryFilter`.
- **(в) `GetProductBySku(string sku, string? warehouse)`.** Если склад передан, ищем одну запись по паре SKU и склад: на одном складе SKU уникален. Если склад null, одну запись молча не выбираем. Метод возвращает `Found`, `NotFound` или `Ambiguous` — в последнем случае со списком складов, где лежит этот SKU.
- **(г) Дата последней отгрузки.** Максимум считается в базе по заказам с `ShippedAt != null`. Если у клиента нет отгруженных заказов, метод бросает `InvalidOperationException`, потому что тип возврата `DateTime` не допускает null. `ShippedAt` хранится как `timestamptz` и читается в UTC (`Kind=Utc`).
