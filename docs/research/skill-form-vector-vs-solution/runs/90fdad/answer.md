Выполнил все четыре задачи для сервиса управляющей компании:

## Созданные/изменённые файлы

1. **Models.cs** — добавлены поля `Phone` (опциональный номер) и `CompletionComment` (комментарий при закрытии) в `ServiceRequest`
2. **HousingDbContext.cs** — конфигурация новых свойств с ограничением длины
3. **HousingService.cs** — реализована сортировка по дате (по умолчанию DESC), адресу (дом→квартира) и статусу; добавлен метод `CloseRequestAsync` с проверкой статуса InProgress; поддержка номера телефона при создании заявки
4. **PlanService.cs** — метод `UpdatePlanAsync` для замены плана целиком с сохранением истории выполнения

## Ключевые решения

- Сортировка: трёхуровневая (по умолчанию дата DESC), для адреса используется составной ключ (дом ID, затем номер квартиры)
- Закрытие заявки: проверка статуса выполнена исключением `InvalidOperationException` (преобразуется в 409 на уровне контроллера)  
- Обновление плана: сравнение по WorkCode, новые работы добавляются, отсутствующие удаляются, существующие обновляются с полным сохранением истории
