**Решение:**

**(a)** Выписка загружается построчно, каждая строка проверяется на дублирование через BankRef. Номер договора извлекается из назначения платежа, абонент ищется по ContractNo. При совпадении зачисляется платёж и баланс; при отсутствии абонента платёж откладывается в UnreconciledPayment.

**(б)** После зачисления платежа проверяется статус Suspended — если баланс ≥ 0, абонент переходит в Active с отметкой ResumedAt.

**(в)** Поиск по последним цифрам телефона через EndsWith с лимитом 20 результатов.
