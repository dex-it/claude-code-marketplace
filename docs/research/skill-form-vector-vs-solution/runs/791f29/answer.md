- `_answer.md` — этот ответ

Решения:
- Входной `IEnumerable` перебирается один раз: дубликаты id убираются через `Distinct().ToList()`, то есть одному клиенту уходит одно письмо. Для пустого списка метод сразу завершается.
- Клиенты загружаются не по одному в цикле, а пачками по 500 id (`Chunk`, в SQL — `WHERE Id IN (...)`), чтобы не раздувать список параметров в PostgreSQL. Из БД берётся только `Email`. Несуществующие id и клиенты с пустым email пропускаются.
- Письма отправляются последовательно, тема задана константой. Ошибка отправки прерывает всю рассылку, а часть писем к этому моменту уже уйдёт. Повторы и журнал отправленных писем не делал.
- Сборку и тесты не запускал.
