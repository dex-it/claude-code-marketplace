Решения:
- **Входной список.** `IEnumerable<Guid>` обходится один раз, дубли убираются через `Distinct().ToArray()`. Адреса загружаются пачками по 1000 id, по одному запросу на пачку, а не на каждого клиента. `Contains` в Npgsql превращается в `= ANY(@ids)`. Из базы берётся только колонка `Email`, а не вся сущность.
- **Одно письмо на адрес.** `HashSet` без учёта регистра пропускает повторяющиеся адреса, пустые адреса тоже пропускаются. Id, которых нет в базе, просто игнорируются.
- **Сигнатура.** `IEmailSender` асинхронный, поэтому метод возвращает `Task`. Имя оставил `NotifyCustomers` и добавил `CancellationToken`.
- **Тема и ошибки.** В сигнатуре темы нет, поэтому тема письма — константа. Если отправка падает, исключение пробрасывается и рассылка останавливается на этом месте.
