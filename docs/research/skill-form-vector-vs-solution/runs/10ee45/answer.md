Создан файл: `CustomerNotifier.cs`

Решения:
- ID из маркетинговой системы дедуплицируются (`Distinct()`), чтобы не отправлять письмо дважды одному клиенту.
- Список ID батчится по 500 (`Chunk`) перед `Contains`, чтобы не деградировал план запроса в PostgreSQL на больших списках.
- Из БД выбирается только `Email` через проекцию (`Select`), а не полные сущности `Customer`, одним запросом `WHERE IN` на батч вместо N запросов в цикле.
