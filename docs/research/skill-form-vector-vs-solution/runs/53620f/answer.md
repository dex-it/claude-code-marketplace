Решения:
- **Отметка прихода.** E-mail уникален только в пределах одного мероприятия. Поэтому `/checkin` ищет регистрацию среди мероприятий, которые идут сегодня (по часовому поясу площадки), или по `eventId`, если он передан. Если найдено несколько регистраций, возвращается 409 со списком мероприятий. При повторной отметке `CheckedInAt` не меняется.
- **Удалённые залы.** На `Hall` действует фильтр `IsDeleted`. В бейдже воркшопы берутся без обращения к залу, а отчёт использует `IgnoreQueryFilters`. Так оплаченные воркшопы и выручка по выведенным из работы залам не пропадают. Отчёт строится по `PaidOn` в полуоткрытом интервале квартала и суммирует `PaidAmount`, а не `Price`.
- **Последняя версия программы.** `PublishedOn` хранит только дату, а за один день может быть несколько публикаций. Поэтому при одинаковой дате берётся версия с большим `Id`, пункты сортируются по `StartsAt`.

Сборка и тесты не запускались. Миграций в проекте нет: для колонки `Company` миграцию нужно добавить отдельно.
