Решения:
- **Дубли:** входной список обходится один раз, дубли убираются через `Distinct()`, так что на каждый id уходит одно письмо. Если такого клиента в базе нет, id просто пропускается.
- **Один запрос:** адреса почты читаются одним запросом `Where(ids.Contains(c.Id)).Select(c => c.Email)` с `AsNoTracking`. EF Core 8 с Npgsql передаёт список одним параметром (`= ANY(@p)`). Поэтому нет отдельного запроса на каждого клиента, список не режется на пачки и из базы берётся только поле Email.
- **Тема и ошибки:** тема письма в поручении не указана, поэтому пока стоит константа `"Shop"` — её нужно заменить на настоящую. Если отправка одного письма падает с исключением, рассылка на этом останавливается.
