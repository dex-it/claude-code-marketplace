## Решения
E-mail сравнивается через `ToLower()` в SQL (без учёта регистра клавиатуры телефона), поэтому используется `FirstOrDefault` с сортировкой по `Id`, а не `Single` — БД гарантирует уникальность только по точному совпадению. Отчёт по выпускникам обходит `!IsDeleted`-фильтр инструкторов через `IgnoreQueryFilters()`, но школа восстановлена вручную, чтобы не потерять мульти-тенантность; счётчик выпускников считается агрегатом в SQL. Список учеников инструктора и ближайшее занятие получены одним запросом (коррелированный подзапрос `MIN(StartsAt)`), маскирование — после материализации через общий `Masking`.
