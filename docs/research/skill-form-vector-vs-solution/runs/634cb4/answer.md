Создан файл: `CustomerNotifier.cs` (и `_answer.md` с этим же резюме).

Решения:
- Список ID от внешней (маркетинговой) системы дедуплицируется через `Distinct()`, чтобы не слать письмо дважды одному клиенту.
- ID батчатся по 500 (`Chunk(500)`) перед `WHERE IN`, чтобы не деградировал план запроса Postgres на больших списках.
- Из БД выбирается только `Email` через `Select`, а не целая сущность `Customer` — меньше трафика и нет лишней нагрузки на change tracker.
