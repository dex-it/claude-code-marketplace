Задачи выполнены. Вот список созданных/изменённых файлов:

1. **appsettings.json** — новый файл с конфигурацией штрафов (PerDay, GraceDays, Max)
2. **Program.cs** — добавлена регистрация FineRules через DI, endpoints GET /branches/{id}/debtors и POST /reports/loans-by-branch
3. **LoanService.cs** — внедрена конфигурация через IOptions<FineRules>, методы GetDebtorsAsync (должники с активными просроченными выдачами, отсортированные по штрафам с суммой) и GetLoansByBranchAsync (число выдач по филиалам за период в UTC)

**Решения:**
- Штрафы вынесены в конфиг через appsettings и DI, что позволяет менять ставки без пересборки.
- Должники запрашиваются Include-ом для читателя и книги с AsNoTracking (оптимизация), фильтруются только с положительным штрафом и сортируются убыванием штрафа.
- Отчёт вычисляет GROUP BY в SQL; период из POST-тела преобразуется из пользовательского часового пояса в UTC для корректной фильтрации.
