Решения:
- **Большой список из маркетинговой системы.** Дубли id отбрасываются, остальные делятся на пачки по 1000. На каждую пачку идёт один запрос без отслеживания сущностей (`AsNoTracking`), который берёт только `Id` и `Email`, поэтому запросов на каждого клиента по отдельности нет. Ни весь список, ни клиенты целиком в памяти не лежат.
- **Асинхронный метод.** Метод возвращает `Task<NotifyResult>` и принимает `CancellationToken`, потому что `IEmailSender.SendAsync` асинхронный. Тема письма — необязательный параметр, в задаче она не задана.
- **Ошибки отправки.** Если письмо одному клиенту не ушло, рассылка продолжается, а его id попадает в `Failed`. Иначе при повторном запуске уже получившие письмо клиенты получили бы его ещё раз. Id, которых нет в базе или у которых пустой email, попадают в `NotFound`. Отмена через токен прерывает рассылку.
