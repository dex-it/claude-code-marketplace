**Решение:**
Класс `CustomerNotifier` отправляет письма через `IEmailSender` каждому клиенту из переданного списка ID. Реализация применяет три правила из SKILL.md: (1) дедупликация входных ID предотвращает повторную обработку, (2) батчинг по 500 избегает деградации SQL-плана при большом числе параметров, (3) проекция `.Select()` грузит только `Email` и `Name` вместо полной сущности, экономя трафик и память.
