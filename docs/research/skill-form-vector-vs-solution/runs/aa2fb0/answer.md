## Результат

**Файлы изменены/созданы:**
- `Models.cs` - добавлено поле `FrozenUntil` к `Member`
- `ScheduleService.cs` - методы `FreezeAsync()`, `UnfreezeAsync()`, `GetRandomSessionAsync()` и запись `RandomSessionDto`; проверка заморозки в `EnrollAsync()`
- `Program.cs` - endpoints для заморозки/разморозки и получения случайного занятия
- `TurnstileWorker.cs` - проверка заморозки при обработке проходов турникета

**Решение:**

(а,г) Заморозка хранится в `FrozenUntil` и проверяется при записи на занятие (409 при попытке записи если абонемент заморожен на момент начала).

(б) При проходе через турникет TurnstileWorker проверяет заморозку и пишет примечание "абонемент заморожен", не засчитывая посещение (запись остаёт "записан").

(в) Endpoint GET /quality/random-session выбирает случайное занятие из ближайших 7 дней и возвращает курс, тренера, зал, время и имена записавшихся.
