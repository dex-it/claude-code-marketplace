Решения:
- (а)/(б): `Include` для Items и Payments + `AsSplitQuery` (без декартова произведения); (б) возвращает `IAsyncEnumerable<Order>` вместо `List<Order>`, чтобы не грузить в память тысячи заказов сразу.
- (в): при заданном warehouse — точный матч (sku, warehouse); при `null` — если SKU уникален по складам, возвращаем найденный, иначе явно бросаем исключение вместо угадывания склада.
- (г): выбирается только колонка `ShippedAt`; при отсутствии отгруженных заказов бросается исключение, т.к. возврат не nullable и подменять "нет данных" фиктивной датой нельзя.
