Решения:
- Дубли id снимаю через `Distinct()` до обработки, чтобы на один id уходило одно письмо. Вход перечисляю один раз (`ToArray`). Если список пустой, метод выходит без запроса к БД.
- Все email достаю одним запросом без отслеживания изменений: `ids.Contains(c.Id)` превращается в Npgsql в `Id = ANY(@p)` с одним параметром, поэтому список на пачки не режу. Запросов в цикле нет, полные сущности не загружаю — только `Email`. Несуществующие id просто пропускаются.
- `IEmailSender` асинхронный, поэтому метод возвращает `Task` и принимает `CancellationToken`. Тема письма — константа `"Shop"`, потому что в задаче она не указана.
