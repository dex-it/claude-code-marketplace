## Решения:

**(а)** Endpoint возвращает неверну­тые просроченные выдачи филиала, отсортированные по штрафу убывающе, с общей суммой внизу. Учитывается категория читателя и стандартное правило расчета штрафа.

**(б)** Отчёт конвертирует входной период пользователя в UTC и обратно в локальный пояс каждого филиала для корректного подсчёта выдач с перекрытием часовых поясов.

**(в)** FineRules внедряется через IOptions<FineRules> из конфигурации, позволяя менять параметры в appsettings без перекомпиляции.
