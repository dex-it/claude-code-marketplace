Решения:
- **(а) и (б):** все чтения идут с `AsNoTracking` и проекцией в DTO, поэтому lazy-loading прокси не срабатывают и лишних запросов (N+1) нет. Карточку заказа (а) грузит один запрос с JOIN, без `AsSplitQuery`. В выгрузке (б) стоит `AsSplitQuery` с сортировкой, чтобы тысячи заказов × позиции × платежи не перемножались в один огромный результат. Сейчас она возвращает весь список сразу; если заказов будет ещё больше, понадобится пагинация.
- **(в):** если склад передан, `GetProductBySku` ищет по паре SKU + склад через `SingleOrDefault`: эта пара уникальна. Если склад `null`, SKU может лежать на нескольких складах, поэтому метод берёт первый по имени склада через `FirstOrDefault`. Это временная заглушка: какой склад выбирать на самом деле, должен решить бизнес.
- **(г):** самая поздняя дата отгрузки считается в SQL, только по заказам с заполненной датой отгрузки. Тип результата `DateTime` не допускает null, поэтому если у клиента нет отгруженных заказов, метод бросает `InvalidOperationException`, а не возвращает `default`.
