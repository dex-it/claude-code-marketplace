## Ключевые решения

- Коды входа с 10-мин TTL хранятся в БД, нормализуется email по ToLower для case-insensitive поиска
- Отчёт использует `IgnoreQueryFilters()` включить уволенных инструкторов, группирует по выпускникам за год
- Ближайшее занятие загружается через `StartsAt > UtcNow`, паспорт маскируется по примеру `MaskForInstructor()`
