**Решения**
- **Поиск.** Для каждого `scope` свой фиксированный SQL-шаблон: собрать его из пользовательского ввода нельзя, а выражения `to_tsvector` совпадают с индексами из README буква в букву, включая `coalesce` для диагноза. Поиск по препарату сделан через `EXISTS`, чтобы визит не повторялся в выдаче. Если `scope` не передан, ищем по жалобе, как раньше; неизвестное значение → 400. В сортировку добавил `Id` вторым ключом: в одном слоте бывает несколько визитов, и без этого страницы «плывут».
- **Карточка.** Последний визит — самый поздний слот среди визитов со статусом Completed или InProgress. Питомец может быть в одном слоте у нескольких врачей, поэтому возвращаются все визиты этого слота, а не один произвольный. Если визитов нет — 404. Анализы и назначения грузятся отдельными запросами (split), без трекинга.
- **CSV.** Местные даты переводятся в UTC-интервал `[from 00:00; to+1 00:00)`, так фильтр попадает в индекс `(VetId, SlotStart)`. Число назначений считает БД подзапросом. Строки стримятся прямо в тело ответа и в памяти не копятся.

**Что стоит подтвердить у бухгалтерии:** отменённые приёмы в выгрузку не попадают; файл в UTF-8 с BOM и с разделителем `;` под русский Excel.
