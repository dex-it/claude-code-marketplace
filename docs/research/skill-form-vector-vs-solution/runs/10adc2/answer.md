Решения:
- **`CreatedAt`**: колонка остаётся `timestamp without time zone` и хранит время UTC. Npgsql 8 выбрасывает исключение, если в такую колонку писать `DateTime` с `Kind=Utc`. Поэтому конвертер при записи убирает Kind (локальное время сначала переводит в UTC), а при чтении помечает значение как Utc.
- **`Complexity`**: в коде по умолчанию 1, в базе CHECK `BETWEEN 1 AND 5`. `HasDefaultValue` не ставил: с ним явно заданный 0 без ошибки заменялся бы значением по умолчанию. Когда будете добавлять колонку миграцией, существующие строки нужно заполнить через `defaultValue: 1`.
- **Связи**: мягкое удаление ничего не каскадирует. Для Items стоит Cascade, поэтому `Items.Clear()` удаляет строки из базы. Для Payments стоит Restrict, то есть физически удалить из базы заказ с платежами нельзя. `ClearItems` загружает позиции через `Include`. Если заказ удалён или его нет, метод выбрасывает `KeyNotFoundException`.

`Total` после очистки позиций не пересчитывается. Нужно ли его обнулять, должен решить бизнес.
