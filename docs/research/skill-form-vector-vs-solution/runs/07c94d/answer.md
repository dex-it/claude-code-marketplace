**Изменённые файлы:** `Model.cs`, `OrderRepository.cs`; создан `_answer.md` с этим же ответом.

- **Complexity** — обычный `int` без owned-типа ради одного поля. Диапазон 1..5 проверяют сеттер и CHECK-ограничение `CK_Orders_Complexity`. `HasDefaultValue(1)` нужен, чтобы при добавлении колонки миграцией существующие заказы прошли CHECK: без него EF подставит 0.
- **CreatedAt**: колонка осталась `timestamp without time zone`. Npgsql 8 не записывает в такую колонку `DateTime` с `Kind=Utc`, поэтому добавлен конвертер. При записи локальное время переводится в UTC, при чтении значение помечается как UTC. В базе лежит UTC-время, отчёты DBA не затронуты.
- **Связи и ClearItems**: мягкое удаление заказа на позиции и платежи не распространяется. При жёстком удалении позиции удаляются вместе с заказом, а платежи блокируют удаление (`Restrict`), чтобы финансовые записи не пропадали незаметно. `ClearItems` загружает заказ с позициями, очищает список и сохраняет; EF удаляет оторванные позиции. Для мягко удалённого или несуществующего заказа метод бросает исключение.
