Решения:
- `NotifyCustomers` сделан асинхронным (`Task`, есть `CancellationToken`), потому что `IEmailSender.SendAsync` асинхронный. Входной `IEnumerable` перебирается один раз и сразу собирается в `HashSet`, поэтому дубли id не дают повторных писем.
- Адреса загружаются не отдельным запросом на каждого клиента, а одним запросом на порцию из 5000 id. Npgsql превращает `Contains` в `= ANY(@ids)`. Из базы берётся только `Email`, без отслеживания изменений (`AsNoTracking`). Клиенты, которых нет в базе, и пустые адреса пропускаются.
- В сигнатуре нет темы письма, поэтому тема задана константой `"Shop"`. Сборку и тесты не запускал.
