Создан файл: `CustomerNotifier.cs`

Решения:
- Id из маркетинговой системы дедуплицируются (HashSet) и разбиваются на батчи по 200, чтобы не строить гигантский `IN (...)` и не выбирать всех клиентов сразу.
- Реально существующие клиенты и их email подтверждаются запросом к `ShopDbContext` (внешний список может содержать устаревшие/несуществующие id); письма отправляются только по найденным адресам через `IEmailSender.SendAsync`.
- Тема письма зафиксирована константой, тело — переданный `text`; сборка и тесты не запускались по условию задачи.
