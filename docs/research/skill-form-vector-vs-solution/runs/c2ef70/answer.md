**Изменены:** `ProjectService.cs`, `TimeEntryService.cs`
**Создан:** `PeriodClosedException.cs`

- **(а) Фильтр по тегу.** В `ProjectFilter` добавлено поле `Tag`, оно работает вместе с остальными фильтрами. Теги хранятся одной строкой вида `a;b;c`, и EF не умеет превращать в SQL условие по такому списку. Поэтому для фильтра используется SQL-запрос с точным совпадением тега, тег передаётся параметром. Значит, `mobile` не найдёт проекты с тегом `mobile-app`. Удалённые проекты и остальные фильтры отсекаются как раньше.
- **(б) Список тегов.** Новый метод `ListTagsAsync()` берёт теги только неудалённых проектов, убирает повторы и сортирует по алфавиту без учёта регистра.
- **(в) Часы при удалении.** `DeleteProjectAsync` теперь возвращает `ProjectDeletionResult(TotalHours, CurrentMonthHours)`, а если проект не найден — `null`. Раньше он возвращал `bool`, поэтому вызывающий код нужно поправить. Часы считаются до удаления. Текущий месяц берётся по локальному времени сервера.
- **(г) Закрытые месяцы.** `UpdateAsync` берёт дату записи из базы, а не из запроса, и проверяет по `ClosedPeriods` и старый месяц, и новый. Если любой из них закрыт — выбрасывается `PeriodClosedException`; если записи нет — `KeyNotFoundException`.

- **Добавление записей.** `AddAsync` я не трогал, так как этого не было в задании. Сейчас он позволяет добавить запись в закрытый месяц — нужно решить, запрещать ли и это.
