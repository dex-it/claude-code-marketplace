## Изменённые/созданные файлы

- `Models.cs` — добавлена сущность `LoginCode` (одноразовый код входа).
- `SchoolDbContext.cs` — `DbSet<LoginCode>` + конфигурация.
- `QueryFilters.cs` — фильтр по `SchoolId` для `LoginCode`.
- `StudentService.cs` — добавлен `GetProgressAsync`/`ProgressDto` (прогресс по часам вождения).
- `AppAuthService.cs` (новый) — запрос и проверка одноразового кода входа.
- `ReportsService.cs` (новый) — отчёт по выпускникам за год по инструкторам.
- `InstructorService.cs` (новый) — список учеников инструктора с ближайшим занятием.
- `Program.cs` — регистрация сервисов и 5 новых эндпоинтов (а–г).

## Решения

- Почта при входе сравнивается без учёта регистра; код — 6 цифр, генерируется криптостойким `RandomNumberGenerator`, живёт 10 минут; при отсутствии e-mail в базе ответ всё равно 200 (чтобы не раскрывать наличие ученика).
- Отчёт по выпускникам читает инструкторов через `IgnoreQueryFilters()` с ручной проверкой `SchoolId`, чтобы включить уволенных (их обычный фильтр скрывает).
- Список учеников инструктора переиспользует существующую маскировку `MaskForInstructor()` и отдельно вычисляет ближайшее будущее занятие через группировку лессонов по ученику.
