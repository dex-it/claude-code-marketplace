Готово! Реализованы все требования:

**Созданные/изменённые файлы:**
- **Models.cs** — добавлено `FrozenUntil` в Member
- **ScheduleService.cs** — методы `FreezeAsync`, `UnfreezeAsync`, `GetRandomSessionAsync` и проверка заморозки в `EnrollAsync`
- **TurnstileWorker.cs** — блокировка засчитывания при заморозке
- **Program.cs** — endpoints для freeze/unfreeze и random-session

**Решение:** Заморозка отслеживается через `DateTime? FrozenUntil` в Member. При записи на занятие проверяется, не заморожен ли абонемент на момент начала. При проходе через турникет заморозка блокирует засчитывание (пометка в Note), но запись остаётся "записан". Функция случайного занятия выбирает из ближайших 7 дней и возвращает только активных участников.
