**Решения:**
- Теги лежат в базе одной строкой через `;`, поэтому обычный запрос EF по списку тегов в SQL не переводится. Фильтр (а) сделан через `FromSql` с `tag = ANY(string_to_array("Tags", ';'))`: тег передаётся параметром, совпадение точное, удалённые проекты и остальные фильтры работают как раньше. Список тегов (б) собирается в памяти по неудалённым проектам: повторы убираются, сортировка по алфавиту без учёта регистра.
- (в) Часы считаются до удаления проекта. Текущий месяц определяется по локальному времени сервера.
- (г) `UpdateAsync` теперь загружает запись из базы и проверяет месяц и старой даты, и новой. Ту же проверку я добавил в `AddAsync`, хотя её не просили: без неё в подписанный месяц можно было бы дописать часы. Если это лишнее, проверку можно убрать.
