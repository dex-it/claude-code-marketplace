Создан файл: `CustomerNotifier.cs` (класс `CustomerNotifier` с методом `NotifyCustomers`). Ответ также записан в `_answer.md`.

Решения:
- Список `customerIds` из внешней (маркетинговой) системы дедуплицируется через `Distinct()`, чтобы не отправлять письмо клиенту дважды.
- ID батчатся по 500 (`Chunk`) перед `Contains()`, чтобы не деградировал план запроса на больших списках в PostgreSQL.
- Из БД выбирается проекция только email (`Select`), а не полные `Customer`-сущности — меньше трафика и не раздувается Change Tracker.
