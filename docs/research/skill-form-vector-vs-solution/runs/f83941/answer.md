**Решения:**
- (а) GetDebtorsAsync выбирает активные выдачи филиала с просрочкой, проецирует только нужные поля (LoanRow), вычисляет штраф после сужения выборки, сортирует по штрафам убывающе и возвращает с общей суммой.
- (б) GetLoansByBranchReportAsync конвертирует ISO 8601 даты в UTC, группирует выдачи по BranchId в SQL, загружает имена филиалов отдельным no-tracking запросом, возвращает отчёт с числом выдач по филиалам и суммой.
- (в) Конфигурация Fines (PerDay, GraceDays, Max) вынесена в appsettings.json; LoanService читает её через IConfiguration в конструкторе.
