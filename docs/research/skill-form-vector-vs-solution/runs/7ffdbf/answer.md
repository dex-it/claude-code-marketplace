## Изменённые файлы
- `Models.cs` — сущность `LoginCode`, статический класс `PrivacyMasking` (вынесена маскировка паспорта/e-mail, использует её и старый `MaskForInstructor`).
- `SchoolDbContext.cs` — `DbSet<LoginCode>` + маппинг.
- `QueryFilters.cs` — фильтр по `SchoolId` для `LoginCode`.
- `Program.cs` — DI-регистрации и 5 эндпоинтов из задания.

## Новые файлы
- `AppService.cs` — `AppLoginService` (запрос/подтверждение кода) и `StudentProgressService` (прогресс по часам).
- `ReportsService.cs` — отчёт по выпускникам за год по инструкторам (включая уволенных).
- `InstructorAppService.cs` — текущие ученики инструктора + дата ближайшего занятия.

## Решения
- Код хранится как SHA-256 хеш, запрос кода не раскрывает наличие e-mail в системе; подтверждение ограничивает число попыток подбора кода.
- Сравнение e-mail — через `EF.Functions.ILike` (транслируется в SQL, в отличие от `.ToLower()`), с детерминированным выбором строки вместо `Single`, так как регистронезависимое совпадение не гарантировано уникальным схемой.
- Отчёт считает агрегаты в SQL; уволенные инструкторы получены через `IgnoreQueryFilters()` с ручным восстановлением фильтра по `SchoolId`. Миграция для `LoginCode` не создавалась — в репозитории нет `.csproj`/`Migrations`, а запуск `dotnet ef` был вне разрешённых действий.
