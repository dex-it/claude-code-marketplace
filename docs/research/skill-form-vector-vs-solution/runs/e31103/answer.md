## Решение
Метод `NotifyCustomers` дедублирует входящий список (правило "Дубли во входном списке id"), выполняет один запрос к БД с проекцией только Email (правило "Полная сущность для списка"), а затем отправляет письма в цикле. Это избегает запросов в цикле и неэффективной передачи полных сущностей, соблюдая правила команды из SKILL.md.
