Сортировка по штрафу (сначала самые большие) и общая сумма `TotalFine` считаются уже после загрузки из базы, потому что формулы штрафа в SQL не переводятся. В базе отбираются только невозвращённые книги этого филиала с истёкшим сроком. Дети-должники в списке остаются, но со штрафом 0.
- **(б)** `POST /reports/loans-by-branch` переводит `from` и `to` в UTC до запроса, потому что Npgsql не принимает время со смещением +05:00 для столбца `timestamptz`. Период считается как `[from, to)`: `to` не входит. Филиалы без выдач попадают в отчёт с нулём. Если `from` или `to` нет либо `from >= to`, возвращается 400.
- **(в)** Ставка, льготный период и потолок читаются из секции `Fines` в `appsettings.json` (`PerDay`, `GraceDays`, `Max`). Значения по умолчанию прежние: 10 / 3 / 500. При отрицательном значении в конфиге приложение не запустится. Старую константу `FineRules.Default` я удалил.
