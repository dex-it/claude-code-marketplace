Решения:
- Метод `NotifyCustomers` сделан асинхронным и возвращает `Task<int>` — количество отправленных писем, потому что `IEmailSender.SendAsync` асинхронный. Тема письма задана константой: в сигнатуре есть только `text`.
- Список из маркетинговой системы перебирается один раз, и из него сразу убираются дубли (`Distinct().ToArray()`), чтобы клиент не получил письмо дважды. Id, которых нет в базе, и клиенты с пустым email пропускаются.
- Клиенты читаются пачками по 5000 — один запрос на пачку, а не на каждого клиента. В EF Core 8 / Npgsql `Contains` передаётся одним параметром-массивом (`= ANY(@ids)`). Из базы берутся только `Id` и `Email`. Пачка загружается целиком до начала отправки, поэтому соединение с БД не занято, пока идут письма.
- Ошибки отправки не перехватываются. Если отправка упадёт на середине, часть писем уже уйдёт, и при повторном запуске эти клиенты получат письмо ещё раз.
