Решения:
- Список id из маркетинговой системы дедуплицирован (`Distinct()`) и разбит батчами по 500 (`Chunk`) — защита от деградации плана запроса на больших `IN(...)` в PostgreSQL.
- Загружается не вся сущность `Customer`, а только `Email` через `.Select()` — проекция в SQL, один запрос на батч вместо N запросов в цикле.
- Guard на пустой список id — выходим без обращения к БД.
