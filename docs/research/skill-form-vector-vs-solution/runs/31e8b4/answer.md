## Решения

- Email ищется без учёта регистра (`.ToLower()`); код хранится только в виде SHA-256-хэша с TTL 10 минут; ответ на `login/request` всегда 200, чтобы не раскрывать наличие карточки.
- Авторизации (JWT/сессий) в проекте нет нигде — следуя стилю кода (инструктор тоже просто передаётся заголовком), `login/confirm` возвращает `{StudentId, FullName}`, который приложение использует как идентификатор дальше.
- Отчёт по выпускникам получает инструкторов через `IgnoreQueryFilters()` с ручным фильтром по `SchoolId`, чтобы не терять уволенных сотрудников.
