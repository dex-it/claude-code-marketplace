## Решения

- (а) карточка заказа — одна сущность, поэтому `Include`×2 без `AsSplitQuery` (JOIN дешевле доп. round-trip'а); `AsNoTracking`, т.к. read-only.
- (б) выгрузка заказов клиента — при тысячах заказов два `Include` дают cartesian explosion, поэтому добавлен `AsSplitQuery`; фильтр по `CustomerId` до материализации.
- (в) `GetProductBySkuAsync` — SKU уникален только в рамках склада, а склад может быть `null`; вместо слепого `Single()` беру `Take(2)` и явно бросаю исключение, если без склада нашлось больше одной записи, — неоднозначность не скрывается.
- (г) `GetLastShippedAtAsync` — `MAX(ShippedAt)` считается в SQL с предварительным `WHERE ShippedAt != null`; поскольку возврат не-nullable `DateTime`, при отсутствии отгруженных заказов бросается явное исключение вместо фиктивного значения.
