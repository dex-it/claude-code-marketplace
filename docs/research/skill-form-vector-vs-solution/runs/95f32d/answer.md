Решения:
- **Входной список:** один раз перевожу его в `HashSet<Guid>`. Это убирает дубликаты, так что каждый клиент получает одно письмо. Заодно список, который может приходить с отложенным чтением, перебирается только один раз.
- **Запросы к БД:** email беру пачками по 500 id через `Chunk(500)`, по одному запросу `WHERE Id IN (...)` на пачку. Отдельного запроса на каждого клиента нет, выбирается только колонка `Email`. Неизвестные id и пустые адреса пропускаются без ошибки.
- **Асинхронность и тема письма:** метод асинхронный (`Task NotifyCustomers(..., CancellationToken ct = default)`), потому что `IEmailSender.SendAsync` асинхронный. Тема письма в задаче не была указана, поэтому пока это константа `"Shop"` — её стоит заменить на нужную.
