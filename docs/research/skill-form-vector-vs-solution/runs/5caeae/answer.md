## Решения

- **(а)** Поиск по e-mail без учёта регистра, транслируется в SQL; при 0 или >1 совпадений карточка не выбирается наугад (чек-лист EF про `Single` на неуникальном условии), ответ одинаков для существующей/несуществующей почты. Код хранится как SHA-256 хеш и помечается `ConsumedAt` после использования.
- **(б)** Отчёт снимает `IgnoreQueryFilters()` у `Instructor`/`Student` (чтобы не терять уволенных), но вручную возвращает условие по `SchoolId`; группировка и `Count` — на уровне SQL, а не после материализации.
- **(в)** Чтение проекцией нужных полей без трекинга, ближайшее занятие — коррелированный подзапрос `MIN(StartsAt)` в БД; маскирование e-mail/паспорта вынесено в общий класс `Mask`, чтобы вид карточки совпадал с CSV-выгрузкой для инструктора.
- **(г)** Сумма минут `Done`-занятий считается агрегатом в БД (`SumAsync`), 56 часов — константа сервиса.
