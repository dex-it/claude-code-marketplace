Реализовал все четыре пункта. Сборку и тесты не запускал, как просили.

**Созданные файлы:**
- `AppAuthService.cs` — запрос/проверка одноразового кода входа (а)
- `ReportService.cs` — отчёт по выпускникам за год (б)
- `InstructorAppService.cs` — список учеников инструктора с ближайшим занятием (в)

**Изменённые файлы:**
- `Models.cs`, `SchoolDbContext.cs`, `QueryFilters.cs` — новая сущность `LoginCode` (хранит только хэш кода) + tenant-фильтр
- `StudentService.cs` — `GetProgressAsync` для (г)
- `Program.cs` — DI-регистрации и 5 новых эндпоинтов

**Ключевые решения:** код входа хранится как SHA-256-хэш, сравнение через `FixedTimeEquals`, старые активные коды инвалидируются `ExecuteUpdateAsync`; поиск ученика по e-mail регистронезависимый через `SingleOrDefaultAsync` (коллизия падает явно, не выбирается молча); отчёт по уволенным инструкторам использует `IgnoreQueryFilters` с ручным условием по `SchoolId`, агрегация выпускников — в БД до материализации; список учеников инструктора собирается двумя пакетными запросами без N+1.
