## Решения

Сортировка строится не из произвольной пользовательской строки, а через `switch` по enum-парам в жёстко заданные SQL-фрагменты (защита от инъекции при сохранении сортировки на уровне БД для пагинации). Для 409 при закрытии заявки введено доменное исключение `RequestStatusConflictException`, транслируемое эндпоинтом в HTTP. Замена плана дома использует явный `_db.PlanItems.RemoveRange(...)` (а не удаление из коллекции), так как в контексте включён `CascadeTiming.Never` для другого сценария (`MergePlansAsync`) — совпавшие по коду работы обновляются на месте без потери `Id`/истории, остальные удаляются вместе с историей.

Важно: в каталоге нет `Program.cs` и миграций EF — новые поля модели потребуют `dotnet ef migrations add`, которую не создавал и не запускал (нужна сборка).
