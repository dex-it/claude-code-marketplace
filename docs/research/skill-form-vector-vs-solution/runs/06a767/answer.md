## Решения

- **Фильтр по тегу.** Теги хранятся одной строкой через `;`, поэтому обычный LINQ-фильтр по ним не превращается в SQL. Фильтр сделан через `FromSql` с параметром: тег сравнивается точно, SQL-инъекция исключена. Скрытие удалённых проектов и остальные фильтры работают как раньше.
- **Список тегов.** Собирается в памяти по неудалённым проектам. Повторы убираются по точному значению, как в фильтре; сортировка по алфавиту без учёта регистра.
- **Удаление проекта.** Часы считаются до удаления: всего и за текущий месяц. Месяц определяется по времени сервера (`DateTime.Today`).
- **Правка записи времени.** `UpdateAsync` больше не перезаписывает запись из DTO: он загружает её из базы, иначе не узнать старую дату. Если записи нет, теперь будет `KeyNotFoundException`.
