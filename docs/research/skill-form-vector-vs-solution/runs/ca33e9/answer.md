## Решения

- **(а)** E-mail сравнивается без учёта регистра. Если таких карточек несколько, код не отправляется: уникальный индекс в базе учитывает регистр, и такие дубли возможны. В базе хранится только хеш кода. Код одноразовый, на него даётся 5 попыток, повторно его можно запросить не раньше чем через минуту. Ответ на запрос кода одинаковый для известных и неизвестных адресов.
- **Токен входа (сверх поручения).** После проверки кода выдаётся токен сессии. `/api/app/progress` требует `Authorization: Bearer <токен>` и отдаёт прогресс только своего ученика. Без этого любой мог бы смотреть чужой прогресс, просто подставив `studentId`.
- **(б)** Уволенных инструкторов скрывает глобальный фильтр, поэтому он снят через `IgnoreQueryFilters`. Это снимает и фильтр по автошколе, поэтому условие `SchoolId` возвращено явно.
- **(в)** `MaskForInstructor` меняет саму запись ученика, а после каждого запроса к API изменения автоматически сохраняются в базу. Без `AsNoTracking` скрытые паспорт и почта записались бы в базу вместо настоящих. Поэтому запрос идёт без отслеживания, а в CSV-выгрузку `AsNoTracking` добавлен для страховки.
- **Ближайшее занятие в (в)** — будущее, ещё не отмеченное Done, и только с этим инструктором. Время отдаётся в UTC.
