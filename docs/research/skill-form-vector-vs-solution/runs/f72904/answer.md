## Решения

- **Сортировка**: Динамический ORDER BY в SQL с поддержкой date/address/status и направления asc/desc (по умолчанию date desc)
- **Закрытие заявки**: CloseRequestAsync проверяет статус InProgress, устанавливает Done с комментарием; иначе выбрасывает исключение
- **Обновление плана**: UpdatePlanAsync удаляет работы которых нет в новом списке, обновляет параметры существующих, добавляет новые; история PlanItemCompletion не затрагивается
- **Телефон**: Опциональное поле PhoneNumber; диспетчер заполняет при приёме, мастер видит в карточке заявки
