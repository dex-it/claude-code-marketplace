## Изменённые файлы
- `Models.cs` — у `Member` добавлено поле `FrozenUntil` (UTC, nullable).
- `ScheduleService.cs` — исключение `MembershipFrozenException`; в `EnrollAsync` проверка заморозки на момент начала занятия.
- `TurnstileWorker.cs` — при заморозке абонемента проход не засчитывает занятие, в `Note` пишется «абонемент заморожен».
- `Program.cs` — регистрация сервисов, endpoints `POST/DELETE /members/{id}/freeze`, `GET /quality/random-session`, 409 при заморозке в `/sessions/{id}/enroll`.

## Новые файлы
- `MembersService.cs` — заморозка на N дней и досрочное снятие.
- `QualityService.cs` — выбор случайного занятия из ближайших 7 дней с деталями и записавшимися (без отменённых).

## Решения
Заморозка — одно поле `FrozenUntil` на `Member` (текущий статус = дата окончания); проверки — простое сравнение времени. Случайное занятие выбирается в два шага (список id → деталь по одному id), чтобы не грузить лишние данные и не искажать выбор материализацией всей выборки. Миграция для новой колонки не создана: в каталоге нет `csproj`/`Migrations`, а запускать EF-тулинг/сборку нельзя — это отражено в примечании.
