- `Program.cs`: эндпоинты `POST /checkin`, `GET /reports/workshops`, `GET /events/{id}/program`; в запросы добавлены поля `Company` и `EventId`.
- `_answer.md`: этот же ответ.

Решения:
- **Отметка прихода (/checkin):** e-mail уникален только внутри одного мероприятия, а в один день их может быть несколько. Поэтому регистрацию ищу среди мероприятий текущего дня по часовому поясу сервера, можно передать и `eventId`. Если подходит несколько регистраций — ответ 409 со списком мероприятий, если ни одной — 404. Время прихода записывается только при первой отметке; повторная отметка просто возвращает данные для бейджа.
- **Отчёт по выручке:** выборка по дате оплаты внутри квартала, группировка по залам. Запрос идёт без фильтра удалённых залов: иначе оплаты воркшопов в выведенных из эксплуатации залах молча выпали бы из отчёта. Такие залы отмечены в ответе отдельным флагом.
- **Текущая программа:** в `PublishedOn` хранится только дата, а за день бывает несколько публикаций. Поэтому последнюю версию определяю по дате, а при совпадении — по `Id`. Пункты отсортированы по времени начала; если программы нет — 404.

Для поля `Company` нужна миграция базы данных: в проекте их нет, и я её не создавал.
