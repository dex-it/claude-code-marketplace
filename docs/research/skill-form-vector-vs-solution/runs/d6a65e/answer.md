Решения:
- **Дубли:** входной список проходится один раз, повторяющиеся id убираются до отправки. Каждый id получает одно письмо. Пустой список сразу завершает метод.
- **Запрос к БД:** адреса клиентов загружаются одним запросом, только поле email. Весь список id уходит в запрос одним параметром, на пачки он не делится. В цикле обращений к базе нет.
- **Подпись метода:** `IEmailSender` отправляет письма асинхронно, поэтому метод тоже асинхронный: возвращает `Task` и принимает необязательный `CancellationToken`. Тема письма в поручении не указана, я поставил `"Shop"`. Письма уходят по очереди. Если одна отправка упадёт, рассылка остановится на этом клиенте.
