**Решение:**

Создан сервис `OrderQueries` с методами для работы с заказами:
- **GetOrderCardAsync** — загружает заказ со всеми позициями и платежами, используя `AsSplitQuery()` для эффективной загрузки двух коллекций
- **GetCustomerOrdersAsync** — выгружает все заказы клиента с позициями/платежами, оптимизирована для больших объемов данных через `AsNoTracking()` и split query
- **GetProductBySku** — ищет по SKU, опционально фильтруя по складу (если warehouse null, возвращает первый найденный)
- **GetLastShippedDateAsync** — возвращает дату отгрузки последнего отгруженного заказа клиента, или `DateTime.MinValue` если нет отгруженных

Все методы следуют чек-листу SKILL.md: `AsNoTracking()` для читаемых выборок, split query для избежания N+1 при нескольких Include.
