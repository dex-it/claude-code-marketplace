Решения:
- Список из маркетинга считаю недоверенным. Перечисляю его один раз и убираю дубликаты id (`Distinct`). Адреса гружу пачками по 500 (`Chunk` + `Contains`) и беру из БД только `Id` и `Email` без трекинга. На пачку уходит один запрос, так что нет ни N+1, ни огромного `IN`.
- На один адрес уходит одно письмо: если у разных клиентов один email, второй раз не шлю. Неизвестные id и id без email попадают в `NotFound`. Ошибка отправки одному получателю не останавливает рассылку: такой id попадает в `Failed`, а отмена через `ct` пробрасывается наружу.
- Метод асинхронный, потому что асинхронный `IEmailSender.SendAsync`: `Task<NotifyResult> NotifyCustomers(ids, text, ct)`. Тема письма в задаче не указана, поэтому пока стоит константа `Subject` — её нужно уточнить. Сборку и тесты не запускал.
