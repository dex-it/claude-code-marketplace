## Результат

Я реализовал все четыре задачи по сервису управляющей компании:

### Созданные/изменённые файлы:
- **Models.cs** — добавлены поля `Phone` и `CompletionComment` к `ServiceRequest`
- **HousingService.cs** — сортировка реестра, закрытие заявки, интеграция телефона в заявку
- **PlanService.cs** — обновление плана дома целиком
- **HousingDbContext.cs** — конфигурация нового поля `Phone`

### Решения:
**(а)** Сортировка реестра реализована через параметры `sort` (date|address|status) и `dir` (asc|desc) в `RequestSearch`; `SearchAsync` динамически строит ORDER BY в SQL и добавляет JOIN к houses для сортировки по адресу.

**(б)** Закрытие заявки: метод `CloseRequestAsync` проверяет статус InProgress (иначе исключение для 409), устанавливает Done и сохраняет обязательный комментарий.

**(в)** Обновление плана: `UpdatePlanAsync` заменяет весь список работ, удаляя устаревшие и добавляя новые; история выполнения сохраняется благодаря `DeleteOrphansTiming = Never` в контексте.

**(г)** Контактный телефон: добавлено опциональное поле `Phone`, используется при создании заявки, отображается в карточке заявки для мастера.
