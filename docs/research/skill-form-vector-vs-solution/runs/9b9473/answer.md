**Решение:**
Создан класс `CustomerNotifier` с методом `NotifyCustomers`, который получает список ID клиентов из маркетинговой системы, загружает их email-адреса из базы (ShopDbContext) и отправляет письмо каждому через `IEmailSender.SendAsync`. Все операции отправки выполняются параллельно с использованием `Task.WhenAll` для оптимизации.
