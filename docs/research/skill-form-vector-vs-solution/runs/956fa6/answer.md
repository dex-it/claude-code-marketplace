## Решения
- **(а)** Почта сопоставляется регистронезависимо через `EF.Functions.ILike` (транслируется в SQL), а не `SingleOrDefault` — при неоднозначном совпадении код просто не шлётся, ответ всегда `200 OK`, чтобы не раскрывать наличие e-mail; код хранится как SHA-256 хеш с TTL 10 мин и счётчиком попыток.
- **(б)** Группировка/агрегат выполняются в БД; уволенные инструкторы получены отдельным запросом с `IgnoreQueryFilters()` только для `Instructor`, при этом изоляция по школе возвращена вручную, чтобы не ослабить tenant-фильтр `Student`.
- **(в)** Один транслируемый запрос с коррелированным подзапросом по занятиям (без N+1, `AsNoTracking`); маскирование — после материализации над DTO, а не над отслеживаемой сущностью.
- **(г)** Часы считаются `SUM(Minutes)` по занятиям `Done=true` в БД, конвертация в часы — на клиенте.
