Файлы:
- `CustomerNotifier.cs` (новый): `CustomerNotifier.NotifyCustomers(IEnumerable<Guid> customerIds, string text, CancellationToken ct = default)` возвращает `Task<NotifyResult>`.
- `_answer.md` (новый): этот же ответ.

Решения:
- Список из маркетинговой системы может быть большим и с повторами. Поэтому он читается потоково, повторы id и email отбрасываются, а клиенты загружаются пачками по 1000 одним запросом `Id = ANY(@ids)`. Из базы берутся только `Id` и `Email`, с `AsNoTracking`, без отдельного запроса на каждого клиента.
- Неизвестные id и пустые email пропускаются. Если отправка на один адрес падает, рассылка продолжается. Результат возвращается в `NotifyResult` (`Sent`/`NotFound`/`Failed`), а отмена через `ct` прерывает рассылку.
- Метод асинхронный, потому что `IEmailSender` асинхронный. Сигнатура не задаёт тему письма, поэтому она пока константа `Subject = "Shop"`; стоит заменить на нужную.
