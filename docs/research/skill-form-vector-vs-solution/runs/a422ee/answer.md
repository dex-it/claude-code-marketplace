Решения:
- (а)/(б): `Include(Items).Include(Payments)` даёт декартово произведение двух коллекций, поэтому обе выборки идут с `AsSplitQuery()` и `AsNoTracking()`. В (б) фильтрация по `CustomerId` — напрямую по `Orders`, а не через навигацию `Customer.Orders`, что важно при тысячах заказов у клиента.
- (в) `GetProductBySku`: SKU уникален только в паре со складом, поэтому `Single` по одному SKU не используется. Если склад передан — `SingleOrDefaultAsync` по (sku, warehouse); если `null` — ищем по SKU и явно проверяем неоднозначность (`Take(2)`), выбрасывая понятное исключение вместо случайного результата.
- (г) `GetLastShippedAtAsync`: фильтр `ShippedAt != null` стоит до сортировки/выборки (без слепого `!`). Возврат non-nullable `DateTime` — отсутствие отгрузок у клиента выражено исключением, а не суррогатным значением.
