Решения:
- Входной список id читается один раз. Дубли убираются до обработки, так что на один id уходит одно письмо. Если список пустой, метод сразу выходит.
- Email-адреса загружаются одним запросом `ids.Contains(c.Id)`, без разбиения на пачки: в EF Core 8 + Npgsql весь список уходит одним параметром (`Id = ANY(@p)`). Запрос берёт только `Email`, а не клиента целиком, и в цикле к базе не обращается.
- Метод возвращает `Task`, потому что `IEmailSender` асинхронный; название осталось как в задаче, без суффикса `Async`. Письма отправляются по одному. Тема письма в сигнатуре не задана, поэтому я поставил константу `"Shop"`. Id, которых нет в базе, молча пропускаются.
