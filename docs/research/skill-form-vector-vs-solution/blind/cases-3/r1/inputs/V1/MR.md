# MR !214: онлайн-бронирование мест у причала с депозитом

## Зачем

Сейчас судовладельцы бронируют место через диспетчера по телефону, депозит переводят по реквизитам,
а диспетчер вручную сверяет выписку. Этот MR даёт владельцам самостоятельную бронь с оплатой
депозита картой и автоматическим подтверждением.

## Что сделано

- `POST /api/bookings` — владелец бронирует место под своё судно на даты заезда и выезда.
  Стоимость считается по тарифу места: ставка за метр длины судна в сутки, тарифицируется каждый
  начатый метр. На части мест летом действуют сезонные ставки (`SeasonalRates`), в остальные дни -
  базовая ставка места. При стоянке от 7 ночей скидка 10 %. В ответе - ссылка на оплату депозита
  (30 % от стоимости).
- Заезд с 14:00, выезд до 12:00 по местному времени марины, поэтому в день выезда одной яхты место
  можно отдать следующей - так диспетчеры работают и сейчас.
- Параллельные брони одного места идут по очереди: в транзакции берём блокировку строки места
  (`FOR UPDATE`), проверяем занятость и только потом вставляем бронь.
- `POST /api/payments/webhook` — вебхук платёжного провайдера. Когда оплачен депозит, бронь
  переходит в `Confirmed`. Провайдер доставляет события по схеме at-least-once: повторяет отправку,
  пока не получит 2xx, и при сетевых сбоях может прислать одно и то же событие ещё раз.
- `POST /api/bookings/{id}/cancel` — отмена. Если до заезда остаётся не меньше 48 часов, возвращаем
  внесённый депозит полностью, иначе депозит остаётся у марины. Отменить может владелец брони или
  начальник порта.
- `GET /api/bookings` — список броней. Владелец видит только свои брони (можно сузить до одного
  своего судна через `?vesselId=`), начальник порта видит все.
- `GET /api/berths/{id}/calendar` — публичный календарь занятости места для сайта марины, без
  авторизации: показывает, какие даты заняты.
- Optimistic concurrency для брони через `xmin`, чтобы вебхук и отмена не затирали друг друга.

Миграция будет отдельным MR после ревью модели.
