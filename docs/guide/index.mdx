Памятки по стекам, агенты-специалисты и готовые команды: ревью, поиск причины бага, фича от требований до кода. Ставите только нужное: набором под роль или по одному плагину.

## С чего начать

Выберите задачу. Для каждой есть бандл (набор плагинов) и команда, с которой начинается работа.

<CardGrid>
  <Card title="Проверить ветку перед push" icon="approve-check">
    Бандл `code-review`, команда `/dex-self-reviewer:self-review`. Claude реально прогонит сборку и тесты и выдаст чеклист правок.

    [Как это работает](/scenarios/review-before-push/)
  </Card>
  <Card title="Отревьюить чужой MR или PR" icon="pencil">
    Бандл `code-review`, команда `/dex-mr-reviewer:mr-review`. Находки приходят инлайн-тредами в MR или PR.

    [Как это работает](/scenarios/review-others/)
  </Card>
  <Card title="Найти причину бага" icon="magnifier">
    Бандл `bug-lifecycle`, команда `/dex-debugger:root-cause`. Красный тест, изоляция, проверка гипотезы.

    [Как это работает](/scenarios/find-bug/)
  </Card>
  <Card title="Отдать задачу целиком" icon="rocket">
    Бандл `auto`, команды `/dex-auto:goal` и `/dex-auto:auto`: от цели до коммитов и PR.

    [Как это работает](/scenarios/auto/)
  </Card>
</CardGrid>

## Как выглядит работа

Подключить каталог и поставить набор:

```bash
claude plugin marketplace add dex-it/claude-code-marketplace
git clone https://github.com/dex-it/claude-code-marketplace.git
cd claude-code-marketplace
./install-bundle/install-bundle.sh code-review
```

Запустить в своём проекте:

```text
/dex-self-reviewer:self-review
```

Подробный разбор шагов - в [быстром старте](/start/). Устройство каталога и взаимодействие уровней - в разделе [Как это устроено](/concepts/).
