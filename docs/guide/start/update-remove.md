## Обновление

Каталог, добавленный не из репозиториев Anthropic, по умолчанию не обновляется автоматически: Claude Code не обновляет такие каталоги сам, пока вы не включите автообновление на вкладке «Marketplaces» в `/plugin`. Поэтому обновляйте вручную.

Освежить списки каталогов:

```bash
claude plugin marketplace update
```

Без имени команда освежает списки всех подключённых каталогов, но установленные плагины остаются на своих версиях. Обновить конкретный плагин:

```bash
claude plugin update dex-mr-reviewer@dex-claude-marketplace
```

Новая версия применяется после перезапуска Claude Code. Обновить все плагины каталога разом можно из сессии: `/plugin`, вкладка «Marketplaces», выбрать каталог и «Update marketplace».

Скрипт `install-bundle` версии не трогает: он доставляет только недостающие плагины.

## Что поставлено и чего не хватает

```bash
claude plugin list                          # установленные плагины
./install-bundle/sync-plugins.sh            # у каких поставленных агентов нет нужных skills
./install-bundle/sync-plugins.sh --fix      # поставить недостающие skills
```

`sync-plugins.sh` смотрит на то, что поставлено у вас, а не на бандлы. Он докладывает недостающие skills и специалистов; `--fix` ставит только skills, новых специалистов не добавляет: что добавлять, решаете вы. Запускать его нужно из клона репозитория.

## Удаление

Бандл целиком:

```bash
./install-bundle/uninstall-bundle.sh code-review --dry-run   # что будет удалено
./install-bundle/uninstall-bundle.sh code-review
```

Один плагин:

```bash
claude plugin uninstall dex-dotnet-coder
```

:::caution[Общие плагины]
Удаление бандла убирает все его плагины, в том числе те, что входят и в другой ваш бандл. Скрипт не проверяет, нужен ли плагин остальным. Если у вас поставлено несколько бандлов, после удаления одного поставьте оставшиеся заново: уже поставленные плагины скрипт пропускает, недостающие вернёт.
:::

## Снятые и переименованные плагины

Установщики снятые плагины не удаляют: переименованный или снятый плагин остаётся у вас и продолжает загружаться по имени. Такие плагины удаляются вручную через `claude plugin uninstall`. Что снято и чем заменено - в таблице «Renamed and removed plugins» файла [install-bundle/README.md](https://github.com/dex-it/claude-code-marketplace/blob/main/install-bundle/README.md).

## Убрать каталог

```bash
claude plugin marketplace remove dex-claude-marketplace
```

Claude Code удалит и все плагины, поставленные из этого каталога.
