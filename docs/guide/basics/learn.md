## Курс Claude 101

[Claude 101](https://anthropic.skilljar.com/claude-101) - бесплатный вводный курс Anthropic Academy с сертификатом. Нужна бесплатная регистрация на площадке Skilljar. По программе (сверено 23.10.2026) он идёт модулями:

- знакомство: что такое Claude, первый разговор, как получать лучшие ответы, работа на десктопе;
- организация работы: проекты, артефакты, skills;
- расширение возможностей: подключение инструментов (коннекторы), поиск по корпоративным данным, исследование;
- сценарии по ролям и другие способы работы.

Курс рассказывает о продукте Claude для повседневных задач. О терминальном Claude Code в программе отдельных уроков не видно, поэтому для работы с каталогом он даёт общую подготовку (как формулировать задачу, что такое проект и skill), а не инструкцию к плагинам. Это вывод по оглавлению: содержание уроков за регистрацией мы не читали.
