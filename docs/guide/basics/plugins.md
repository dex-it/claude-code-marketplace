Плагин - каталог с компонентами (skills, агенты, хуки, MCP-серверы, команды), который Claude Code ставит и загружает как одно целое. Маркетплейс - репозиторий или папка с файлом `.claude-plugin/marketplace.json`, где перечислено, какие плагины есть и откуда их брать. Это каталог, а не магазин с хостингом. Источники: [Plugins](https://code.claude.com/docs/en/plugins), [Create a marketplace](https://code.claude.com/docs/en/plugin-marketplaces), сверено 23.10.2026.

:::note[Не путать]
Маркетплейс плагинов Claude Code, который вы подключаете командой `marketplace add`, - не то же, что сайт Claude Marketplace на claude.com. Сайт подключить командой нельзя. AI KIT - маркетплейс в первом смысле.
:::

## Как устроен плагин

```text
my-plugin/
├── .claude-plugin/plugin.json     манифест: имя, версия, описание
├── skills/review/SKILL.md         запускается как /my-plugin:review
├── agents/reviewer.md             специалист
├── hooks/hooks.json               хуки на события
└── .mcp.json                      MCP-сервер
```

Из компонентов нужны только те, что есть в плагине. Skills, агенты, хуки и MCP-серверы работают и без плагина: положите skill в `~/.claude/skills/`, и он доступен везде. Плагин нужен, когда надо упаковать несколько вещей вместе, раздать команде или версионировать.

## Как устроен маркетплейс

Файл `marketplace.json` требует `name`, `owner` и список `plugins`. У каждой записи обязательны `name` и `source` (путь от корня маркетплейса или внешний источник: GitHub-репозиторий, подкаталог репозитория и другие). Имя записи должно совпадать с `name` в `plugin.json` плагина: если не совпало, установка по имени из манифеста не найдёт плагин.

Запись плагина `dex-mr-reviewer` в этом каталоге (сокращено):

```json
{
  "name": "dex-mr-reviewer",
  "source": "./plugins/specialists/review/dex-mr-reviewer",
  "version": "3.4.5",
  "category": "specialist"
}
```

Сам каталог называется `dex-claude-marketplace`, а лежит в репозитории `dex-it/claude-code-marketplace`. Подключают по адресу репозитория, ставят по имени каталога:

```bash
claude plugin marketplace add dex-it/claude-code-marketplace
claude plugin install dex-mr-reviewer@dex-claude-marketplace
```

Формат `имя@каталог` и есть идентификатор установки. Проверить свой маркетплейс до публикации можно командой `claude plugin validate <путь>`.

## Области установки

| Область | Для кого включён плагин |
|---|---|
| user (по умолчанию) | для вас, во всех проектах на этой машине |
| project | для всех в репозитории, через `.claude/settings.json`; каждый всё равно ставит плагин у себя |
| local | для вас, только в этом репозитории |

Выбирается флагом `--scope` у `claude plugin install`. Скрипты `install-bundle` область не меняют и ставят в user: [Установка](/start/install/).

## Во что обходится включённый плагин

Включённый плагин присутствует в каждой сессии. Для каждого skill, агента и команды, которые Claude может вызвать сам, название и описание лежат в контексте на каждом ходу, даже если плагин не использовался. Полный текст загружается по требованию. Посмотреть состав и оценку: `claude plugin details <имя>`; выключить без удаления: `claude plugin disable <имя>`.

## Обновления

Маркетплейс не из репозиториев Anthropic по умолчанию сам не обновляется: списки освежает `claude plugin marketplace update`, а плагин - `claude plugin update имя@каталог`. Подробно для AI KIT: [Обновление и удаление](/start/update-remove/).

## Ограничения и ошибки

- **Плагин исполняется с вашими правами.** Хуки и MCP-серверы плагина запускаются от вашего имени. Читайте, что ставите, особенно из чужих каталогов.
- **Установка плоская.** Плагин не подтягивает другие плагины сам. Поэтому в AI KIT есть [бандлы](/concepts/bundles/): специалист приезжает вместе со skills.
- **Зарезервированные имена.** Имена официальных маркетплейсов Anthropic, например `claude-plugins-official`, чужому каталогу взять нельзя.
