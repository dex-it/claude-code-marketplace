## Куда и откуда

Ветку создаёте от `develop`, Pull Request открываете в `develop`. Изменения доходят до `main` отдельным слиянием.

В истории репозитория принят формат сообщений коммитов вида `тип(область): суть`, например `docs(readme): ...`, `fix(плагин): ...`, `test(...)`.

## Что проверить до открытия

- [Проверки](/contributing/checks/) зелёные: `npm run validate`, `npm test`, `npm run test:tools`.
- Версии плагина и каталога подняты и синхронизированы: [Версии](/contributing/versions/).
- Новый или переименованный плагин назван в витрине README.
- Снятый плагин - строка в таблице снятых.

## Что произойдёт

На Pull Request запускается проверка `Validate Plugins`: все валидаторы каталога, тесты правил, типы и тесты модов. Эти проверки обязательны, поэтому на этот workflow не стоит фильтра по путям.

Опишите в Pull Request, что изменилось и почему, и как проверено. Если снимаете или переименовываете плагин, добавьте строку про ручное снятие у тех, кто уже поставил плагин.
