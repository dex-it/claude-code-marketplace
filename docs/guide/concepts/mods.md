Skill, специалист и команда меняют то, что читает модель. Мод меняет то, что делает и показывает сам Claude Code.

## Что это

Мод - плагин, поведение которого несёт модуль **function hooks**: TypeScript, который исполняется внутри процесса клиента. Он может рисовать строки над вводом и панели, показывать тосты, перехватывать события и регистрировать собственные команды.

Моды каталога:

- `dex-github-pr-tracker` - pull request текущей ветки: состояние, проверки, вердикт ревью, треды и коммиты строкой над вводом и панелью `/pr`.
- `dex-gitlab-mr-tracker` - то же для merge request GitLab, панель `/mr`.
- `dex-jira-tracker` - задачи Jira через jira-cli: в работе, открытые, мои, новые комментарии и смены статуса строкой над вводом и панелью `/jira`; от задачи кнопками постановка, взятие в работу и сдача PR/MR командами каталога.
- `dex-session-dispatcher` - одно окно для всех сессий Claude Code на машине: кто работает, кто ждёт ответа, кто закончил.

Подробности и установка: [Моды в каталоге](/catalog/mods/).

## Что важно знать

- **Ранний доступ.** API модов может меняться между релизами Claude Code без предупреждения.
- **Версия клиента.** Нужен Claude Code 2.1.287 или новее; на более старых версиях мод ставится «пустым» и ничего не делает.
- **Адресная установка.** Моды в бандлы ролей не входят: их ставят по решению разработчика.
- **Мод и утилита.** Утилита запускает отдельный процесс на событие или команду и возвращает текст. Мод работает внутри клиента и может менять интерфейс. В каталоге один плагин не бывает и тем и другим.

Устройство мода для авторов: [MOD_FRAMEWORK.md на GitHub](https://github.com/dex-it/claude-code-marketplace/blob/main/docs/MOD_FRAMEWORK.md). Сравнение с хуками-командами и Agent SDK: [EXTENSION_MECHANISMS.md на GitHub](https://github.com/dex-it/claude-code-marketplace/blob/main/docs/EXTENSION_MECHANISMS.md).

## Пример

```bash
claude plugin install dex-github-pr-tracker@dex-claude-marketplace
```

Откройте сессию в клоне репозитория GitHub, где у ветки есть PR. Над полем ввода появится строка с состоянием PR, проверками и вердиктом ревью. Команда `/pr` откроет панель с тредами, `/pr threads` выпишет открытые треды текстом, `/pr checks` покажет упавшие проверки со ссылками на логи.

## Ограничения и частые ошибки

- **Нужен доступ к хостингу.** Для GitHub это залогиненный `gh` либо токен в `GH_TOKEN`; сессия должна быть открыта внутри клона.
- **Старая версия клиента.** На Claude Code ниже 2.1.287 мод ставится, но ничего не делает ([Устранение неполадок](/faq/troubleshooting/)).
- **Мод работает с вашими правами.** Ставьте только то, что готовы прочитать: [Основы, Хуки и моды](/basics/hooks-mods/).
