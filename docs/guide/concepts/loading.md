Эта страница о том, что происходит со стороны Claude Code, когда плагин поставлен. Источник - [документация Claude Code о плагинах](https://code.claude.com/docs/en/plugins).

## Что загружается

Плагин - каталог с компонентами: skills, агенты, команды, хуки. Claude Code ставит и грузит его целиком. Загрузка происходит при старте сессии либо при `/reload-plugins` в уже запущенной.

## Что лежит в контексте

Включённый плагин присутствует в каждой сессии, а не только там, где вы его использовали. Для каждого skill, агента и команды, которые Claude может вызвать сам, название и описание лежат в контексте на каждом ходу, чтобы Claude знал, что они есть. Полный текст skill или агента загружается, только когда он используется.

Отсюда практические выводы:

- Ставьте нужное: каждый лишний плагин добавляет описания в контекст и уменьшает место под работу.
- Размер плагина можно измерить: `claude plugin details <имя>` показывает состав и ожидаемую стоимость в токенах.
- Ненужный плагин можно отключить, не удаляя: `claude plugin disable <имя>`.

## Как срабатывает каждый вид

| Вид | Что решает, что он нужен |
|---|---|
| Skill | Описание skill сопоставляется с контекстом разговора |
| Специалист | Описание агента: Claude делегирует ему задачу по смыслу, либо его вызывает команда |
| Команда | Вы, явным вызовом `/плагин:команда` |
| Мод | Событие клиента, на которое он подписан |

Команды и skills плагина вызываются в форме `/плагин:команда`.

## Установка бандла и что она значит

Бандл не включает ничего особенного: он ставит плагины по одному обычной командой `claude plugin install`. Поэтому всё сказанное выше относится к каждому его плагину. Бандлы каталога большие, потому что специалисту нужны его skills; если вам нужна одна команда, посмотрите, в каком плагине она лежит, и поставьте его поштучно вместе со skills, которые он называет.
