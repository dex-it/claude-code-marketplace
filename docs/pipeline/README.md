# Конвейер требований: зона «идея -> допуск к разработке»

Два документа, разные предметы:

- [CHAIN.md](CHAIN.md) - **нормативная основа**: на какие стандарты опирается цепочка этапов, какой
  информационный элемент выпускается на каждом, какие атрибуты несёт его выход. Отвечает на вопрос
  «чем это подпёрто».
- [PIPELINE.md](PIPELINE.md) - **устройство работы**: какими единицами она идёт, в каком порядке,
  что проверяется на стыках, когда останавливается ради решения человека. Отвечает на вопрос «как
  это работает». Требования к самому конвейеру - в его шапке, `R-1..R-9`.

Дом фактов и статусов сверки - [реестр стандартов](../standards/README.md): здесь дизайн, там
источники и их статусы. Утверждение из первоисточника несёт пометку реестра там, где его повторяет.

Проверяются оба кейсами [pipeline-basic.md](../../tests/_cases/pipeline-basic.md): у каждого кейса
названы раздел схемы и требование `R-N`, которые он держит.
