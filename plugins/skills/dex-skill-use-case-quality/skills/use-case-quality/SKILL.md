# Use case - оракул сценария

Оракул судит готовый сценарий и даёт вердикт для метки `quality-checks`. Норма состава - `use-cases-cockburn`. Своему артефакту вердикта не ставят: оракул прогоняет судья, не автор (`node-contract`, раздел B п.7). Автор прогоняет его самоконтролем и отчитывается полем `self-check` - вердиктом это не является.

## Чек-лист

Пункт называет ситуацию, которую сценарий проверяется на присутствие.

- Шаг без действующего лица
- Два действия в одном шаге
- Ветвление внутри основного хода
- Вариация данных записана как расширение
- Расширение без терминала
- Правило или число в шаге сценария
- Трассировка ведёт на несуществующее требование
- Заголовок называет действие интерфейса, а не цель актора
