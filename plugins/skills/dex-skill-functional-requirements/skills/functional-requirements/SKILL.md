# Правила - чек-лист

Пункт называет ситуацию, которую правило проверяется на присутствие.

- Правило выведено из `BR` напрямую, хотя сценарий на эту цель разобран, а основание «несценарное требование» не объявлено либо объявлено, хотя шаг или расширение сценария это поведение наблюдает: основанием ставится шаг или расширение сценария (`UC-NNN 1a`), `BR` - через него
