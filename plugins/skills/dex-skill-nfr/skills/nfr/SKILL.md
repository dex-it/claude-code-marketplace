# NFR - чек-лист

Пункт называет ситуацию, которую набор мер проверяется на присутствие.

- Число меры не из источника и без записи решения
- Доступность мерится временем работы сервера, а не долей успешных запросов
- Классификация данных и модель авторизации не заданы
