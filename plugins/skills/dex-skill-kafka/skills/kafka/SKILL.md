# Kafka - чек-лист

Пункт называет ситуацию, которую исполнитель сам не заподозрит.

- Продьюсер без идемпотентности: повторы отправки дублируют и переупорядочивают сообщения
- Потребитель с накопленными несохранёнными смещениями: при ребалансе обработанное читается заново
- Ядовитое сообщение блокирует партицию потребителя: после ограниченного числа попыток оно уходит на разбор (топик `*.DLT` или иное хранилище) с содержимым и причиной, смещение движется дальше; повтор на месте без предела партицию не освобождает
