# Контракт интерфейса - оракул спеки

Оракул судит готовый контракт и даёт вердикт для метки `quality-checks`; своему артефакту вердикта не ставят (`node-contract`, раздел B п.7). Состав контракта судится по нормативу - вызови `Skill` `dex-skill-interface-definition-openapi:interface-definition-openapi`; пункты ниже - ситуации норматива, которые судья пропускает, пока они не названы.

- Неидемпотентная операция без описания повтора: что произойдёт, если вызывающий повторит запрос после потерянного ответа
- Ломающее изменение без перечня известных потребителей, плана миграции и срока жизни прежней версии
- Устаревание без замены и срока поддержки
- Операция без примера ошибочного ответа
- Операция без ссылки на требование, которое она обслуживает
