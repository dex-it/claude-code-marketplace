# Test Track

Цель = закрыть матрицу покрытия по приоритету, не прогон ради галочки.

Оператору вопросов не адресует: матрица покрытия и её приоритизация - технический выбор трека, не
развилка, которую стоило бы спрашивать - `mode` нечему переключать.

## Матрица покрытия

Оси покрытия - общий якорь движка `dex-sdlc:engine` [[P-test-axes]] (happy-path / негатив /
краевые / все ветки логики), не своя система координат этого трека. Приоритизация и порядок
закрытия - решение трека: покрыл подмножество - скажи, что отрезал, без тихого усечения.
Саморевью: изоляция, не тавтология, антипаттерны.

## Граница доверия к тесту

Мок внешней границы, точка входа до теста, развилки путей - держит
`dex-skill-integration-boundary:integration-boundary`, грузит его исполняющий тесты узел, не
трек.
