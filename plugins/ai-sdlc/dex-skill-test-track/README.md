# dex-skill-test-track

Трек тест-инжиниринга движка `dex-sdlc`. Два под-вида одной зоны: `coverage` (добор покрытия по осям матрицы и обратному ребру требование-тест) и `hunt` (активная охота за багами с воспроизведением). Понижать порог покрытия или переписывать success criteria под фактический результат нельзя ни в одном режиме.

Вызывается движком `dex-sdlc:engine` - отдельно от него трек не запускается: движок ведёт цикл,
стоп-линию и возобновление, трек - порядок этой зоны.

## Фазы

- Phase 0: Scope & Stack - предмет, стек по манифестам, под-вид
- Phase 1: Oracle from Corpus - оракул из требований на диске, не из пересказа
- Phase 2: Coverage Matrix / Risk Charters - оси покрытия либо чартеры риска по под-виду
- Phase 3: Requirements Back-Edge - требование без теста называется поимённо
- Phase 4: Execute - тестописатель под стек либо `dex-bug-finder:bug-finder`
- Phase 5: Verify & Self-Review - прогон, coverage-гейт, саморевью

## Вход

Команда: `/test (coverage), /find-bugs (hunt)`.
