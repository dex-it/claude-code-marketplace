# dex-skill-architecture-track

Трек-указатель зоны дизайна движка `dex-sdlc`: собственного порядка фаз не держит - он целиком живёт
в `dex-architect:architect` (агент без `Agent` в `tools`, ничего не спавнит). Скилл существует ради
единообразного контракта диспетчинга: движок называет трек в auto-ledger одинаково для любой зоны.

Вызывается движком `dex-sdlc:engine` - отдельно от него трек не запускается.

## Вход

Команда: `/design`.
