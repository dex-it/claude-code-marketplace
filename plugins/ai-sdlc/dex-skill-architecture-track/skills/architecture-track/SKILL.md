# Architecture Track

Трек-указатель, не собственный порядок фаз. Весь дизайн-конвейер (альтернативы, решение с
CAP/PACELC, deep-dive, план, опционально ADR/диаграммы) ведёт `dex-architect:architect` -
самостоятельный агент, ничего не спавнящий (`Agent` не входит в его `tools`). Этот скилл существует
только ради единообразного контракта диспетчинга: движок называет `track=dex-skill-architecture-track:architecture-track`
в task-флаге так же, как для любой другой зоны, а фактическую работу ведёт агент напрямую.

## Делегирование

Движок, определив зону 2, вызывает `dex-architect:architect` (или `dex-architect-dotnet:architect-dotnet`
для .NET-специфичного deep dive) с входом - бизнес-задача + NFR/constraints. Дальнейший порядок фаз,
гейты и выход - контракт агента, не этого трека.

## Boundaries

- Этот трек не ведёт собственных фаз и не судит результат - вся ответственность у агента.
- Полный редизайн под идиому фаз-контракта - вне этого пакета (перенос как есть).
