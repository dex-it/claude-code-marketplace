# /discover

Обзорное (breadth-first) ревью существующего кода через `dex-skill-discover-track:discover-track`:
инвентаризация проблем по топикам, результат сохраняется в `docs/discover/`. Не глубокая
верификация-под-рефактор и не ADR-планы - это `/review-arch`.

## Goal

Дать карту проблем существующего проекта вширь: трек делегирует `discover-orchestrator`, тот
детектит стек/масштаб, спавнит `discover-reviewer` по топикам, связывает находки кросс-топиково и
калибрует severity под масштаб. По каждому релевантному топику - список находок с приоритетом
разбора (P0-P3), сводный мастер-док с порядком разбора.

## Input

Аргумент - путь к проекту (по умолчанию текущая директория). Без фильтров: discover всегда идёт
вширь по всем релевантным стеку топикам. Углубление в конкретную область - отдельным инструментом по
результату.

## Output

`docs/discover/README.md` - мастер-док: карта стека и масштаба, таблица выбранных топиков, сводная
карта приоритетов P0-P3 (кросс-топиковая), executive summary, рекомендуемый порядок разбора.

`docs/discover/NN-<топик>.md` - на каждый топик: «что смотрим», таблица находок (`severity ·
находка · якорь file:line · маркер /? · рекомендация`), краткие рекомендации.

Severity - P0-P3 (приоритет разбора, не гейт на мёрдж), калиброванный под масштаб. Маркеры
доказанности обязательны: подтверждённый код прочитан целиком, под вопросом - по grep без полного
аудита.

## Constraints

- Калибровка меняет уровень находки, не вычёркивает её. Надёжность и безопасность не понижаются по
  масштабу
- Дефолт подсветки: нет явного маркера accepted tech debt (TODO+тикет, ADR, пометка в проекте) ->
  находка подсвечивается, не молча принимается
- Не предлагать рефакторинг-планы и ADR - это обзор, не глубокое ревью
- Стек не определён - трек спрашивает; если и после этого стек не ясен (нет манифестов, README,
  понятной структуры) - пройти универсальные топики «Архитектура и слои» и «Качество кода и
  тестируемость», пометив в мастер-доке, что стек не детектирован

Трек не принимает поле `mode` - у оркестратора нет цикла команд к оператору, результат уходит
готовым мастер-доком. Вызови `Skill` -> `dex-sdlc:engine` (откроет/возобновит цикл, авто-ledger с
треком `dex-skill-discover-track:discover-track`), затем `Skill` ->
`dex-skill-discover-track:discover-track`.
