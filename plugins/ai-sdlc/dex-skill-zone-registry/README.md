# dex-skill-zone-registry

Реестр зон конвейера AI-SDLC - **вход в движок** `dex-sdlc:engine`. Отвечает на два вопроса:
конвейерный ли предмет поручения вообще и, если да, какая зона его ведёт.

Резолв идёт до подъёма движка: поручение, не попавшее ни в одну строку, признаётся внеконвейерным -
движок не поднимается, работа идёт обычным порядком. Раньше реестр жил справочником внутри движка, и
отсечь предмет можно было только после его загрузки.

## Что производит

- имя зоны и трек, который её ведёт, - строкой таблицы;
- либо терминал «вне конвейера»;
- формулировку, из которой зона выведена, - для допущений выхода.

## Дальше

Исполнитель поднимает `dex-sdlc:engine` и называет ему трек из строки; трек движок поднимает сам,
шагом 1 своего цикла. Продолжение уже начатой работы через реестр не идёт - трек записан в шапке
auto-ledger.
