# dex-skill-rulebook-track

Трек зоны свода правил проекта движка AI-SDLC. Зона отвечает на вопрос «что принято в этом репозитории» и производит корпус, на который ревьюеры опираются вместо своей памяти.

## Что делает трек

| Фаза | Кто исполняет |
|---|---|
| приёмка входа зоны, разрешение адреса свода, заготовка дерева и ключ путей | трек |
| добыча: окно, чтение свода, сборщики, сведение, фальсификация, поиск пропускаемого, запись | узел добычи |
| вердикт оракула по своду и метка качества | трек |
| публикация MR со сводом | трек, по санкции `publish` |
| круг разметки владельца по единицам | трек, по разметке владельца |
| приёмка результата и выход по контракту узла | трек |

Порядка добычи трек не несёт - он живёт в узле. Содержания свода трек не пишет: написав его, он потерял бы право судить; метку качества, ключ путей и заготовку дерева он пишет - это обязанности судьи и держателя расположения.

## Установка

Едет вместе с зоной. Замкнутость состава держит `npm run validate:bundles`: трек называет узел добычи и оракул свода, поэтому оба обязаны ехать в том же бандле.
