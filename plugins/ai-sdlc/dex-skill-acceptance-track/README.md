# dex-skill-acceptance-track

Заглушка - перенос без переработки из закрытого движка `autonomous-task` (трек
`stand-acceptance.md`, см. git-историю плагина `dex-skill-autonomous-task` до его удаления).

Приёмка слитой фичи на развёрнутом стенде против ТЗ: привязка образа к merge-коммиту, проба
каждого требования с наблюдением, регрессия соседей, фальсификация находок, ремедиация через
`dex-bug-fixer:bug-fixer`.

Полный редизайн под идиому фаз-контракта - отдельный будущий пакет, не эта поставка.
