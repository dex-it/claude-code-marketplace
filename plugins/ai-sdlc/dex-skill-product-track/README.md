# dex-skill-product-track

Трек зоны продукта движка `dex-sdlc`: порядок работ над корпусом **уровня 0** - тем, что верно для
продукта целиком, а не для одной фичи.

| Артефакт | Единицы | Кто пишет |
|---|---|---|
| BRD продукта | `BR-NNN` с мерой успеха `MOE`, `non-goals`, anti-metrics | `dex-business-analyst:business-requirements-analyst` |
| Доменная модель (словарь) | термин - значение - дом - «не путать с» | `dex-domain-analyst:domain-analyst` |
| Конституция | `INV-NNN`, `NFR-P-NNN` с основанием и методом проверки | `dex-domain-analyst:domain-analyst` |

Точка входа - `/product` (движок + этот трек). Правая граница - принятый корпус уровня 0; фичи,
сценарии и системные требования - зона требований (`/feature`), которая на этот корпус ссылается и
своего второго BRD не заводит.

Три слоя движка (движок / трек / узел) и порядок вызова `Skill` - README плагина `dex-sdlc`.
