# dex-sdlc-requirements

Команды зоны требований AI-SDLC-конвейера. Плагин несёт только команды - вход в движок;
сам движок (универсальный цикл, диспетчинг по треку, авто-леджер) живёт в `dex-sdlc`,
порядок работ зоны - в трек-скилле.

| Команда | Что делает | Трек |
|---|---|---|
| `/feature` | сценарии UC, правила FR/NFR, истории с AC | `dex-skill-analytics-track` |
| `/feature-check` | проверка готового корпуса требований судьями | - |

## Установка

Плагин ставится вместе с `dex-sdlc` (движок) и трек-скиллами своей зоны: команда без них
не резолвит исполнителя. Готовые наборы - бандлы каталога; замкнутость проверяет
`npm run validate:bundles` (правило `bundle-command-not-closed`).
