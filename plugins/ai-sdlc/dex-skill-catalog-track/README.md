# dex-skill-catalog-track

Трек зоны «каталог» движка `dex-sdlc` - правка **артефакта-инструкции**: skill, агент, команда,
бандл, манифест плагина, нормативное правило репозитория.

Вызывается движком `dex-sdlc:engine` - отдельно от него трек не запускается: движок ведёт цикл,
стоп-линию и возобновление, трек - порядок этой зоны.

Отличие от зоны разработки: у инструкции нет сборки и тестов, валидатор судит форму файла, а
деградирует поведение исполнителя. Отсюда две опоры трека - единственный дом нормы и прогон
поведения вместо зелёного валидатора.

## Фазы

- Phase 0: Repository Norms - нормы репозитория до первой правки
- Phase 1: Intake & Artifact Type - тип артефакта и класс правки
- Phase 2: Home Inventory - все носители факта, один дом
- Phase 3: Formulate - однозначность, терминал ветки, механизм, обобщённость
- Phase 4: Edit Plan - порядок по носителям
- Phase 5: Apply - правка, исполнитель по критерию
- Phase 6: Behaviour Run - оптимизация под LLM и прогон кейсов
- Phase 7: Sync & Version - версии, каталог, витрина, замыкание бандла
- Phase 8: Gate - гейт репозитория фактом прогона
