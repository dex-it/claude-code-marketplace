# Discover Track

Трек-указатель, не собственный порядок фаз. Весь конвейер обзорного ревью (детект стека/масштаба,
фан-аут по топикам, связывание находок кросс-топиково, калибровка severity, запись в
`docs/discover/`) ведёт `dex-code-discovery:discover-orchestrator`, который сам спавнит
`discover-reviewer` через `Agent` по топикам. Этот скилл существует только ради единообразного
контракта диспетчинга движка.

## Делегирование

Движок вызывает `dex-code-discovery:discover-orchestrator` напрямую; дальнейший фан-аут, критерии
полноты и выход - контракт оркестратора, не этого трека.

## Boundaries

- Этот трек не ведёт собственных фаз и не судит находки - вся ответственность у оркестратора.
- Полный редизайн под идиому фаз-контракта - вне этого пакета (перенос как есть).
