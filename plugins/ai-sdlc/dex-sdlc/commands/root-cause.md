# /root-cause

Найти первопричину репортнутого бага по коду через `dex-skill-diagnostics-track:diagnostics-track`
и, если правка запрошена, исправить корень с подтверждающим тестом.

## Goal

Провести расследование через универсальный цикл движка и фазы трека, делегирующего `debugger`
(Reproduce, Direct Analysis, Skill-Based Deep Scan, Hypothesize, Fix, Verify). Трек нарезает
гипотезы срезами и требует фальсификации каждой до принятия причины - корреляция не равно
причинность.

## Input

Симптом и как его наблюдать: stack trace, лог, шаги воспроизведения, ожидаемое против фактического,
окружение. Чего нет - сказать прямо, узел не додумывает. Стек определяется по манифестам проекта.
Нужна правка кода, а не только диагноз - сказать явно.

## Output

- Status: исход узла (`complete` / `blocked` / `partial`) первым полем
- Expected-basis: эталон получен на входе либо реконструирован по коду и не подтверждён - во втором
  случае `status` не выше `partial`
- Pass 1 (Direct Analysis): находки с `anchor` file:line и evidence
- Pass 2 (Skill-Based Deep Scan): те же находки, прогнанные по профильным skills стека
- Hypothesis: первопричина «если X, то Y, потому что Z», фальсифицированная трек-конвейером;
  техутверждение в её основе сверено - `verified` / `unverifiable` / `contradicted`
- Fix: минимальный diff, red -> green тест, статус прогона регрессии - либо предложенный fix с
  названной причиной, по которой он не применён
- Остаточные риски

## Constraints

- Лечить причину, не симптом; обходной путь - только с явной пометкой
- Root cause не подтверждён фальсификацией - фикс не пишется, это hard gate
- Нужны runtime-инструменты (profiler, dump) - трек говорит об этом и передаёт на `/investigate`
- Глубину под стек дают профильные skills `dex-skill-<стек>-*`, подбираются по реестру стеков

Вызови `Skill` -> `dex-sdlc:engine` (откроет/возобновит цикл, авто-ledger с треком
`dex-skill-diagnostics-track:diagnostics-track`), затем `Skill` ->
`dex-skill-diagnostics-track:diagnostics-track` с **`mode: interactive`** - без этого поля трек
работает как узел (`autonomous`), канала к пользователю у него нет, и результат уходит handoff-ом
наверх, а не пользователю. Запрошена ли правка кода - передавать явно: трек состав не додумывает.
