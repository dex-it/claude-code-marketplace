# dex-sdlc-rulebook

Команда зоны свода правил AI-SDLC-конвейера. Плагин несёт только команду - вход в движок; сам движок (универсальный цикл, диспетчинг по треку, авто-леджер) живёт в своём плагине, порядок работ зоны - в трек-скилле.

| Команда | Что делает | Трек |
|---|---|---|
| `/rulebook` | выводит из истории ревью то, что в репозитории принято, и пишет свод правил в корпус документации | `dex-skill-rulebook-track` |

## Установка

Плагин ставится вместе с движком и трек-скиллом своей зоны: команда без них не резолвит исполнителя. Готовые наборы - бандлы каталога; замкнутость проверяет `npm run validate:bundles` (правило `bundle-command-not-closed`).
