# /product

Описать продукт целиком - кому служит, что считается успехом, каким языком о нём говорят и что верно
во всех его состояниях. Вход конвейера: на этот корпус опирается каждая фича.

## Goal

Провести работу через универсальный цикл движка и фазы трека
`dex-skill-product-track:product-track`: Bootstrap, Стороны и границы -> BRD продукта (делегировано
`business-requirements-analyst`), Язык -> доменная модель и Инварианты и меры -> конституция
(делегировано `domain-analyst`), Приёмка корпуса, Handoff.

## Input

Аргумент - в одной из трёх форм:

- **идея продукта в свободной форме** («сервис уведомлений для внутренних команд», «маркетплейс
  плагинов») - стороны и границы разбираются интервью на замыкание, апрув берётся на остановке;
- **путь к принятому корпусу уровня 0** - прогон продолжается с накопленного, закрытые фазы не
  переигрываются;
- **названная правка принятой единицы** (`BR-007`, термин, `INV-012`, изменившийся внешний
  регламент) - дельта-прогон с обходом задетого по всему корпусу проекта.

Аргумент не передан - трек запрашивает предмет одним вопросом в первом сообщении.

## Output

- BRD продукта: `BR-NNN` с мерой успеха `MOE`, `non-goals`, anti-metrics, допущения, открытые вопросы
- Доменная модель: термин - значение - дом определения - «не путать с»; отдельно термины без дома
- Конституция: `INV-NNN` и `NFR-P-NNN`, у каждой единицы основание (`traced from`) и метод проверки
  с пометкой автоматическая/ручная
- `decision-log` корпуса: находки гейтов с исходами, сведённые расхождения имён, решения с основанием
- `quality-checks` по каждому артефакту; тип без оракула - `unverifiable` с причиной, не пустое место

## Constraints

- Корпус уровня 0 - один на продукт: второй BRD, второй словарь или вторая конституция не заводятся,
  новая тема продукта идёт правкой принятого
- Артефакты пишут узлы (`business-requirements-analyst`, `domain-analyst`), не трек и не эта команда
- Безусловная остановка одна - приёмка корпуса целиком: цели и границы предъявляются на ней же, а не
  отдельным апрувом; молчание апрувом не считается. Нижней границы у числа вопросов нет: всё замкнуто
  выводом из принятого -> остановка идёт без вопросов (MVP раньше полноты)
- Единица уровня 0 переживает удаление любой одной фичи; не переживает - это цель фичи, её место в
  `/feature`
- Фичи, сценарии, `FR`/`NFR` фичи и задачи здесь не порождаются - граница зоны

Следующий шаг - `/feature`: цели фичи трассируются на принятые `BR-NNN`, единицы фичи проверяются
против `INV`/`NFR-P`. Вызови `Skill` -> `dex-sdlc:engine` (откроет/возобновит цикл, авто-ledger с треком
`dex-skill-product-track:product-track`), затем `Skill` -> `dex-skill-product-track:product-track` с
**`mode: interactive`** - без этого поля трек берёт автономную планку (`autonomous`) и остановки не
встанут перед оператором: канал у тела команды есть, останавливаться на нём трек будет только с
этим полем.
