# Documentation Track

Артефакт - нормативный текст; верификация = синхрон с кодом + стандарт.

## Конвейер

Контекст: аудитория (оператор в 3 ночи / интегратор / новичок) + стандарт проекта. Факты - из
кода/конфигов, не из памяти и не из других доков (протухают).

## Саморевью

Полнота, нет LLM-маркеров, single source of truth. Жанр задаёт критерий: ADR -
контекст->решение->последствия; runbook - воспроизводимые шаги под стресс; API-док - контракт точь-в-точь
как код.
