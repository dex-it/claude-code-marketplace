# Ключ прогона: как определяется и как ищется совпадение с корпусом

Дом обязательства - `SKILL.md`, «Ключ прогона»; здесь алгоритм.

Вход несёт папку фичи или явный ключ - берётся он. Иначе слаг строится из темы (нижний регистр,
буквы, цифры и дефис, остальное в дефис) и ищется среди фич корпуса - по каталогам и артефактам,
уже заведённым: слаг несёт сама раскладка (дефолт `<NN>-<слаг>`,
`dex-skill-artifact-naming:artifact-naming`), на чужой раскладке слаг ищется в шапках артефактов.
Точное совпадение - продолжение прогона; совпадения нет, но есть похожие - предъявляются оператору
вопросом «продолжаем эту или заводим новую»; пусто - фича новая. В `autonomous` вопроса нет: трек
решает сам и пишет строку в список принятых за оператора решений.

Слаг уже принятой фичи берётся из найденного пути и не подменяется слагом, выведенным заново из
новой фразы: две формулировки одной темы иначе заводят два набора артефактов под одну фичу.
