# Дельта-прогон: правка принятой единицы

Читается треком `analytics-track` при классификации входа «правка принятого» - целиком, до правки
файлов.

Вход - правка принятого, а не новая тема. Правкой принятого считается и **изменение внешнего
основания**: политика, регламент, ADR, норма среды, на которую единица сослалась видом основания.
Такое изменение стартует обход так же, как правка `BR`: иначе мера, стоящая на норме, молча живёт
со старым числом - обход от единиц корпуса до неё не доходит. Порядок:

1. **Род изменения объявляется до правки файлов** - уточнение формулировки, смена ограничения,
   расширение области, снятие (`unit-identity`). Род определяет, что пересчитывать.
2. **Задетое считается по трассе поиском по номеру единицы** (изменилось внешнее основание - по его
   указателю: путь и версия нормы, идентификатор ADR): хранимого списка «что из меня выведено» нет
   ни у одной единицы - принятое сужение, обратное поле протухает молча, поиск не протухает. Область
   обхода - корень корпуса, не папка фичи: одна мера обслуживает несколько фич. Обход конечен -
   единица входит в него один раз, взаимные ссылки двух наборов дают волну, а не круг.
3. **Оператор останавливается после пересчёта задетого, а не до правки.** До пересчёта неизвестно,
   что потянется, и ответ даётся вслепую. Правка, вышедшая за свой набор, - остановка всегда, даже
   если внутри своего набора полностью выводима.
4. **Чужую единицу правит её владелец.** Задевший переводит её в `review` с пометкой «основание
   изменено», называет изменившееся и текст соседнего набора не переписывает; незакрытый чужой
   `review` свой набор не блокирует.
5. Каждая задетая единица получает исход - пересмотрена, признана незатронутой с основанием или
   снята; апрув отзывается в изменяемой части, не во всём документе. Единицы, чей исход из правки
   выводится, идут без вопроса.

Расщепление: исходная единица снимается с записью «заменено на X, Y», потомки получают свои номера,
ссылки снизу переадресуются по предмету. Висячей ссылки на снятый ID не остаётся.
