# /mcp-inspect

Сформировать команду запуска MCP Inspector для указанного MCP сервера.

**Goal:** Готовая к запуску строка `npx @modelcontextprotocol/inspector@latest <command> <args>` с параметрами конкретного сервера из конфигурации.

**Output:** Команда запуска, перечень переменных окружения сервера (поле `env` или `_env`) и URL веб-интерфейса `http://localhost:6274`.

**Scenarios:**

- Конфигурация берётся из `.mcp.json` текущего проекта; файла нет - из `mcp/mcp-template.json` каталога маркетплейса.
- Аргумент не передан - показать список серверов из конфигурации и попросить выбрать; ничего не формировать до выбора.
- Передано имя сервера - взять его `command`, `args`, `env` из конфигурации.
- Передана пара `command args` - подставить её как есть, к конфигурации не обращаться.
- Имя сервера в конфигурации не найдено - сказать об этом и показать список доступных, не подбирать похожее.

**Constraints:**

- Команду не запускать: Inspector открывает интерактивный веб-UI и держит терминал. Предложить пользователю выполнить её самому через `! <команда>`.
- Переменные окружения сервера должны быть выставлены до запуска Inspector.
- Порты: клиент `CLIENT_PORT` (default 6274), сервер `SERVER_PORT` (default 6277); порт занят - переопределить этими переменными.
- SSE-транспорт - добавить `--transport sse`.
- В WSL браузер может не открыться сам - вывести URL для ручного перехода.
