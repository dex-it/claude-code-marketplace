# /root-cause

Найти первопричину репортнутого бага по коду и, если правка запрошена, исправить корень с подтверждающим тестом.

## Goal

Провести расследование через фазы агента `debugger`: Reproduce, Direct Analysis, Skill-Based Deep Scan, Hypothesize, Fix, Verify.

## Input

Симптом и как его наблюдать: stack trace, лог, шаги воспроизведения, ожидаемое против фактического, окружение. Чего нет - сказать прямо, агент не додумывает. Стек определяется по манифестам проекта. Нужна правка кода, а не только диагноз - сказать явно.

## Output

- Status: исход узла (`complete` / `blocked` / `partial`) первым полем
- Expected-basis: эталон получен на входе либо реконструирован по коду и не подтверждён - во втором случае `status` не выше `partial`
- Pass 1 (Direct Analysis): находки с `anchor` file:line и evidence
- Pass 2 (Skill-Based Deep Scan): те же находки, прогнанные по профильным skills стека
- Hypothesis: первопричина «если X, то Y, потому что Z»; техутверждение в её основе сверено - `verified` / `unverifiable` / `contradicted` + что сверялось; гипотеза на техутверждении не держится - сказать это прямо, а не оставить строку пустой
- Fix: минимальный diff, red->green тест, статус прогона регрессии - либо предложенный fix с названной причиной, по которой он не применён
- Остаточные риски

Перечисленное обязательно - это нижняя граница, агент отдаёт не меньше. Живёт оно у агента в двух местах, и ни одно не покрывает всё: поля стыка (`status`, `expected-basis`, остаточные риски) - в разделе `**Output (handoff):**`, продукт фаз (Pass 1, Pass 2, гипотеза со статусом сверки) - в самих фазах и в вёрстке `## Output Format`. Ни один из двух разделов полным форматом по отдельности не является.

## Constraints

- Лечить причину, не симптом; обходной путь - только с явной пометкой
- Root cause не подтверждён - фикс не пишется, это hard gate агента
- Нужны runtime-инструменты (profiler, dump) - агент говорит об этом и передаёт профильному диагносту
- Глубину под стек дают профильные skills `dex-skill-<стек>-*`; подбирает их сам агент по реестру стеков, отдельного агента на язык здесь нет

Делегировать агенту `debugger` с **`mode: interactive`** во входе - без этого поля агент работает как узел (`autonomous`), канала к пользователю у него нет, и результат уходит handoff-ом наверх, а не пользователю. Запрошена ли правка кода - передавать явно: состав вызова агент не додумывает.
