# /root-cause

Найти источник репортнутого бага по коду и вернуть найденные проблемы списком.
Стек - по манифестам проекта.

## Input

Симптом и как его наблюдать: stack trace, лог, шаги воспроизведения, ожидаемое против фактического,
окружение. Чего нет - скажи прямо, не додумывай.
Симптома нет - работа не начинается, скажи чего не хватает.

## Порядок делегирования

Порядок ведёт главный поток: канал к оператору есть только у него, узлу вниз идёт планка эскалации
`interactive`, но не канал - невыводимое он возвращает сюда статусом, а не спрашивает оператора.

Расследование ведёт `dex-debugger:debugger`. Вход ему: симптом с уликами, ожидаемое поведение (не
пришло - передай и это, эталон он реконструирует по коду), область поиска.

Правка кода в состав этой команды не входит: список уходит оператору, и правку по нему он назначает
отдельным вызовом - кодер стека либо `dex-bug-fixer:bug-fixer`, когда багов пачка и фикс идёт
follow-up веткой. Сам за оператора маршрут не выбирай.

Вернулся `blocked` - предъяви оператору, чего не хватает, и останови работу. Вернулся `partial` -
предъяви наработанное с перечнем недостающего; перечень называет runtime-инструменты (профайлер,
дамп, стенд) - предложи `/investigate`, здесь runtime не имитируется.

## Output

- `status` первым полем (`complete` / `blocked` / `partial`)
- Expected-basis: эталон получен на входе либо реконструирован по коду и не подтверждён - во втором
  случае `status` не выше `partial`
- Воспроизводящий тест: путь и вывод падения, остаётся незакоммиченным в дереве; теста нет - почему, строкой
- Список проблем: место (файл:строка), механизм, severity, evidence. Первой - причина симптома,
  остальные - `open-observations`
- У причины: «если X, то Y, потому что Z»; попытки опровержения строкой «предсказание -> наблюдение
  -> исход» и итоговый confidence; техутверждение в её основе сверено - `verified` /
  `unverifiable` / `contradicted`
- Частных skills под стек не нашлось - названо строкой в отчёте, не умолчанием
- Остаточные риски

## Constraints

- Называть первопричину, а не симптом; обход, если он виден в коде, помечен обходом
- Причина не пережила фальсификации - она идёт в список кандидатом с этой пометкой, причиной не
  объявляется
- Глубину под стек дают профильные skills `dex-skill-<стек>-*`, подбираются по реестру стеков
