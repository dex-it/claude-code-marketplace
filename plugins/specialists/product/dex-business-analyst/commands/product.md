# /product

Описать продукт целиком - кому служит, что считается успехом, каким языком о нём говорят и что верно
во всех его состояниях. На этот корпус опирается каждая фича.

## Input

Аргумент - в одной из трёх форм:

- **идея продукта в свободной форме** («сервис уведомлений для внутренних команд») - стороны и
  границы разбираются интервью на замыкание, апрув берётся на остановке;
- **путь к принятому корпусу уровня 0** - работа продолжается с накопленного, закрытое не
  переигрывается;
- **названная правка принятой единицы** (`BR-007`, термин, `INV-012`, изменившийся внешний
  регламент) - обход задетого по всему корпусу проекта.

Аргумент не передан -> запроси предмет одним вопросом первым сообщением.

## Порядок делегирования

Порядок ведёт главный поток: канал к оператору есть только у него, спавненному узлу режим
`interactive` неисполним. Узлам вниз идёт та же планка эскалации, но не канал - невыводимое они
возвращают сюда, а не решают сами.

1. **Стороны, границы, BRD продукта** - `dex-business-analyst:business-requirements-analyst`.
2. **Язык и инварианты** - `dex-domain-analyst:domain-analyst`: доменная модель, затем конституция.
3. **Приёмка корпуса целиком** - одна остановка оператора, на ней же цели и границы.

## Output

- BRD продукта: `BR-NNN` с мерой успеха `MOE`, `non-goals`, anti-metrics, допущения, открытые вопросы
- Доменная модель: термин - значение - дом определения - «не путать с»; отдельно термины без дома
- Конституция: `INV-NNN` и `NFR-P-NNN`, у каждой единицы основание (`traced from`) и метод проверки
  с пометкой автоматическая/ручная
- `decision-log` корпуса: находки гейтов с исходами, сведённые расхождения имён, решения с основанием;
  форму записи держит `Skill` -> `dex-skill-decision-log:decision-log`, вызови его перед первой записью
- Сверка трёх артефактов между собой: каждая единица конституции трассируется на `BR` продукта либо
  на внешнюю норму; каждый термин, на котором стоит `BR`, `INV` или `NFR-P`, имеет запись в словаре;
  anti-metrics BRD не противоречат `NFR-P` без названной цены разрешения конфликта. Каждое
  расхождение - находка с исходом в `decision-log`
- Выводимость вниз: `BR` без `MOE`, `INV` без метода проверки, термин без дома читаются зоной
  требований как разрешение решать самой - каждый случай находка либо явное решение «отдаём на
  усмотрение зоны требований» с основанием в `decision-log`
- `quality-checks` по каждому артефакту; тип без оракула - `unverifiable` с причиной, не пустое место

## Constraints

- Корпус уровня 0 - один на продукт: второй BRD, второй словарь или вторая конституция не заводятся;
  новая тема продукта идёт правкой принятого
- Артефакты пишут узлы, не эта команда
- Безусловная остановка одна - приёмка корпуса целиком; молчание апрувом не считается. Нижней
  границы у числа вопросов нет: всё замкнуто выводом из принятого -> остановка идёт без вопросов
- Единица уровня 0 переживает удаление любой одной фичи; не переживает - это цель фичи, её место в
  `/feature`
- Фичи, сценарии, `FR`/`NFR` фичи и задачи здесь не порождаются

Следующий шаг - `/feature`: цели фичи трассируются на принятые `BR-NNN`, единицы проверяются против
`INV`/`NFR-P`.
