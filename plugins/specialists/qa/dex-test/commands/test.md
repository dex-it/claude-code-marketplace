# /test

Закрыть матрицу покрытия тестами: не запуск существующих тестов ради отчёта, а добор покрытия по
осям в приоритетном порядке. Стек определяется по манифесту затронутой папки - явно указывать не
нужно.

## Input

Аргумент - путь к файлам/модулю под тест или diff-scope (по умолчанию - незакоммиченный + staged
diff текущей ветки). Стек и тестовый раннер определяются по манифесту (`*.csproj` -> `dotnet test`
с `--collect:"XPlat Code Coverage"`; `package.json` -> Vitest/Jest по конфигу).

## Порядок делегирования

1. **Матрица и приоритет** - здесь: разбор diff-scope на публичные контракты и ветки, оси покрытия
   (happy-path, негатив, краевые значения, все ветки) в порядке закрытия, обратное ребро
   «требование -> тест» там, где требования есть.
2. **Написание** - тестописатель своего стека (.NET - `dex-dotnet-tester:dotnet-test-writer` `[справочно]`, TS/JS -
   `dex-ts-tester:ts-test-writer` `[справочно]`); на вход идут пути под тест, публичные контракты и success criteria как оракул.
   Границу доверия к тесту, порог покрытия и техники подбора кейсов узел поднимает своими skills.
3. **Замер и добор** - прогон с покрытием; оси, оставшиеся незакрытыми, идут в выход перечнем, а не
   молча.

Стек не выводится из манифеста либо в репозитории их несколько - спроси, какой брать; молча выбирать
исполнителя нельзя.

## Output

- Тест-файлы, закрывающие приоритетные оси покрытия по diff-scope
- Branch coverage по diff-scope с указанием, какое подмножество осей закрыто, а какое отрезано и
  почему - без тихого усечения
- Статус прогона (passed / failed / skipped, время); для упавших - имя, ожидание vs результат,
  предполагаемая причина
- Саморевью узла: изоляция тестов (не флейки от порядка, таймеров, моков), не тавтология с кодом,
  отсутствие типовых антипаттернов

## Constraints

- Приоритизация осей и порядок закрытия - решение этой команды, у оператора не спрашиваются
- Тесты не собираются - сначала чинится компиляция / type-check, затем покрытие
- Coverage ниже 50% для файлов с бизнес-логикой - подсвечивается как критичный, не молчаливо
  принимается
