- `roots-check` - запись на каждое решение входа, кроме `none`, её `anchor` - место этого решения:
  `anchor`, `verdict`, `evidence`:
  - `upheld` - код вердикт ревьюера подтверждает; в `evidence` - корень, доказанный своим чтением, и входы, где
    решение неверно, перебранные сверх `evidence` ревьюера;
  - `overturned` - код вердикт опровергает: у `legitimate` корень не доказан либо есть вход, где решение неверно,
    у `illegitimate` корень доказан и такого входа нет; в `evidence` - чем опровергнут.
- Решение нелегитимно по итогу хоть одной своей записи (`legitimate` + `overturned`, `illegitimate` + `upheld`) -
  находка решения в `confirmed` либо открытая - в `prior`: подтверждение находки из `finding` решения либо своя на
  месте решения.
- `roots-missed` - решение правки вне тестов, место которого не пересекает решение входа, кроме `none`: `anchor`,
  `decision`; таких нет - пусто.
