# /onboard

**Goal:** проект готов к циклу `/dex-auto:goal` -> `/dex-auto:auto`: корпус найден либо развёрнут, назначение
продукта и решения устройства, видимые в коде, - единицами корпуса `status: review` либо названы с причиной, почему
единицы нет; `CLAUDE.md` несёт порядок работы и команды сборки, тестов и гейтов либо их отсутствие. Продуктовый код,
тесты и конфигурацию сборки команда не меняет, push не делает.

**Вход.** Описание продукта текстом либо путём к файлу (`Read`); нет - описания нет. `--interactive` - режим с
каналом к оператору, дефолт `autonomous`.

**Каталог.** Корень - `git rev-parse --show-toplevel`. Не репозиторий либо `git status --porcelain` непуст - остановка
`blocked` с причиной до любой записи. Коммиты ложатся на текущую
ветку.

**Описание.** Описания нет и режим `interactive` - до трека `AskUserQuestion` блоком: назначение продукта (кому и
зачем), его стороны, граница - чего продукт не делает; у каждого вопроса варианты, выведенные из README и кода, и
следствие каждого. Ответы - описание продукта. `autonomous` - вопросов нет, описание выводит узел трека.

**Трек.** `Workflow` с `name` `dex-auto:dex-auto-onboard`, `args` `{cwd, brief}` (`brief` без описания не подаётся).
Возврат ждёшь в том же ходе циклом `until` в `Bash` по файлу вывода задачи `<Task ID>.output` под `claude-<uid>`
временного каталога (первый заданный из `CLAUDE_CODE_TMPDIR`, `TMPDIR`, `TMP`, `TEMP`, иначе `/tmp`), Task ID - из
текста старта `Workflow`; готовность - файл непуст и разбирается как JSON, возврат - его поле `result`. Таймаут цикла
- новый такой же вызов, пока в `Transcript dir` из текста старта за последние 15 минут изменился хоть один файл; не
изменился ни один - исход `blocked` «возврат Workflow не получен: 15 минут без записи прогона». Закрытый ход
(`ScheduleWakeup`, «до уведомления») прогон убивает.

**CLAUDE.md.** После возврата, кроме `blocked` и отказа `Workflow`:

1. Гейты - вызови `Skill` `dex-skill-project-baseline:project-baseline`, раздел «Что проверять»: по каждой оси -
   команда из манифеста и конфигурации проекта (сборка, проверка типов, линтер, тесты, прогон в CI) либо `нет`.
   Отсутствующий гейт не заводишь: он идёт в выход предложением.
2. Блок - текст `${CLAUDE_PLUGIN_ROOT}/templates/flow.md`, затем раздел `## Сборка и гейты` строкой на ось, между
   строками-маркерами `<!-- >>> dex-auto: flow -->` и `<!-- <<< dex-auto: flow -->` в `CLAUDE.md` корня. Маркеры
   есть - содержимое между ними заменяешь; нет - блок дописываешь в конец; файла нет - создаёшь. Текст вне маркеров
   не трогаешь.
3. Коммит - только `CLAUDE.md`, с трейлером `Dex-Auto-Onboard: flow`; блок не изменился - коммита нет.

**Приёмка.** `interactive` и в возврате есть `units` либо `commit` - вопрос: единицы, `derived`, `conflicts`,
`layout`, вердикты сверщика - принять | отклонить. Отклонить - `git revert` коммита трека и коммита `CLAUDE.md` этого
вызова, в выход причина. `autonomous` - приёмка за человеком на MR, вопросов нет.

**Output:** исход первой строкой - `status` возврата (`blocked` до трека - причина), затем `where`; корпус (`corpus`)
и `layout`; единицы `units` путями, `derived` - к приёмке оператором; `covered`, `unrecorded` с причиной,
`conflicts` - выбор стороны за оператором; вердикты `checks` не `upheld` и `missed`; гейты по осям и отсутствующие -
предложением завести; коммиты вызова; ответ приёмки; строка «свод правил проекта не собирается: его источник -
история ревью, а не код»; следующий шаг - `/dex-auto:goal`.

**Constraints:** поля возврата брать из поля `result` файла вывода, не из пересказа.
