# Профиль команды клиента

Заполняется консультантом по ходу интервью (см. `../01-assessment.md`). Хранит
**собранные факты** о процессе клиента + его цель. Один слой - сырой факт: точки
встраивания по профилю выведет планировщик (отдельная работа), в профиле их нет.

Профиль - чистый снимок состояния клиента (не протухает, перепроверяем) и вход
планировщика. Оси повторяют блоки анкеты.

Клиент: __________  Дата обследования: __________  Консультант: __________

## 1. Ревью и тесты

- Ревью MR: [обязательно / неформально / нет]
- Автотесты + покрытие: [есть с метрикой / без метрики / нет]; тесты [против требований /
  после кода]
- Доступ к репозиторию и diff (git): [есть / нет]

## 2. Постановка

- BRD (бизнес-требования): [есть / отрывочные / нет]
- Критерии приёмки: [проверяемы, до разработки, не правятся / расплывчатые или после кода /
  нет]
- NFR: [фиксируются / всплывают постфактум / нет]
- Валидация требований на полноту/конфликты: [есть / нет / legacy без постановки]
- Где хранится постановка: [git общий / git выделенный репо / трекер (какой) / гибрид
  (что где) / вразнобой]

## 3. Разработка

- Локальная сборка/тесты: [воспроизводимы / только CI]
- DoD инкремента: [есть отдельный / неформальный / нет]
- Legacy без тестов: [есть, объём / нет]

## 4. Процесс

- Методология: [Scrum / Kanban / waterfall / нет]
- Приёмка после деплоя: [есть на стенде / нет]
- Где фиксируются критерии приёмки: [до разработки, где именно / дозревают по ходу]

## 5. Инструменты

- Трекер: __________
- Хостинг репо: __________
- CI: __________
- Инфра для диагностики: __________
- E2E: __________

## 6. Стек

- Языки: __________
- Фреймворки: __________
- Менеджер пакетов / сборка: __________

## 7. Люди и власть

- Спонсор и полномочия: __________
- Владельцы CI/инфры (для доступа): __________
- Ожидаемое сопротивление: __________
- Команда для пилота: __________

## 8. Цель клиента

- Боль/цель + к какому шагу процесса привязана: __________
- Ожидаемый эффект + критерий успеха (или «неизмеримо»): __________
- Ограничения, сроки, no-go зоны: __________

---

Профиль заполнен -> передать планировщику (отдельная работа) для определения точек
встраивания: какой агент на какой слот, какой CLI-плагин под инструмент, где гейты, что
в волне 0, порядок раскатки. Планировщик принимает эти факты и цель на вход; анкета сюда
решения не пишет.
