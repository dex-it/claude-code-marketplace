# adoption - playbook внедрения агентного SDLC

Каталог продукта внедрения (консалтинг с активом). Читатель - консультант, ведущий
внедрение у клиента. Отличается от `docs/` (там нормативка для авторов плагинов).

## Состав (текущий)

- `01-assessment.md` - анкета обследования: снять профиль клиента, определить точки
  встраивания. Ведёт консультант на интервью. Оси - в порядке внедрения.
- `templates/company-profile.md` - шаблон профиля-снимка (выход обследования).
- `tools-dictionary.md` - словарь проверенных решений «инструмент -> интеграция -> как
  включить в контекст агента». Шире каталога плагинов, наполняется по мере встречи.
- `cases/` - заполненные профили реальных обследований.

## Порядок работы

1. Провести интервью по `01-assessment.md`.
2. Заполнить `templates/company-profile.md` -> положить копию в `cases/<клиент>.md`.
3. Сводка точек встраивания внизу профиля - вход для планирования внедрения.

Остальные файлы playbook (матрица зрелости, планирование, пилот, метрики) - следующие
работы, здесь пока нет.
