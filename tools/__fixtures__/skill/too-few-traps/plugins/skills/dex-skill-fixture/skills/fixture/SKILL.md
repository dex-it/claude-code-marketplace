# Фикстура trap-skill

База песочницы: файл обязан давать ноль находок всеми валидаторами. Ловушки ниже - минимальный
валидный набор, содержание вторично, форма первична.

### Правка базы вместо оверлея

**Плохо:** правило проверяется правкой `_base`.

**Правильно:** оверлей `<validator>/<rule>/` поверх базы.

**Почему:** база - общий ноль для всех фикстур; правка ломает каждую вторую проверку сразу.

### Оверлей без своего правила

**Плохо:** оверлей меняет файл, но ожидаемого правила не поднимает.

**Правильно:** оверлей поднимает ровно то правило, чьё имя носит директория.

**Почему:** молчащая фикстура выглядит зелёной и не проверяет ничего.
