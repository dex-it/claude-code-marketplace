# Материал по требованию: четыре адреса, на которые правило не смотрит

Файл держит молчащую половину оверлея. Каждая строка ниже похожа на адрес доки каталога и
адресом каталога не является; сработает правило хоть на одной - фикстура покажет находку
с именем этого файла.

Корпус пользователя, не документация каталога - `docs/product/GLOSSARY.md`.

Внутренний дизайн-док вложенного каталога, голым именем не адресуется - `PIPELINE.md`.

Чужой файл, чьё имя оканчивается на имя нашего - `MY_CORPUS.md`.

Голое имя в составе чужого пути, слева `/` - `internal/CORPUS.md`.
