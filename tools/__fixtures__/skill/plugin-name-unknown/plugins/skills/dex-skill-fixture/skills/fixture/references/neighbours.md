# Материал по требованию: указатели на соседей

Файл держит вторую точку вызова правила - `references/` скилла. Норму, поднятую референсом,
исполнитель читает так же, как тело, и протухшее имя в нём ведёт ровно в никуда.

Разбором пачки находок ведает `dex-nowhere-reference` - имени нет в каталоге.

Базой песочницы ведает `dex-fixture-specialist` - имя в каталоге есть, правило молчит.

Загрузка через плагин, которого нет: `dex-nowhere-refload:fixture` - полная форма, половина «плагин» неизвестна.

Загрузка через плагин песочницы: `dex-fixture-specialist:fixture-oracle` - правило молчит.
