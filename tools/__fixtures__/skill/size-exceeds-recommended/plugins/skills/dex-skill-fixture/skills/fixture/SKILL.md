# Фикстура trap-skill

База песочницы: файл обязан давать ноль находок всеми валидаторами. Ловушки ниже - минимальный
валидный набор, содержание вторично, форма первична.

### Правка базы вместо оверлея

**Плохо:** правило проверяется правкой `_base`.

**Правильно:** оверлей `<validator>/<rule>/` поверх базы.

**Почему:** база - общий ноль для всех фикстур; правка ломает каждую вторую проверку сразу.

### Оверлей без своего правила

**Плохо:** оверлей меняет файл, но ожидаемого правила не поднимает.

**Правильно:** оверлей поднимает ровно то правило, чьё имя носит директория.

**Почему:** молчащая фикстура выглядит зелёной и не проверяет ничего.

### Односторонняя проба

**Плохо:** проверяется только срабатывание на дефекте.

**Правильно:** база даёт ноль, оверлей даёт находку - обе стороны.

**Почему:** правило, срабатывающее всегда, проходит одностороннюю пробу и ломает каталог.

### Побочные находки не названы

**Плохо:** оверлей поднимает ещё три правила, ожидание перечисляет одно.

**Правильно:** побочные правила перечислены в `also` файла `expect.json`.

**Почему:** неучтённая побочка маскирует поломку соседнего правила при рефакторинге.

### Фикстура на живом каталоге

**Плохо:** правило проверяется правкой реального артефакта с последующим откатом.

**Правильно:** прогон на песочнице через `MARKETPLACE_ROOT`.

**Почему:** ручной откат забывается, а проверка не остаётся регрессией.
