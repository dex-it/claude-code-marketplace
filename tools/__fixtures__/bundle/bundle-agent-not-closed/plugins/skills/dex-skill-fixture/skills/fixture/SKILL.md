# Фикстура trap-skill с делегированием

## Делегирование

Найденный дефект чинит `dex-fixture-specialist:fixture-agent` и возвращает статус.

Соседний разбор ведёт `dex-skill-peer:peer` - имя скилл-плагина, а не специалиста: у правила
два шаблона сообщения, и это второй.
