# Next Agent

Агент существует ради ребра handoff: содержание вторично, адресуемость первична.

## Phase 1: Intake

**Goal:** Принять выход предыдущего узла как свой вход.

**Input (handoff):** `[blocking]` результат предыдущего узла; `[default-ok]` режим (дефолт `autonomous`).

**Exit criteria:** Вход принят либо нехватка названа списком.

## Phase 2: Report

**Goal:** Отдать результат вызывающему.

**Output (handoff):** `status` (`complete`/`blocked`/`partial`), перечень находок, допущения.

**Exit criteria:** Output содержит `status` и перечень находок; пустой перечень назван явно.
