# Фикстура профильного скилла стека

Скилл существует ради двух рёбер оверлея и в состав бандла намеренно не входит.

### Исключение by-stack принято за общее

**Плохо:** профильный скилл стека молчит у любого потребителя.

**Правильно:** молчит там, где потребитель этот стек не заявляет своим предметом.

**Почему:** специалист по предмету грузит скилл всегда, а не «если в стеке» - молчание тут прячет дефект.
