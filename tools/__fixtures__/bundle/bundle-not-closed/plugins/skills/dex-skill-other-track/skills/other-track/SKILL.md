# Фикстура соседнего трека

Трек стоит в составе бандла и называет чужой трек - тот в состав не входит и входить не должен.

**Граница с соседями.** Работу за этой границей ведёт `dex-skill-zone-track:zone-track`.

### Общий сегмент имени принят за общий предмет

**Плохо:** два трека делят сегмент `track` и потому считаются предметом друг друга.

**Правильно:** `track` - родовое слово, предметом его не считать.

**Почему:** иначе каждый трек тянет за собой соседей по графу зон, и бандл роли везёт весь реестр.
