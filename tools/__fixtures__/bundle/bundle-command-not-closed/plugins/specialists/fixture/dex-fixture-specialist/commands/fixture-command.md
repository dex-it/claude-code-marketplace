# Прогон фикстуры

**Goal:** Прогнать валидатор на дереве-песочнице и назвать сработавшие правила.

**Output format:** перечень `правило -> уровень -> файл`; пустой перечень назван явно.

Разбор находок ведёт `dex-skill-fixture:fixture`.

Спорную находку пересуживает `dex-peer-specialist:peer-agent` - имя специалиста, а не скилла: у
правила два шаблона сообщения, и это второй.
