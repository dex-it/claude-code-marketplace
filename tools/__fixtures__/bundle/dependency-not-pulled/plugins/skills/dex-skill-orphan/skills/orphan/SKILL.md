# Фикстура записи без тянущего ребра

Скилл существует ради одной пробы: он в `dependencies[]`, но его никто не называет.

### Хвост удалённого компонента оставлен в списке

**Плохо:** компонент убран из состава, а подтянутые им записи остались.

**Правильно:** запись уходит вместе с ребром, которое её тянуло.

**Почему:** установка молча везёт лишнее, а список перестаёт отвечать на вопрос «зачем это здесь».
