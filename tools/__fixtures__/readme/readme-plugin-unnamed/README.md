# Fixture Marketplace

Витрина фикстурного каталога для песочницы валидаторов. Из перечня `Skills` снят
скилл `fixture`, из витрины плагинов - строка движка: слово `fixture` осталось в
прозе и во второй колонке строки специалиста, но покрытия это не даёт - имя
плагина читается только в позиции имени плагина. Два неназванных плагина дают
оба текста правила: короткая форма `fixture` делится с бандлом, короткая форма
движка не делится ни с кем.
