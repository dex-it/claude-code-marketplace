# Fixture Marketplace

Витрина фикстурного каталога для песочницы валидаторов. Три позиции имени, и в
каждой стоит мёртвое имя - у трёх проходов сверки общего кода нет, и смерть
одного из них остальными не видна.

| Bundle | Описание |
| --- | --- |
| `fixture` | Фикстурный бандл для песочницы валидатора |
| `fixture-ghost` | Строка бандла, ведущая на имя, которого нет в витрине |

| Плагин | Описание |
| --- | --- |
| dex-fixture-specialist | Фикстурный специалист для песочницы валидатора |
| dex-fixture-engine | Фикстурный движок песочницы |
| dex-skill-fixture-ghost | Строка витрины, ведущая на имя, которого нет |

| Категория | Skills |
| --- | --- |
| **Фикстура** | `fixture`, `fixture-skill-ghost` |
