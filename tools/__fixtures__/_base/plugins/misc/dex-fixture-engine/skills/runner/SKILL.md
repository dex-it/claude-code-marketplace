# Фикстура движка

Второй эталон нулевых находок: этот плагин везёт скилл `runner`, и записи с именем вида
`<префикс скилла>-runner` в витрине нет. README называет такой плагин **именем скилла** - на этом
держится обратная сверка `validate-readme.js`, и без этого файла её ветка свидетеля не имеет.

### Список исключений вместо дерева

**Плохо:** пара «имя скилла -> плагин» лежит константой в валидаторе.

**Правильно:** владельцы читаются с дерева при каждом прогоне.

**Почему:** список протухает молча, а дерево - тот же источник, по которому заполняется витрина.

### Свидетель только на живом каталоге

**Плохо:** ветка проверяется тем, что реальный README её задевает.

**Правильно:** ветка задета песочницей, и её глушение валит прогон фикстур.

**Почему:** живой каталог доказывает отсутствие предмета, а не работоспособность проверки.

### Короткая форма без позиции

**Плохо:** имя ищется как слово где угодно по файлу.

**Правильно:** имя читается в позиции, форму которой задаёт шапка таблицы.

**Почему:** короткая форма не инъективна, и покрытие закрывается чужой строкой.

### Образец записи принят за витрину

**Плохо:** строка таблицы внутри код-блока читается как имя плагина.

**Правильно:** код-блоки снимаются до разбора позиций.

**Почему:** образец закрывал бы покрытие собой и приезжал бы мёртвой ссылкой одновременно.

### Односторонняя сверка витрины

**Плохо:** проверяется только «каждый плагин назван».

**Правильно:** проверяется и обратное - каждое имя витрины ведёт в каталог.

**Почему:** переименование оставляет строку на мёртвое имя, и односторонний гейт на ней зелёный.

### Версия подвала без сверки

**Плохо:** номер в подвале витрины правится руками и ни с чем не сравнивается.

**Правильно:** подвал сверяется с версией каталога тем же прогоном.

**Почему:** третий носитель версии расходится молча - его никто не генерирует.
