## Словарь полей

| Поле | Смысл | Синонимы |
|---|---|---|
| `status` | исход узла, первым полем выхода | `complete`/`blocked`/`partial` |
| `diff-scope` | пути изменённых файлов + ветка/база | список путей |
| `run-status` | результат build/test/lint | зелёный/красный + что |
| `red-run` | чем доказано, что тест сторожит предмет | мутация + упавший тест |
| `uncovered` | что осталось непокрытым тестами | непокрытые ветки |
