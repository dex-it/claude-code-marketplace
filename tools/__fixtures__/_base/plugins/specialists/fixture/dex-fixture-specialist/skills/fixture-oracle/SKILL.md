# Фикстура скилла внутри специалиста

База песочницы для плагина, поставляющего и скиллы, и агентов: файл обязан давать ноль находок
всеми валидаторами. Содержание вторично, форма первична.

### Адрес агента судится как адрес скилла

**Плохо:** проверка ссылок команды, найдя у плагина хоть один скилл, судит `{plugin}:{агент}` тем же
перечнем и не находит агента среди скиллов.

**Правильно:** имя, совпадающее с агентом того же плагина, из проверки скилл-ссылок исключено.

**Почему:** вернётся прежний охват - база даст находку, и правило станет ложно срабатывать на
каждом смешанном плагине.

### Скилл внутри специалиста не найден

**Плохо:** перечень скиллов плагина собирается обходом только `plugins/skills/`.

**Правильно:** обход идёт по всему дереву, владелец берётся из ближайшего манифеста.

**Почему:** скилл, поставленный специалистом, иначе читается как несуществующий у своего же плагина.

### Имя скилла повторяет имя плагина-соседа

**Плохо:** скилл смешанного плагина назван так же, как скилл соседнего плагина.

**Правильно:** имя уникально в пространстве имён каталога.

**Почему:** адрес `{plugin}:{skill}` разрешается по паре, но два одинаковых имени в перечнях
неотличимы для читателя и для отбора по префиксу.

### Запись каталога выведена из места файла

**Плохо:** категория записи ставится по группе-папке, в которой лежит плагин.

**Правильно:** категория выводится из содержимого - `agents/` есть, значит специалист.

**Почему:** смешанный плагин лежит среди специалистов и несёт скиллы, и место о его типе не говорит.

### Скилл смешанного плагина назван в бандле отдельной строкой

**Плохо:** состав бандла перечисляет скилл смешанного плагина рядом с самим плагином.

**Правильно:** в составе стоит плагин; его скиллы приезжают вместе с ним.

**Почему:** имени-плагина у такого скилла нет, и строка ведёт в пустоту - установка её не разрешит.
