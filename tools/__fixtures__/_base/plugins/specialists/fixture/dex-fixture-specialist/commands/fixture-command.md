# Прогон фикстуры

**Goal:** Прогнать валидатор на дереве-песочнице и назвать сработавшие правила.

Порядок: оракул `dex-fixture-specialist:fixture-oracle` судит форму, прогон ведёт агент
`dex-fixture-specialist:fixture-agent` - скилл и агент одного плагина, адреса формой не различаются.

**Output format:** перечень `правило -> уровень -> файл`; пустой перечень назван явно.
