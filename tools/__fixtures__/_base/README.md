# Fixture Marketplace

Витрина фикстурного каталога для песочницы валидаторов. Три носителя имени в
одном файле: бандл назван короткой формой в таблице с шапкой `Bundle`, скилл -
короткой формой в перечне `Skills`, специалист - полным именем. Короткую форму
`fixture` делят бандл и скилл: кому она принадлежит, решает шапка таблицы.

| Bundle | Описание |
| --- | --- |
| `fixture` | Фикстурный бандл для песочницы валидатора |

| Плагин | Описание |
| --- | --- |
| dex-fixture-specialist | Фикстурный специалист для песочницы валидатора |

| Категория | Skills |
| --- | --- |
| **Фикстура** | `fixture` |
