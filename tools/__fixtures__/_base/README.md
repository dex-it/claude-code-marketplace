# Fixture Marketplace

Витрина фикстурного каталога для песочницы валидаторов. Три носителя имени в
одном файле: бандл назван короткой формой в таблице с шапкой `Bundle`, скилл -
короткой формой в перечне `Skills`, специалист - полным именем. Короткую форму
`fixture` делят бандл и скилл: кому она принадлежит, решает шапка таблицы.

Имя плагина - `dex-skill-<имя скилла>`, единственное исключение - движок
`dex-fixture-engine`, он назван в перечне `Skills` именем своего скилла
(`runner`).

| Bundle | Описание |
| --- | --- |
| `fixture` | Фикстурный бандл для песочницы валидатора |

| Плагин | Описание |
| --- | --- |
| dex-fixture-specialist | Фикстурный специалист для песочницы валидатора |
| dex-fixture-engine | Фикстурный движок песочницы: имя плагина не выводится из имени скилла |

| Категория | Skills |
| --- | --- |
| **Фикстура** | `fixture`, `runner` |

Образец строки витрины - в код-блоке: имени плагина в нём нет, есть форма записи.

```markdown
| Плагин | Описание |
| --- | --- |
| dex-fixture-example | Плагина с таким именем в витрине нет |
```
