# Артефакт уровня: вердикт записан колонкой таблицы

Форма записи - та, которой пакеты каталога пишут вердикты уровней; `status`
пакета живёт в соседнем файле, поэтому конфликт собирается только по директории.

## `quality-checks` артефакта

| Артефакт | Проверка | Вердикт |
|---|---|---|
| фикстура | `requirement-set-quality` | `failed` -> находки закрыты решениями D-1 ... D-4 |

| Артефакт | Статус | Почему не выше |
|---|---|---|
| фикстура | `review` | апрува оператора в `autonomous` нет |
