# Прогон фикстуры

**Goal:** Прогнать валидатор на дереве-песочнице и назвать сработавшие правила. Перед прогоном
вызови `Skill` -> `dex-skill-fixture:nosuch`.

**Output format:** перечень `правило -> уровень -> файл`; пустой перечень назван явно.
