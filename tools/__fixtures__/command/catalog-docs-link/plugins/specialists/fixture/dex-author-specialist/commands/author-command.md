# Прогон фикстуры

**Goal:** Прогнать валидатор на дереве-песочнице и назвать сработавшие правила.

**Output format:** перечень `правило -> уровень -> файл`; пустой перечень назван явно.

## Пороги

Пороги правил - `docs/CORPUS.md`: артефакт автора исполняется в клоне каталога, где `docs/` лежит рядом, поэтому адрес у него разрешается.
