## {N}. `src/router.js` - маршрутизатор путей
`export class Router`; шаблон - `/`-сегменты: статический, `:name` (один непустой сегмент), `*name` (остаток пути).

- `add(method, pattern, handler)` -> сам роутер (цепочкой). `method` регистронезависим. `handler` - любое значение,
  `match` возвращает его как есть. Один завершающий `/` в шаблоне игнорируется (`/a/` == `/a`); корень - `/`.
- `add` бросает `TypeError`: `method` или `pattern` не строка; `pattern` не начинается с `/`; пустое имя (`/a/:`,
  `/a/*`); `*name` не последний сегмент (`/a/*r/b`). Дубль (тот же метод и шаблон после нормализации, имена
  параметров не учитываются: `/u/:id` и `/u/:uid`) - `Error`, но не `TypeError`. `/a/:x` и `/a/*x` - не дубли.
- `match(method, path)`: от первого `?` в `path` всё отбрасывается; один завершающий `/` игнорируется.
- `:name` берёт непустой сегмент, `*name` - весь остаток, в т.ч. пустой (`/f` и `/f/` подходят под `/f/*p`, `p` = `''`);
  остаток - сегменты через `/`. Статический сегмент сравнивается с сегментом пути как есть, без декодирования.
- Приоритет сегмента слева направо: статический > `:name` > `*name`. Если выбранная ветка не дала совпадения глубже
  (в т.ч. нет обработчика метода в конце), поиск откатывается к ветке следующего приоритета.
- Значения `:name` и `*name` проходят `decodeURIComponent`; ветка с некорректной escape-последовательностью
  (`%E0%A4%A`) не совпадает. Остаток `*name` декодируется целиком (`%2F` даёт `/`).
- `HEAD`: сначала ищется совпадение для `HEAD` по всем шаблонам; только если его нет - для `GET`.
- Совпадение: `{ handler, params }`, `params` - обычный объект `{}` (без параметров - пустой).
- Путь не подходит ни под один шаблон (с любым методом) -> `{ status: 404 }`. Путь подходит под шаблоны, но не для
  этого метода -> `{ status: 405, allow }`: отсортированные методы в верхнем регистре из всех подошедших под путь
  шаблонов, без дублей (`HEAD` сам по себе не добавляется).
- Примеры (маршруты `GET`; `a`, `b` - обработчики): `/u/:id`, `match('GET','/u/a%20b?x=1')` -> `{ handler: a, params:
  { id: 'a b' } }`; `/f/*p`: `match('get','/f/x/y/')` -> `{ p: 'x/y' }`, `match('GET','/f')` -> `{ p: '' }`;
  `/a/b/c`, `/a/:x/d`, `/a/*r`: `match('GET','/a/b/d')` -> `{ x: 'b' }` (откат), `/a/b/e` -> `{ r: 'b/e' }`;
  только `POST /p`: `match('GET','/p')` -> `{ status: 405, allow: ['POST'] }`, `match('GET','/q')` -> `{ status: 404 }`;
  `add('GET','/a',h).add('GET','/a/',h)` -> `Error`; `add('GET','a',h)` -> `TypeError`.
