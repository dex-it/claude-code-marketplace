## {N}. `src/diff.js` - построчный diff (LCS) и unified-формат
- Разбиение на строки: по `\n`; завершающий `\n` лишней пустой строки не даёт; `""` -> 0 строк; `"\n"` -> одна пустая
  строка; `\r` не трогается. Строки сравниваются точно, наличие завершающего `\n` на сравнение не влияет.
- `diffLines(a, b)` -> массив `{ op: 'equal'|'delete'|'insert', line }` в порядке прохода. Число `delete`+`insert`
  минимально (`equal` - наибольшая общая подпоследовательность строк). `a`/`b` не строки - `TypeError`.
- Однозначность. Пусть `L(i, j)` - длина LCS хвостов `a[i..]` и `b[j..]`. Проход с `i = j = 0`: если `a[i] === b[j]` -
  `equal`, оба вперёд; иначе при `L(i, j+1) >= L(i+1, j)` (в том числе при равенстве) - `insert b[j]`, иначе -
  `delete a[i]`; хвост одной стороны дорабатывается `delete` либо `insert`. Затем в каждом непрерывном блоке
  не-`equal` операций все `delete` идут перед всеми `insert`, порядок внутри групп сохраняется.
- `unifiedDiff(a, b, options = {})` -> строка. Равные по строкам `a` и `b` -> `""`. Иначе: `--- <fromFile>`,
  `+++ <toFile>` (`options.fromFile`/`toFile`, по умолчанию `a`/`b`; без меток времени), затем ханки; строки вывода
  соединяются `\n`, в конце один `\n`. Строка ханка: пробел (equal), `-` (delete), `+` (insert) и текст строки.
- `options.context` - число контекстных строк с каждой стороны, по умолчанию 3 (и при `undefined`). Не целое или
  меньше 0 (`1.5`, `-1`, `NaN`, `Infinity`, `"2"`) - `RangeError`. `options` не `undefined` и не объект (в т.ч. `null`)
  - `TypeError`. Аргументы проверяются до вычислений, в том числе при равных `a` и `b`.
- Ханки: блоки изменений, между которыми не более `2 * context` строк `equal`, входят в один ханк; ханк начинается
  за `context` строк до первого изменения и кончается через `context` после последнего, не выходя за текст.
- Заголовок `@@ -S,L +S,L @@` (старая сторона - `a`, новая - `b`), нумерация с 1, `L` - число строк ханка на стороне.
  `L = 1` -> пишется только `S`; `L = 0` -> `S,0`, где `S` - номер строки перед диапазоном (0 в начале), как в GNU diff.
- Примеры: `diffLines("a\nb", "a\nc")` -> `equal a`, `delete b`, `insert c`; `diffLines("a\nb", "b\na")` -> `insert b`,
  `equal a`, `delete b`; `diffLines("", "x\n")` -> `[insert x]`; `diffLines("x\n", "x")` -> `[equal x]`.
- `unifiedDiff("a\nb\nc\n", "a\nX\nc\n")` -> `"--- a\n+++ b\n@@ -1,3 +1,3 @@\n a\n-b\n+X\n c\n"`;
  `unifiedDiff("x", "x\n")` -> `""`; `unifiedDiff("", "p\nq\n")` -> `@@ -0,0 +1,2 @@`; обратно -> `@@ -1,2 +0,0 @@`.
- Строки `1..9`, `2` -> `A`, `8` -> `B`: `context: 2` -> ханки `@@ -1,4 +1,4 @@` и `@@ -6,4 +6,4 @@` (5 `equal` > 4);
  `context: 3` -> один `@@ -1,9 +1,9 @@`.
