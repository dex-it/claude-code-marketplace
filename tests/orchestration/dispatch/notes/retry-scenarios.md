# Проверка пересказом: суд провала, повтор, «сам» в цепочке

Читатель - свежий субагент `sonnet` `medium` без контекста правки. Ему дают путь к `SKILL.md` скилла
`subagent-dispatch` и вопросы R1-R12 без колонки «Ожидание»; другие файлы он не открывает. Ответ на
каждый вопрос - действие (тир следующего запуска, кто делает) и цитата пункта, затем отдельно места,
прочитанные двояко. Кейс засчитан, когда ответ совпал с ожиданием и читатель не назвал второго
прочтения этого места.

Во всех вопросах читатель - оркестратор `opus`, кусок с приёмочной проверкой вне дерева.
