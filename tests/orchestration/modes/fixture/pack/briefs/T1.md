# Бриф T1: пометка готовности

Ты исполнитель одной задачи большого плана. Она нужна для проверки конвейера; результат прочтёт оркестратор.

## Задача
Файл out/t1.txt содержит одну строку: ok

## Входы
Нет.

## Ограничения
Пишешь только out/t1.txt.

## Право записи
Пишешь только: out/t1.txt. Остальное - только чтение.

## Выход
- out/t1.txt: одна строка `ok`

## Готово, когда
- файл существует и содержит ровно `ok`

## Проверка
`python3 pack/checks/t1.py`

## Границы
Работаешь один и в пределах брифа: субагентов не запускаешь, найденное сверх брифа записываешь в NEW_SUBTASKS.

## Возврат
RESULT: DONE | DONE_WITH_CONCERNS | NEEDS_CONTEXT | BLOCKED
ARTIFACTS: пути
EVIDENCE: 1-3 строки, «команда -> результат»
NOT_CHECKED: что не проверено и почему
NEW_SUBTASKS: цель одной строкой каждая, либо «нет»
