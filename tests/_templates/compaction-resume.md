# Шаблон: компакт посреди автономного прогона

> Копируется в папку фичи под именем `scenario-compaction-resume.md`; «Вход» и «Состояние на момент компакта» заполняются под задачу.

**Известное расхождение с текущей реализацией (остаётся открытым, отдельная работа):** шаблон ниже писан под
механизм task-флаг сессии + `session_id`-поиск (движок `autonomous-task`, хук
`dex-autonomous-task-resume`). Движок переименован в `dex-sdlc:engine`, хук - в `dex-sdlc-resume`,
и возобновление переписано на **только** auto-ledger (буквальный контракт `Статус: открыт/закрыт`
в `auto-ledger/` папки сессии, без task-флага и без
`session_id`-поиска - см. `plugins/ai-sdlc/dex-sdlc-resume/hooks/scripts/resume-reminder.sh`).
Ниже - идентификаторы обновлены, но точки проверки и обязательный набор случаев живого прогона
писаны под старый (task-флаг) механизм и под новый не переизложены - отдельная работа.

**Вход:** автономный прогон движка (`dex-sdlc:engine`) идёт долго - контекст переполняется, срабатывает auto-compaction. Прогон продолжается в том же сеансе, с тем же `session_id`.

**Маршрут:** движок -> компакт -> хук `dex-sdlc-resume` -> возобновление -> продолжение цели.

Проверяет **не качество работы, а выживание нормы**: после компакта модель видит усечённый движок и не видит файл трека, но продолжает считать, что работает по правилам.

## Что происходит на платформе (проверяется по документации, не по памяти)

| Факт | Источник |
|---|---|
| Компакт переносит последний вызов каждого скилла, **первые 5000 токенов**; общий бюджет реаттача на все скиллы - 25000, ранние вытесняются целиком | [skills](https://code.claude.com/docs/en/skills), «Skill content lifecycle» |
| Полный текст восстанавливает **перевызов скилла** после компакта | там же |
| Файл, прочитанный через `Read` (в т.ч. файл трека), реаттачу не подлежит - это не скилл | там же, от противного: реаттач описан только для скиллов |
| `SessionStart` поддерживает matcher `compact` и получает `session_id` в stdin | [hooks](https://code.claude.com/docs/en/hooks) |
| `hookSpecificOutput.additionalContext` подмешивается в начало разговора после компакта | там же |

Утверждение движка о любом из этих механизмов сверяется с источником заново на дату прогона: расхождение текста с платформой - находка сорта «предписывает».

## Точки проверки

| Точка | Провал, если |
|---|---|
| Граница усечения | нормативный дом, нужный сразу после компакта (процедура возобновления), лежит за первыми 5000 токенами файла - реаттач его не донесёт |
| Карта носителя | в уцелевшем начале нет оглавления: модель не видит, что файл обрезан, и принимает усечение за целый текст |
| Первое действие | процедура возобновления не начинается с перевызова самого движка - модель доводит работу по обрезку, считая её полной |
| Путь к треку | путь в процедуре не резолвится из проекта пользователя (относительный вместо `${CLAUDE_PLUGIN_ROOT}`) - Read падает, шаг закрывается молчанием |
| Якорь состояния | возобновление опирается на память о ходе работы, а не на переживающий компакт носитель (task-флаг + auto-ledger вне рабочего дерева) |
| Хук: срабатывание | флаг сессии есть, а напоминание не выдано - или выдано при закрытом флаге (ложное срабатывание на каждый компакт) |
| Хук: содержание | напоминание пересказывает шаги возобновления вместо отправки к скиллу - копия разойдётся с нормой молча |
| Хук: деградация | отсутствие `jq`, каталога задач или `session_id` роняет хук ненулевым кодом вместо тихого выхода |
| Кросс-файловые отсылки | норма, нужная после компакта, адресована в файл, который в контекст не грузится (дельта чужого трека) |

## Живой прогон хука

Виртуальной трассировкой хук не закрывается - это исполняемый скрипт, проверяется запуском на синтетическом `HOME`:

```
HOME=<песочница> bash hooks/scripts/resume-reminder.sh <<< '{"session_id":"<SID>"}'
```

Обязательный набор случаев: незакрытый флаг -> напоминание; флаг `completed` -> пусто; флага нет -> пусто; каталога сессии нет -> пусто; каталог пуст -> пусто; `session_id` отсутствует -> пусто; флаг не первым файлом по алфавиту -> найден; `jq` вне `PATH` -> пусто + предупреждение в stderr, `rc=0`. В отчёт идут код возврата и размер stdout по каждому случаю, не «работает».

## Отрицательный путь

Отдельным прогоном: компакт при **закрытой** цели (флаг снят). Ожидаемое - хук молчит, возобновление не запускается. Провал - напоминание приходит на каждый компакт независимо от состояния и обесценивается.
