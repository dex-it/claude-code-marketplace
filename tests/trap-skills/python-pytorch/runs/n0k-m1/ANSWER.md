**Описание MR: SW-263, метрики `weighted_f1` и `top_k_accuracy`**

- **`weighted_f1(y_true, y_pred)`**:
  - F1 считается по каждому классу из `y_true`. Результат усредняется с весами, равными числу объектов класса в `y_true`.
  - Классы, которые есть только в предсказаниях, получают нулевой вес и в сумму не входят.
  - Пустой ввод или разная длина дают `ValueError`.
- **`top_k_accuracy(y_true, scores, k)`**:
  - `scores[i][c]` — оценка класса `c` для объекта `i`, а `y_true[i]` — индекс столбца.
  - Объект засчитывается, если его истинный класс входит в `k` лучших по оценке.
  - При равных оценках выше стоит класс с меньшим индексом, поэтому результат детерминирован.
  - `k > числа классов` даёт 1.0.
  - `ValueError` выбрасывается при `k < 1`, пустом вводе, разной длине `y_true` и `scores` и при метке вне диапазона столбцов.
