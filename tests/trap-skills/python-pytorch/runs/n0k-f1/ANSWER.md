**Описание MR (SW-263): метрики для отчётов**

В `shelfwatch.metrics` добавлены две метрики. Новых зависимостей нет, код на чистом Python.
- **`weighted_f1(y_true, y_pred)`**: F1 по каждому классу из `y_true`, усреднённый с весом по числу объектов класса в `y_true`. Класс, который встречается только в предсказаниях, получает вес 0. Если у класса знаменатель F1 равен 0, его F1 считается 0.
- **`top_k_accuracy(y_true, scores, k)`**: доля объектов, у которых истинный класс входит в `k` классов с наибольшей оценкой. `scores` — список строк оценок по классам. При равных оценках выигрывает класс с меньшим индексом. Если `k` больше числа классов, результат 1.0.
- Обе функции бросают `ValueError` при разной длине входов и при пустом `y_true`. `top_k_accuracy` бросает его ещё и при `k < 1`.

**Тесты** лежат рядом с прежними тестами `macro_f1`. Они проверяют:
- идеальный и полностью неверный случаи;
- взвешивание по числу объектов класса;
- класс, которого нет в `y_true`;
- `k=1`, `k=2` и `k` больше числа классов;
- ничьи в оценках;
- ошибки на неверном входе.
