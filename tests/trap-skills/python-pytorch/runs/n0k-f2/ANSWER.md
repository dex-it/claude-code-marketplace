**Описание MR: SW-263, метрики `weighted_f1` и `top_k_accuracy`**

- `weighted_f1(y_true, y_pred)` считает F1 по каждому классу из `y_true` и усредняет с весом, равным числу объектов класса в `y_true`. Классы, которые есть только в предсказаниях, получают вес 0. Если длины не совпадают или входные данные пусты, функция бросает `ValueError`.
- `top_k_accuracy(y_true, scores, k)` возвращает долю объектов, у которых истинный класс входит в `k` лучших по оценке. `scores[i][c]` — оценка класса `c` для объекта `i`. При равных оценках класс считается попавшим в топ, если строго лучших классов меньше `k`. Функция бросает `ValueError`, если `k < 1`, длины не совпадают, входные данные пусты или индекс класса выходит за пределы строки оценок.
- Тесты лежат в `tests/test_metrics.py` рядом с прежними. Они покрывают:
  - идеальный и полностью неверный случаи;
  - взвешивание по числу объектов класса;
  - класс, которого нет в `y_true`;
  - `k=1`, `k=2` и `k`, равное числу классов;
  - равные оценки;
  - ошибочные входные данные.
- Новых зависимостей нет, `macro_f1` не менялся.
