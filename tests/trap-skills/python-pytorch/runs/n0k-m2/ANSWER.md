**Описание MR (SW-263: метрики для отчётов)**

В `shelfwatch.metrics` добавлены две функции на чистом Python, новых зависимостей нет:
- `weighted_f1(y_true, y_pred)` считает F1 по каждому классу и усредняет с весом, равным числу объектов класса в `y_true`. Класс, который есть только в `y_pred`, получает нулевой вес, но его ложные срабатывания снижают precision других классов. Существующий `macro_f1` не менялся.
- `top_k_accuracy(y_true, scores, k)` возвращает долю объектов, у которых истинный класс входит в `k` лучших по оценке. Класс — это индекс столбца в строке `scores`. При равных оценках раньше идёт класс с меньшим индексом, так что результат детерминирован. Если `k` больше числа классов, результат равен 1.0.
- Обе функции бросают `ValueError` на пустой вход и на разную длину входов. `top_k_accuracy` также бросает его при `k < 1`.

Тесты в `tests/test_metrics.py`:

- `top_k_accuracy`: `k=1`, `k=2`, `k` больше числа классов, ничьи, ошибки на некорректном входе.
