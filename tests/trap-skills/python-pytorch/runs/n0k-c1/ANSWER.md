**Описание MR (SW-263): метрики `weighted_f1` и `top_k_accuracy`**

В `shelfwatch.metrics` добавлены две метрики для отчётов, новых зависимостей нет.
- **`weighted_f1(y_true, y_pred)`**: F1 считается по каждому классу из `y_true`, затем усредняется с весом, равным числу объектов класса в `y_true`. Классы, которые есть только в `y_pred`, получают вес 0.
- **`top_k_accuracy(y_true, scores, k)`**: это доля объектов, у которых истинный класс входит в k классов с наибольшей оценкой. Номер класса — индекс столбца в строке `scores`.
  - **Ничьи по оценке:** класс засчитывается, если строго больших оценок у него меньше k.
  - **Ошибки ввода:** при `k < 1` или пустом `y_true` обе функции (для `weighted_f1` — только пустой `y_true`) выбрасывают `ValueError`.

**Тесты** в `tests/test_metrics.py`:
- `weighted_f1`: идеальный случай, взвешивание по поддержке класса, класс, которого нет в `y_true`.
- `top_k_accuracy`: k=1 (совпадает с обычной accuracy), k=2, k равен числу классов.
