**Описание MR: SW-263, метрики `weighted_f1` и `top_k_accuracy`**

- `weighted_f1(y_true, y_pred)` считает F1 по каждому классу из `y_true` и усредняет с весом, равным числу объектов класса в `y_true`. Классы, которые есть только в `y_pred`, получают вес 0, как в sklearn.
- `top_k_accuracy(y_true, scores, k)` возвращает долю объектов, у которых истинный класс входит в `k` классов с наибольшей оценкой. Индекс класса — номер столбца в строке `scores`.
- При равных оценках класс попадает в top-k, если строго лучших классов меньше `k`. Это оптимистичное правило, оно описано в докстринге и покрыто тестом.
- Обе функции бросают `ValueError` при пустом входе и при разной длине `y_true` и `y_pred` (или `scores`). `top_k_accuracy` бросает его ещё при `k < 1` и при метке вне диапазона строки оценок.
- Новых зависимостей нет, реализация на чистом Python в стиле `macro_f1`.
- Тесты в `tests/test_metrics.py`:
  - `weighted_f1`: идеальный случай, все ошибки, взвешивание по support, класс только в `y_pred`, некорректный вход;
  - `top_k_accuracy`: `k=1`, `k=2`, `k` равно числу классов, ничьи, некорректный вход.
