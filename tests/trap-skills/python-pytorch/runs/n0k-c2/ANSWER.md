**Описание MR: SW-263, метрики `weighted_f1` и `top_k_accuracy`**

- `weighted_f1(y_true, y_pred)` считает F1 по каждому классу из `y_true` и усредняет с весом, равным числу объектов класса в `y_true`. Классы, которые есть только в `y_pred`, получают нулевой вес.
- `top_k_accuracy(y_true, scores, k)` возвращает долю объектов, у которых истинный класс входит в `k` классов с наибольшей оценкой. `scores[i][c]` — оценка класса `c` для объекта `i`. При равных оценках выигрывает класс с меньшим индексом.
- Обе функции бросают `ValueError` при разной длине входов и при пустом входе. `top_k_accuracy` бросает его и при `k < 1`.
- Расчёт F1 одного класса вынесен в общий хелпер `_class_f1`, его теперь используют `macro_f1` и `weighted_f1`. Поведение `macro_f1` не изменилось.
- Новых зависимостей нет.
- Новые тесты:
  - **`weighted_f1`:** идеальный и полностью неверный случаи, учёт весов, класс, которого нет в `y_true`, пустой вход.
  - **`top_k_accuracy`:** `k=1`, `k=2`, `k` больше числа классов, некорректные аргументы.
