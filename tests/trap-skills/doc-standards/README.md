DR3 `c1`-`c4` 4/4 (ручной пересчёт c4 в 3/4 - только в этом README, `judge.json` не правлен), набор `s` без пункта
1/4, `u` с пунктом 4/4. Снятие измерено и показало вред (1/4 против 4/4), поэтому пункт остаётся; пользы против
контроля у него нет. Решение владельца (ревью #365): пункт остаётся, просадка DR3 ради размера скилла не
принимается.
