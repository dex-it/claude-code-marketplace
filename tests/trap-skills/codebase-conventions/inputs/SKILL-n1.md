# Конвенции проекта - чек-лист

Новый код и находка ревью стоят на названном источнике конвенции проекта: `Accepted` ADR сильнее принятой единицы свода правил, свод сильнее соседнего кода того же типа.

- Doc-комментарий называет потребителя типа
- Имя класса или метода не сменено вслед за поведением
