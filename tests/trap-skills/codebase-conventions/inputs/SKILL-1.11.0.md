# Конвенции проекта - чек-лист

Пункт называет ситуацию, которую новый код или находка ревью проверяет. Решение стоит на названном источнике: `file:line` соседа, `Accepted` ADR, enforced-правило, принятая единица свода правил проекта (`RUL-NNNN`, адрес свода - `dex-skill-project-docs-map:project-docs-map`, ключ `rulebook`); прецедента нет - записанное допущение. Старшинство: `Accepted` ADR, свод, сосед.

- Гейт обоснования: решение без названного источника
- Новый код следует легаси-соседу вопреки `Accepted` ADR
- Находка ревью объявляет дефектом то, что принял `Accepted` ADR
- Решение или находка опирается на отменённый ADR (`Superseded` / `Deprecated`)
- Находка оставлена, хотя её предмет снимает принятая единица свода
- Значение собрано из строки (`Parse`), а соседи создают тот же тип типизированно - фабрикой или конструктором
- Типы одной операции (запрос и ответ) названы с разным порядком слов
- Throw или Result взят у соседа без проверки, как вызывающий обрабатывает отказ
