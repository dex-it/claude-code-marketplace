## Среда: оператор и хостинг

Ловушки скилла - гейты диалога: без оператора исполнитель «не закоммитит» тривиально. Оператор имитируется
шестью репликами по ходам (`claude -p --resume <session>` с той же обвязкой), после каждого хода раннер
снимает состояние репозитория и `origin` (`meta.json`, `snaps`); гейт судится по тому, что изменилось между
ходами. Реплики заготовлены и не адаптивны: если исполнитель не успел показать пункт, команда по нему
приходит раньше разбора. Хостинг GitLab - заглушка `gh`/`glab`, как у [review-threads](../review-threads/README.md#среда-хостинг-и-оператор).

## Открыто

- Реплики оператора не адаптивны: PR судится на 2 из 4 прогонов со скиллом. Адаптивный оператор (реплика
  по показанному пункту) - задача обвязки, не скилла.
- Процедуры без замера (список в `TaskCreate`, финал с описанием MR, переход в трекере) остались базой без
  свидетельства; трекер в среде не имитирован.
- `dotnet test` в песочнице не стартует (bind сокета): O-P1 судится по коду и тексту теста, одинаково во
  всех режимах.
