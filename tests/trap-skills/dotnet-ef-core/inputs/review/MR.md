# MR !4127: сервисы заказов и каталога для админки

Добавляет в Shop.Data сервисы для админки и фоновый воркер.

- OrderQueries: карточка заказа, выгрузка заказов клиента (у крупных клиентов тысячи заказов), продукт по SKU, дата последней отгрузки клиента.
- OrderAdmin: правка заказа операторами (в админке несколько операторов правят заказы одновременно), пересчёт суммы заказа, отчёт по просроченным заказам.
- CatalogService: резерв остатка, поиск продуктов с динамическим фильтром, переоценка категории.
- OverdueNotifier: фоновый воркер, раз в минуту пишет AuditLog по просроченным заказам.
- Миграция: категории заказов выносятся в таблицы Categories + OrderCategories.

Изменённые файлы: Services/OrderQueries.cs, Services/OrderAdmin.cs, Services/CatalogService.cs, Workers/OverdueNotifier.cs, Migrations/20260920_OrderCategories.cs, Program.cs.
Остальные файлы каталога - существующий код проекта, в MR не менялись.
Контекст модели: один SKU лежит на нескольких складах, на одном складе уникален; Product.Price - цена за единицу, OrderItem.Qty - количество.
