# Entity Framework Core - чек-лист

Пункт называет ситуацию, в которой нужна проверка. Решение - по официальной документации EF Core / Npgsql версии из манифеста проекта, а не по памяти.

- Условие фильтра, которое EF может не транслировать в SQL, досчитывается после материализации
- Выборка только для чтения попадает в Change Tracker
- `DateTime` и тип колонки: с Npgsql 6 свойство без явного типа - `timestamptz`; `Kind` против типа колонки при записи, чтении и в параметре запроса
- Soft-delete (`HasQueryFilter`) при required FK: `OnDelete` каждой связи - каскад в БД и удаление сирот в коде
- Миграция на production: какой SQL уйдёт и кто увидит его до применения
