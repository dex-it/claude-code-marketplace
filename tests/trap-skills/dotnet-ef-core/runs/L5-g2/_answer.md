Решения:
- Список `customerIds` приходит из внешней (маркетинговой) системы и может быть большим, поэтому он бьётся на пачки по 500 через `Chunk`, чтобы не строить один огромный `IN (...)`/параметр-массив за раз.
- Запрос выборки email - только на чтение: `AsNoTracking()` плюс проекция `Select(c => c.Email)`, без подгрузки лишних полей и навигаций (`Orders` и т.д.).
- Фильтр `batch.Contains(c.Id)` по локальному массиву `Guid[]` транслируется Npgsql в `= ANY(@p)`, то есть остаётся translatable-запросом, а не клиентской фильтрацией.
