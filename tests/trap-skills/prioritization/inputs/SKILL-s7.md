# Prioritization - чек-лист

Пункт называет ситуацию, которую приоритизация проверяется на присутствие.

- Effort без единицы или в разных единицах
- Confidence 100% без данных
- Кандидат поднят по слову руководителя без сравнения цифрами с остальными; решение по числам (RICE, ёмкость), согласованное с руководителем, - не находка
- P0 у большинства кандидатов
