**Описание MR: SW-261, тональность отзывов и сводчик**

*Тональность*
- `train_sentiment` дообучает `DeepPavlov/rubert-base-cased` на `reviews.parquet` по колонке `split`. Метрика на проверке: macro-F1.
- Токенизация идёт одним вызовом на всю пачку.
- Прогрев задан как `warmup_steps=0.1`: в transformers 5.x поля `warmup_ratio` нет.
- Модель и токенизатор сохраняются в `artifacts/sentiment/`.
- `classify(texts) -> list[int]` грузит модель с `local_files_only=True` на CPU и кэширует её. Тексты обрабатываются пачками по 32.
- Квантование не применялось: в задаче нет бюджета задержки.
- Тексты режутся до 512 токенов, потому что у BERT 512 позиций, а отзывы бывают до 600. Хвост длинных отзывов теряется.

*Сводчик*
- `train_summarizer` делает QLoRA для `Qwen2.5-7B-Instruct`: база в 4 битах (nf4) на одной GPU, обучается только LoRA-адаптер (r=16, все linear-слои).
- Лосс считается только по токенам сводки, промпт маскируется.
- После обучения адаптер вливается в базу в bf16 и сохраняется в `artifacts/summarizer/` как обычная модель.
- `peft` и `bitsandbytes` импортируются только внутри `train_summarizer`. Сервису разметки `peft` не нужен, это проверяет отдельный тест.
- `summarize(reviews) -> list[str]` возвращает по одной сводке на каждый отзыв. Генерация жадная, с `no_repeat_ngram_size=3` и `repetition_penalty=1.1`.

*Тесты* (без загрузки весов): роли сообщений, маскирование промпта, обрезка отзыва без обрезки сводки, `warmup_steps` в долях, отсутствие `peft` после импорта модуля, пустой вход.
