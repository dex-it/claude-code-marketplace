# dotnet-testing-patterns: сжатие по свидетельству, группа 2.2

Скилл `dex-skill-dotnet-testing-patterns` 2.0.1 ([`inputs/SKILL-2.0.1.md`](inputs/SKILL-2.0.1.md)), эпик
#291, группа 2.2 (#297). Итог - 2.1.0 ([`inputs/SKILL-2.1.0.md`](inputs/SKILL-2.1.0.md)): два пункта из
семи ловушек.

## Заход

Вход, исполнитель и расход группы - протокол
[dotnet-resilience](../dotnet-resilience/README.md#заход-группы-22). Кейсы скилла: G-T (код), RV-T
(ревью); приманки G0, RV0 (P0-T1, P0-T2).

## Потребители

Бандлы `dotnet-developer`, `dotnet-fullstack`, `qa-engineer`; Skill tool в фазе: `dotnet-coder`,
`dotnet-test-writer`, `test-automator` (`[справочно]`); by-stack через `stack-registry`:
`discover-reviewer`. Кейс активации `dotnet-testing-in`.

## Вердикт

Одна ревизия: [`SKILL-n1.md`](inputs/SKILL-n1.md) = 2.1.0, наборы `n` и `f` по 2 прогона на G0, G-T,
RV-T.

| Единица 2.0.1 | Кейс | Контроль | n | f | Исход |
|---|---|---|---|---|---|
| T1 | G-T, RV-T | 2/2, 0/2 | 2/2, 2/2 | 2/2, 2/2 | пункт-название |
| T3 | RV-T | 0/2 | 2/2 | 2/2 | пункт-название |
| T2, T4-T7 | см. «Контроль» | 2/2 | 2/2 | 2/2 | сняты, клетки охвата держатся без пунктов |

**Приманки.** RV-T: P-T1 (`Verify` уведомления - наблюдаемый исход) и P-T2 (`Theory` с данными) не
провалены ни в одном прогоне. G0: G0-P 4/4, T2 и T7 (Н) 4/4. G-T: P-T 4/4. RV0: P0-T1, P0-T2 не
провалены. O-T (цена поставщика без `Currency`) - 0/4, как в контроле.

**Дом единиц тестовой тройки** (#297, «До кейсов»). T5 (`DateTime.Now` в коде) и T6 (`Task.Delay` в
тесте) сняты по контролю 2/2; `DateTime.Now` в `testability` тоже снят контролем (4/4, протокол
[testability](../testability/README.md)) - дом не нужен. Языконезависимого дома нет: `test-design` снят
(#299, PR #317), его протокол оставил пересечение этому набору. T1 (проверка реализации мока вместо
поведения) остаётся здесь по своему провалу контроля (RV-T 0/2); стековый двойник - V10 `ts-vitest-jest`,
by-stack грузится один из них, каждый держится свидетельством своего набора.

## Открыто

- T1: двойник V10 в `ts-vitest-jest` не сжимался, его «Открыто» откладывает дом до merge #317 (протокол
  [ts-vitest-jest](../ts-vitest-jest/README.md)); со стороны этого набора общий дом не нужен - T1 держится своим кейсом.
