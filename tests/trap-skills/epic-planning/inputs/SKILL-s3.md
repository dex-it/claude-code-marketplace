# Epic Planning - чек-лист

Пункт называет ситуацию, которую эпик проверяется на присутствие.

- Цель эпика без ограничения «не должно ухудшиться»
- Оценка эпика с ложной точностью
- Весь объём эпика по его оценке - одна история; детализирована одна история из нескольких - не находка
