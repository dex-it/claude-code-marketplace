# Epic Planning - чек-лист

Пункт называет ситуацию, которую эпик проверяется на присутствие.

- Цель эпика задана изменением метрики, а ограничения «не должно ухудшиться» у неё нет
- Оценка эпика с ложной точностью
- Эпик по своей оценке - одна история; эпик с оценкой категорией или сроком, у которого пока детализирована одна история, - не находка
