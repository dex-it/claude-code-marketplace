# testability: сжатие по свидетельству, группа 1.1

Скилл `dex-skill-testability` 1.1.2 ([`inputs/SKILL-1.1.2.md`](inputs/SKILL-1.1.2.md)) -> 1.2.0
([`inputs/SKILL-1.2.0.md`](inputs/SKILL-1.2.0.md)), эпик #291, группа 1.1 (#293).

Вход - общий мини-проект [`_projects/billing`](../_projects/billing/README.md), кейсы S2, S4, ключ
там же. Исполнитель - `claude-sonnet-5-5` (алиас `sonnet`), effort не задан (наследуется), субагент
`general-purpose` без `Skill` tool, сборка и dotnet разрешены. Прогоны `c` - контроль без скилла,
`v` - со скиллом: промпт дополнен строкой «Перед работой прочитай <SKILL> - дисциплина, принятая в
команде», копия `SKILL.md` подана путём.

Контроль S2 общий с группой 1.1, его `REVIEW.md` - в протоколе
[owasp-security](../removed/owasp-security/README.md) (`runs/s2-*`). S4 - ветка под ловушки, которых
S2 не покрывал: тесты требует задача, тесты ветки зелёные только в зоне МСК.

## Потребители

Skill tool в фазе: `mr-reviewer`, `mr-check-reviewer`, `self-reviewer` (ось `regressions`),
`bug-finder`, `discover-reviewer`, `dotnet-coder`, `dotnet-test-writer`; тематическая строка
`stack-registry`; сноска `integration-boundary`. Бандлы: `code-review`, `bug-lifecycle`, `architect`,
`dotnet-developer`, `dotnet-fullstack`, `ts-fullstack`, `qa-engineer`.

11 ловушек и чек-лист, повторяющий их названиями. Процедур нет.

## Промпт

Общий с группой 0 ([fact-verification](../fact-verification/README.md#заход-группы-0-звенья-каскада-2026-10-04)).

Четыре ловушки, которые контроль пропустил, - случаи одного признака: логика сама обращается к
внешнему миру без шва для подмены в тесте. 1.2.0 - один пункт-название с этим признаком, случаи
названы в нём примерами. Пункт `sealed` «всегда через интерфейс или wrapper» снят вместе с прочими:
он противоречил YAGNI в `dex-skill-solid` (абстракция только при втором потребителе). Шов в 1.2.0
требуется там, где тест должен подставить вход, - тест и есть второй потребитель.

Прогоны 1.2.0 (`s2-v1`, `s4-v1`):

| Кейс | Поймано признаком | Пропущено |
|---|---|---|
| S4 | TF: календарь не подменить, праздники без тестов; TS: `AuditMailer` - конкретный класс; TE и TR - тем же швом выборки | - |
| S2 | TE: `PdfRenderer` сам читает `WKHTMLTOPDF_PATH`, шва нет, тест в `Skip`; FH: статический класс с сетью не подменить; TS - тем же швом `PdfRenderer` | TF: `File.ReadAllText` шаблона поднят как синхронный I/O |

Ложных находок по приманкам S4 (PS, PT) нет ни в контроле, ни со скиллом. Дефект вне скилла O1 - 3/3.

Сторона автора (`dotnet-coder`, `dotnet-test-writer`) не мерилась: кейса на поручение, где код
соблазнительно зашить на внешний мир, нет.
