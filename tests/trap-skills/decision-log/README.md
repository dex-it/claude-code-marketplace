## Тип единиц и дубли (шаг 0)

Содержание - конвенции корпуса требований (что пишется в журнал, как на запись ссылаются, как
оформляется пересмотр) плюс процедура владельца журнала. Конвенции видны из соседних файлов корпуса,
поэтому мерятся кейсами на корпусе, где они уже соблюдаются, а не остаются процедурой без свидетельства;
решение в пользу кейсов принято до прогонов. Процедура владельца (кто заводит, развилка
«есть / утрачен / нет / корпуса нет», кто дописывает, черта ревизии) - база process-skill: её
потребители - команды, которые `dex-skill-node-contract` не грузят, поэтому дубль с ним
(`references/decision-log-ownership.md`) не снимается, дом для команд - здесь.

Дубли:
- «Род изменения не записан» = `unit-identity` «Правку вносят молча, род изменения не объявляют»: дом -
  `unit-identity` (на него ссылаются `node-contract` `references/revision.md` и `domain-analyst`), здесь
  остаётся запись рода в журнале.
- «Правка пришла мимо конвейера» - единица о `quality-checks`, дом здесь.
