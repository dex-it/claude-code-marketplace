# Корреляция изменений

<!-- skill-type: process -->

## Порядок

1. Якорь - момент начала симптома меткой времени.
2. Изменения в окне вокруг него. Код - по sha, запущенному на стенде, а не по tip ветки.
3. Кандидат, доехавший до системы позже начала, отсеивается; остальные проверяются по одному против
   зоны симптома (IS / IS-NOT).
4. Виновник подтверждён: изменённое исполняется в сценарии симптома. `git bisect` - с `--first-parent`
   и scope на каталог зоны.

## Отчёт

Окно, кандидаты с исходом (отсеян - по таймингу, зоне или пути; виновник) и улика по каждому.
