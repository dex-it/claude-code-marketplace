## Тип единиц и дубли (шаг 0)

Процедура корреляции - часть Kepner-Tregoe Problem Analysis: изменения в окне вокруг момента начала,
проверка каждой возможной причины против спецификации (тайминг, IS / IS NOT), подтверждение истинной
причины (источник - в протоколе root-cause-analysis). Шаги - якорь момента начала, изменения окна, отсев по
таймингу и зоне по одному, подтверждение на пути исполнения: единицы «Окно не привязано к моменту
начала», «Изменение после начала объявлено причиной», «Несколько изменений без изоляции», «blame на строку
без проверки исполнения». Ловушки: образ на стенде против ветки, только код без конфига и флагов, bisect
без first-parent и scope, мердж-коммит виноват.

Дубль «Несколько изменений в окне без изоляции» = `root-cause-analysis` «Вина на первом подозрительном
изменении» - дом здесь, шаг 3.
