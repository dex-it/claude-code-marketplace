**Причина:** коммит `28b29d2` («SHIP-42: тарифы: добавлена зона D», Anna Sokolova). Он добавил зону D в `config/tariffs.json` и заодно изменил строку зоны C:

```diff
 "C": { "bands": [ ...
-        { "maxGrams": 5000, "price": 14.90 },
+        { "maxGrams": 5000, "price": 17.90 },
         { "maxGrams": 10000, "price": 16.90 },
```

Скорее всего, это случайная правка. В новой зоне D полоса 5000 г стоит как раз 17.90, так что значение, видимо, попало не в тот блок. Тариф зоны C после правки перестал быть монотонным: за 5 кг просят 17.90, а за 10 кг — 16.90. Описание коммита говорит только про добавление зоны D, а в `docs/tariffs.md` цен 14.90 и 17.90 нет, так что подтвердить изменение тарифа нечем.

**Исправление:** вернуть в `config/tariffs.json` у зоны C полосу 5000 г к значению 14.90:

```diff
-        { "maxGrams": 5000, "price": 17.90 },
+        { "maxGrams": 5000, "price": 14.90 },
```

Зону D (17.90 за 5 кг) трогать не нужно. Файлы я не менял, это предложение. Если хотите, применю правку и добавлю тест в `test/quote.test.js`: 5 кг в зону C стоит 14.90, и цены в зоне не убывают с ростом веса.
