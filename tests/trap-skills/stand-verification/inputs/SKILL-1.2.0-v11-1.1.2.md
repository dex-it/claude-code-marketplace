# Верификация слитой фичи на стенде

Решение по документации версии из манифеста проекта; пункт - ситуация, которую исполнитель не заподозрит.

- Статус пункта ТЗ присвоен по найденному в дельте коду, а не по пробе на развёрнутой фиче.
- Временный E2E опирается на записи, оставленные другими, зеленеет или падает в зависимости от прогона.
- Временный тест по умолчанию создаёт или меняет бизнес-данные общего стенда, следы остаются после прогона.
