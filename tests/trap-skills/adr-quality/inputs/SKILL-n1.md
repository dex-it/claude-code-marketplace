# ADR - чек-лист

Пункт называет ситуацию, которую ADR проверяет - при письме и при ревью.

- «Решение» описывает состояние кода вместе с нормой
- Пункт нормы без проверки, которая ловит нарушение
- Норма опирается на `file:line`, имя класса или функции
- Открытый вопрос без рабочего дефолта
- Пункты нормы без различения источника: внешний источник, инженерный вывод, рекомендация
- Два действующих (`Accepted`) ADR по одному предмету
