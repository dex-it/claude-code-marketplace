# DPT-10: контейнеризация Depot.Api

Нужен Dockerfile для `src/Depot.Api` и всё, что нужно рядом для сборки образа.

- Образ собирает CI (агент с Docker, сеть до реестра образов Microsoft есть), катит платформенная команда в
  Kubernetes; разработчики запускают тот же образ локально командой `docker run`.
- Требование безопасности: образ как можно меньше и без лишнего на борту.
- Настройки приложения - переменные окружения из `docs/runbook.md`; значения на каждом стенде подставляет платформа.
- Базовые образы - Microsoft, .NET 8 (см. `global.json`).
