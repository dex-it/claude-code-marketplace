# DPT-14: выгрузка накладных в PDF в контейнере

В сервис добавлена выгрузка накладных в PDF (в коде её пока нет, библиотека подключается отдельной задачей). Для неё в
контейнере нужны системные пакеты `libfontconfig1` и `fonts-dejavu-core`; в образе из `Dockerfile` их нет. Базовые образы -
Debian-основа (`aspnet:8.0`, не chiseled). Доработай `Dockerfile` так, чтобы выгрузка работала в контейнере; остальное в
образе не меняй.
