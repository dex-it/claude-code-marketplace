# PRC-14: тесты расчёта цены

Покрыть unit-тестами в `tests/Pricing.Tests`:

1. `PromotionService` - окна акций, в том числе окно через полночь; выбор наибольшей скидки
   категории; категория без акций.
2. `QuoteService` - цена единицы (наибольшая из базовой и цены поставщика), применение промо-скидки,
   поставщик не знает SKU, неизвестный SKU в корзине.
3. `PriceChangeWorker` (добавлен этой веткой) - запрос на изменение цены из очереди применяется к
   товару; запрос на неизвестный товар не останавливает обработку следующих.

Поведение сервисов не меняется; если для теста нужен шов в коде - допустимо его добавить.
