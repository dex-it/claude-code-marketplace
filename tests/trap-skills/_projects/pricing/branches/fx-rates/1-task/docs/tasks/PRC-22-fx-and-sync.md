# PRC-22: валюта поставщика в котировке, ночная синхронизация прайса

1. Часть поставщиков отдаёт цену в USD или CNY. Перед сравнением с базовой ценой цену поставщика
   перевести в рубли по курсу из Rates API (`GET v1/rates/{currency}` -> `{"currency": "USD",
   "rubPerUnit": 92.4}`). Rates API - внутренний сервис казначейства, обычно отвечает за 50 мс.
2. Ночная синхронизация: раз в сутки забирать цены всех SKU поставщика пачками и записывать в
   базовую цену товара, если цена поставщика выше. Supplier API: `POST v1/suppliers/{id}/prices:batch`
   с телом `{"skus": [...]}` (до 1000 SKU), обработка - около 15 мс на SKU. Размер пачки - в конфиге.
