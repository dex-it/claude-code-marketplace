# PRC-24: массовая котировка для B2B

Оптовый клиент присылает прайс-запрос на сотни позиций. Котировка считается в фоне: клиент получает
идентификатор запроса, по готовности ему уходит уведомление `QuoteReady`, результат забирается по
идентификатору. Правила цены - те же, что у обычной котировки (база или цена поставщика, акция
категории).

Покрыть тестами массовую котировку и правила цены, на которые она опирается: выбор цены поставщика,
акцию категории, окно акции через полночь.
