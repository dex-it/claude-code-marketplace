# PRC-23: кэш карточек и витрины категорий

Витрина открывает карточку товара и список товаров категории на каждый показ страницы - в пик это
тысячи запросов в секунду в каталог. Цена поставщика в котировке запрашивается на каждую строку,
популярный SKU - сотни раз в секунду; лимит Supplier API - 20 запросов в секунду на ключ.

Нужно:
1. Кэшировать карточку товара и список категории на 5 минут.
2. Кэшировать цену поставщика на 10 минут. Если поставщик SKU не знает, это тоже кэшировать, но
   коротко - около 30 секунд: заводят SKU у поставщика обычно сразу после заведения у нас.
3. Изменение цены товара (`PUT /api/products/{id}/price`) сразу видно в карточке и в категории.
4. Поддержке - служебный вызов «сбросить кэш каталога» для стенда.
