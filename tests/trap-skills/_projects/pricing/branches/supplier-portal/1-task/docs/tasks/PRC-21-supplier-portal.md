# PRC-21: заказы поставщику для портала поставщиков

Портал поставщиков показывает поставщику его заказы от нас и принимает подтверждение.

- Создание заказа поставщику закупщиком: поставщик, номер заказа (уникален в пределах поставщика),
  строки (SKU, количество, цена закупки), внутренняя заметка закупщика, метки закупщика (произвольные
  пары ключ-значение из ERP).
- Заказ поставщика по номеру; строки заказа.
- Список заказов поставщика для портала - фильтр по статусу, постранично (у крупных поставщиков -
  тысячи заказов в месяц).
- Подтверждение заказа поставщиком; уведомление закупщику письмом.
- Очистка отменённых заказов старше года - вызывает только планировщик.

Цена закупки и заметка закупщика поставщику не показываются.
