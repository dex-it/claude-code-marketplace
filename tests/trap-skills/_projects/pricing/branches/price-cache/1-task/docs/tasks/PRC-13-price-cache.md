# PRC-13: кэш цен поставщика

В часы пик витрина шлёт тысячи котировок в минуту, популярный SKU - сотни раз в секунду, и каждая
котировка идёт за ценой в Supplier API. Лимит поставщика - 20 запросов в секунду на ключ; превышение
- 429 и блокировка ключа на минуту, после чего котировки идут без цены поставщика.

Цена поставщика меняется редко. При изменении поставщик присылает вебхук
`POST /api/webhooks/supplier-prices` с телом `{"supplierId": "sup-7", "skus": ["SKU-1", "SKU-2"]}`;
`"skus": null` - поставщик перезалил весь прайс.

Нужно:
1. Кэшировать цену поставщика до 10 минут.
2. По вебхуку сбрасывать изменённое: перечисленные SKU либо весь прайс поставщика.
3. Служебный вызов для поддержки - «сбросить кэш цен поставщика» по `supplierId`. Его дёргают на
   стенде и в проде, когда поставщик поправил цены вручную и вебхук не прислал.
