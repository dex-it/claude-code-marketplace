# PRC-12: наличие и резерв у поставщика

**1. Наличие в котировке.** В каждой строке котировки показать, сколько единиц есть у поставщика.
Supplier API: `GET v1/suppliers/{supplierId}/stock/{sku}` -> `200 {"sku": "...", "available": 12}`.
Если наличие узнать не удалось, котировка всё равно отдаётся, у строки `available = null`.

**2. Резерв при оформлении.** Новый вызов нашего API для сервиса заказов: резерв строк заказа у
поставщика. Вход - `orderId` и строки (SKU, количество); выход - номер резерва по каждой строке.
Supplier API: `POST v1/suppliers/{supplierId}/reservations` с телом
`{"orderId": "...", "sku": "...", "quantity": 3}` -> `201 {"reservationId": "..."}`.

Из документации Supplier API: «Каждый принятый запрос создаёт новый резерв. Запрос с заголовком
`Idempotency-Key`, уже виденным за последние 24 часа, возвращает ранее созданный резерв».
