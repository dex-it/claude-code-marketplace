# PRC-26: акции по времени магазина, ответ витрине в срок

1. Окно акции задано по местному времени магазина, а сервис крутится в UTC: акция 22:00-02:00
   включается в 01:00 по Москве. Часовой пояс магазина - `Store:TimeZone` (IANA), по умолчанию
   `Europe/Moscow`.
2. Витрине - вызов «какая скидка категории действует сейчас», чтобы показать плашку акции.
3. Котировка в часы выгрузки поставщика отвечает витрине дольше 3 с, и та показывает карточку без
   цены. Котировка должна укладываться в срок витрины, даже если поставщик не ответил: тогда она идёт
   по базовой цене (решение коммерческого отдела - базовая цена не ниже закупочной).
4. Окно акции через полночь покрыть тестами.
