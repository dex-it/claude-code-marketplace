# Pricing

Сервис цен магазина: каталог товаров, котировка для корзины, промо-акции.

- `src/Pricing.Domain` - модель без зависимостей.
- `src/Pricing.Application` - сценарии и абстракции внешнего мира.
- `src/Pricing.Infrastructure` - хранилище, клиенты внешних систем.
- `src/Pricing.Api` - HTTP API (контроллеры), Swagger.
- `src/Pricing.Contracts` - NuGet-пакет контракта котировки, публикуется во внутренний фид; его
  подключают витрина и B2B-шлюз. Версия - `<Version>` в csproj, по SemVer.
- `tests/Pricing.Tests` - unit-тесты (xUnit, Moq).

## Внешние системы

- **Supplier API** (`Suppliers:BaseUrl`) - прайс и склад поставщика. Нестабилен: в часы выгрузки
  (09:00-11:00) отвечает 503 и таймаутами до 15 с, ограничение - 20 запросов в секунду на ключ.
  Своих повторов на стороне поставщика нет.
- **Storefront** (фронт магазина) зовёт наш API и ждёт ответа не дольше 3 с, затем показывает
  карточку без цены.

Сборка: `dotnet build`, тесты: `dotnet test`. Версии пакетов - `Directory.Packages.props` (CPM).
