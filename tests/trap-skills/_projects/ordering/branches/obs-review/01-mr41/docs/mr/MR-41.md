# MR-41 Наблюдаемость orders-api (OB-1)

Добавляет OpenTelemetry (трассы, метрики, экспорт OTLP/Prometheus), health-проверку БД и метрики заказов. В Kubernetes: `livenessProbe` и `readinessProbe` смотрят на `/health` (манифест в репозитории платформы). Сборка локально зелёная, тестов на этот код нет.
