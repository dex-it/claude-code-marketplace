# orders CLI - спецификация

`node bin/orders.js <команда>`; состояние - JSON-файл `$ORDERS_FILE` (по умолчанию `./orders.json`). Деньги - центы, вывод `12.34`.

- `create --sku S --qty N --price C [--ref R]` - создаёт заказ со статусом `new`, печатает `id`. SKU - буквы, цифры и дефис, регистр не важен (хранится в верхнем регистре). `qty` - целое от 1 до 100, иначе ошибка `qty must be 1..100` и код 2. `price` - целое число центов > 0. `--ref` - идентификатор запроса клиента: повторная отправка с тем же `--ref` не создаёт второй заказ, печатается id уже созданного.
- `list [--sku S] [--status X]` - заказы по возрастанию `id`; без заказов печатает `no orders`, код 0.
- `pay <id>` - `new` -> `paid`. `ship <id>` - `paid` -> `shipped`.
- `cancel <id>` - допустимо для `new` и `paid`; для `shipped` и `cancelled` - ошибка `cannot cancel`, код 3.
- Неизвестная команда - печать справки, код 1.
