# RFC-0007 Перевод очереди order-events на Redis Pub/Sub

Автор: команда orders. Статус: на согласовании.

## Предложение
Заменить RabbitMQ на Redis Pub/Sub (StackExchange.Redis 2.7.33). `orders-api` публикует событие командой `PUBLISH order-events`, потребители подписываются на канал `order-events`. Брокер RabbitMQ отключаем после переключения.

## Как делаем
1. В `orders-api` заменяем публикацию из outbox на `ISubscriber.PublishAsync`.
2. Потребители `billing-worker`, `mailer`, `audit-sink` переходят на `ISubscriber.SubscribeAsync`.
3. Для хранения состояния обработки добавляем Dapper рядом с EF Core: запись «обработано» делаем Dapper-ом в отдельной транзакции, остальное остаётся на EF Core `SaveChanges`.
4. Переключение за один релиз, ночью.

## Совместимость
Обратная совместимость сохранена: формат события не меняется, потребители продолжают получать те же сообщения.

## Выводы
Решение простое, Redis уже есть в инфраструктуре, задержка доставки меньше. Предлагаем принять.
