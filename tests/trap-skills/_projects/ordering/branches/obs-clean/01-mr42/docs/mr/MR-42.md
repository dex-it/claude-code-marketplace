# MR-42 Наблюдаемость orders-api (OB-1)

OpenTelemetry (трасса на бизнес-операцию, метрики по заказам, OTLP и Prometheus), проверки состояния: `/health/live` для livenessProbe и `/health/ready` для readinessProbe (БД), логи Serilog с TraceId. Сборка локально зелёная.

Порядок и ограничения: канал заказа проверяется по списку (`web`, `mobile`, `partner`), поэтому метка `channel` ограничена; `/metrics` слушает внутренний порт кластера, доступ закрыт NetworkPolicy платформы; эндпоинт чтения заказа не тронут.
