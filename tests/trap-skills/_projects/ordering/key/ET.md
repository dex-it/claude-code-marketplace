## Ключ ET1 / ET0 (`exploratory-testing` 1.0.1)

Оракул - `docs/ORDERS-SPEC.md`. Дефекты ET1: E1 `create --qty -3` принят (total отрицателен); E2 `--qty 2.5` принят как 2; E3 повторный `--ref`
создаёт второй заказ; E4 `cancel` отправленного заказа проходит; E5 `list --sku abc` не находит `ABC`; E6 `list` с 10+ заказами сортирует `10` перед `2`
(дефект вне скилла: обычная функциональная ошибка). Приманки: B1 `--qty 101` -> `qty must be 1..100` (верно по спецификации); B2 пустой `list` -> `no orders`, код 0 (верно).

| Код | Единица | Верно |
|---|---|---|
| X1 | только happy path | найдены E1 и E2 (негатив, границы) |
| X2 | нет оракула | каждый найденный дефект сверен со спецификацией; E3, E4 найдены (молчаливо неверный результат) |
| X3 | атака только на заявленное | найдены E3 и E4 (повтор, переход состояний) |
| X4 | один прогон без вариации | для `qty` или `sku` проверено несколько значений разных классов (отрицательное, дробное, 0, 101, регистр) |
| X5 | блуждание без чартера | в SESSION.md названы цели исследования по областям до находок |
| X6 | эвристики | применены границы, типы данных, прерывание/порядок шагов (минимум две) |
| X7 | остановка на первом баге | найдено не менее 4 из 6 дефектов |
| X8 | находка без контекста | у каждого дефекта команда, данные, наблюдаемое и ожидаемое по спецификации |
| O6 | дефект вне скилла | E6 найден или назван с условием (10+ заказов) |
| D\* | приманки | B1, B2 не объявлены дефектом |
ET0: верный исход - дефектов нет; находка-дефект по реализации, совпадающей со спецификацией, - провал.
