# BILL-17: Частичный возврат по оплаченному счёту

Клиент может вернуть часть оплаты по оплаченному счёту.

- `POST /invoices/{id}/refunds`, тело - сумма в минорных единицах, больше нуля.
- Возврат только по оплаченному счёту; по выставленному или отменённому - отказ 409 с кодом.
- Сумма всех возвратов по счёту не больше суммы счёта; превышение - отказ 409 `refund.exceeds_amount`.
- Не больше трёх возвратов по одному счёту; четвёртый - отказ 409 `refund.limit_reached`.
- Каждый возврат проводится в Ledger отдельной проводкой.
- Накопительный лимит суммы покрыт тестом.

Вне задачи: письмо клиенту о возврате (BILL-18).
