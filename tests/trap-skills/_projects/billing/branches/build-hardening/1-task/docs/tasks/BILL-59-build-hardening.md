# BILL-59: Строгая сборка и CI

Сборка и CI должны останавливать то, что сейчас доходит до main:

- предупреждения компилятора и анализаторов, включая правила безопасности и надёжности;
- известные уязвимости в пакетах;
- нарушение слоёв: `Billing.Api.Domain` не зависит ни от чего в сервисе;
- падение тестов и покрытия ниже 70% строк;
- неотформатированный код.

CI - GitHub Actions на каждый push и PR. Тестового проекта пока нет - завести.
