# BILL-31: Подписки - периодическое выставление счетов

Клиент оформляет подписку на услуги каталога; Billing сам выставляет счета по периодам.

- Подписка: клиент, валюта, позиции (услуга каталога, цена за единицу в минорных единицах,
  количество, включённый объём использования). Не больше 20 позиций.
- Цена позиции при оформлении берётся из текущего тарифа каталога. Смена тарифа каталога
  действующие подписки не меняет: их цена зафиксирована до явной смены.
- При оформлении сразу выставляется счёт за первый месяц - на сумму позиций.
- Период - календарный месяц. Счёт за новый период выставляется фоном в первый день периода.
- Смена цены позиции подписки - с даты `EffectiveFrom`, которую вносит поддержка, в том числе
  задним числом, но только в пределах текущего периода. За дни от `EffectiveFrom` до конца периода
  включительно выставляется доплата отдельным счётом, пропорционально дням; при снижении цены
  доплаты нет. Ответ API о подписке показывает дату, с которой действует текущая цена.
- Использование сверх включённого объёма приостанавливает подписку.
- Приостановка и возобновление; при приостановке неоплаченный счёт текущего периода отменяется.
  Отменённую подписку возобновить нельзя.
- Бэк-офис: превью «кого продлим сегодня» и отчёт о подписках без изменений (позиции, цена,
  статус) дольше 90 дней.
- Ответ API о подписке: признак, что цена подписки зафиксирована по старому тарифу каталога.
- Ошибки прогона продления видны дежурному: прогон, где хоть одна подписка не продлилась, пишет
  лог уровня Error - по нему мониторинг поднимает алерт.

Вне задачи: отмена подписки (BILL-32), оплата картой.
