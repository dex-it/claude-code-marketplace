# BILL-53: Разбивка суммы на части

Будущей рассрочке нужно делить сумму счёта на равные платежи без потери копеек.

- `Money.Allocate(int parts)` возвращает `parts` сумм в той же валюте; их сумма равна исходной.
- Части отличаются не больше чем на одну минорную единицу; остаток раздаётся по одной минорной
  единице в первые части: 100 на 3 - 34, 33, 33.
- `parts` меньше 1 - ошибка вызова.

Вне задачи: эндпоинт и сама рассрочка - отдельной задачей.
