# BILL-51: Импорт банковской выписки

Бухгалтерия раз в день загружает выписку банка; оплаченные по ней счета закрываются.

- `POST /statements`, тело - CSV (`text/csv`), выписка за день: до 50 МБ, до 200 тыс. строк вида
  `дата;сумма_в_копейках;валюта;референс_платежа;назначение`, первая строка - заголовок.
- Исходный файл сначала кладётся как есть в архив выписок (`IStatementArchive`), затем разбирается.
- Платёж сопоставляется со счётом по назначению: в нём клиент пишет номер счёта (`InvoiceId`), часто
  с опечатками. Сопоставление нечёткое: расстояние Левенштейна до номера каждого выставленного
  счёта не больше 2 (выставленных счетов - до 10 тыс.), сумма и валюта совпадают.
- Сопоставленных платежей бывает до 50 тыс. По каждому статус платежа сверяется в банке
  (`BankClient.GetPaymentStatusAsync`, ответ за ~100 мс); подтверждённый (`Settled`) платёж
  оплачивает счёт тем же путём, что `POST /invoices/{id}/pay`.
- Импорт укладывается в 2 минуты; не уложился - прерывается, ответ 504. Бухгалтер может отменить
  загрузку, закрыв запрос.
- Ответ - сводка: строк, сопоставлено, оплачено, не сопоставлено.

Вне задачи: повторная загрузка той же выписки, ручное сопоставление.
