# BILL-61: Дайджест просроченных счетов

- `GET /invoices/overdue?asOf=yyyy-MM-dd&limit=N` - выставленные и не оплаченные счета со сроком раньше `asOf`,
  самые старые первыми; `limit` от 1 до 500, по умолчанию 100.
- Каждое утро финансам уходит дайджест на дату дня: число просроченных счетов, сумма по валютам, десять
  самых старых. Адресаты дайджеста - из сервиса рассылок финансов (`GET v1/finance/recipients`), отправка -
  `POST v1/finance/digests` туда же. Сервис рассылок недоступен - дайджест дня пропускается, сервис
  продолжает работу.
