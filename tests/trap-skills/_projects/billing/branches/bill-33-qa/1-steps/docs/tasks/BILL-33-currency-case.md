# BILL-33: валюта в нижнем регистре проходит в счёт

Шаги:

1. `POST /invoices` с телом `{"customerId": "...", "amountMinor": 10000, "currency": "rub", "dueDate": "2026-11-01"}`.
2. Счёт создан со статусом `Issued`, валюта `rub`.
3. `POST /invoices/{id}/pay` - Ledger отклоняет проводку: код валюты не ISO 4217.

Ожидается: создание счёта с валютой не в верхнем регистре - отказ 400 с полем `Currency`.
