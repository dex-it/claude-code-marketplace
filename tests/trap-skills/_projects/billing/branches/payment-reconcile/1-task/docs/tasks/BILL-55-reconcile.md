# BILL-55: Ночная сверка с Ledger и напоминания об оплате

- Каждую ночь оплаченные за прошедший день счета сверяются с проводками Ledger по счёту
  `billing-receivables` (за день - до 100 тыс. проводок). Расхождение (оплачен без проводки, сумма
  проводки не та) - в отчёт финансам через CRM (`CrmClient`); отчёт дня доступен по
  `GET /reconciliation/{date}`.
- Тем же проходом клиенту уходит напоминание по email и SMS о счёте, срок оплаты которого через
  3 дня. Недоставленное напоминание сверку не останавливает.
- Оплата счёта: проводка в Ledger - условие оплаты, как и раньше.
- Логи - в Seq; дежурный должен видеть по ним сбои сверки.
