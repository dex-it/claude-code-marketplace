# Каталог шаблонов ошибок импорта (согласован с партнёрами)

Аргументы `args` подставляются по номеру: `{0}` - первый элемент, `{1}` - второй.

| code | Шаблон |
|---|---|
| `amount.range` | Сумма должна быть от {0} до {1} |
| `value.required` | Поле обязательно |
| `value.too_long` | Не длиннее {0} символов |
| `value.invalid` | Недопустимое значение |
