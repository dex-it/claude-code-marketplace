# BILL-58: Импорт счетов от партнёров

- `POST /partners/{partnerId}/invoices/import` - партнёр присылает пачку счетов, до 1000 за раз, тело до 5 МБ.
  Формат - контракт SDK партнёра (Newtonsoft.Json): суммы строками в русской записи (`"1234,50"`),
  курс пересчёта партнёра - числом.
- Поля счёта: `customerId` (обязателен), `externalNumber` (номер у партнёра: латиница, цифры, дефис, до 64),
  `description` (до 256), `comment` (уходит в ЭДО, предел ЭДО - 2000 байт), `amount` (от 1 до 1 000 000 в
  валюте), `currency`, `fxRate` (курс партнёра к валюте счёта, положительный), `kind` (`goods` / `services`),
  `dueDate`.
- Ошибки - 400 со списком `{ index, field, code, args }`; партнёр рендерит текст по своему каталогу шаблонов
  (`docs/partners/error-templates.md`), аргументы подставляются в шаблон по номеру.
- Импорт создаёт выставленные счета; партнёр при сбое сети повторяет запрос целиком.
