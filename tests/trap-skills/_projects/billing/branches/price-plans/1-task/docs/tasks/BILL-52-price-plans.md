# BILL-52: Тарифные планы

Продуктовая команда заводит тарифные планы, по которым позже будут выставляться счета.

- `POST /price-plans` - создать план, ответ 201 с id; `PUT /price-plans/{id}` - изменить план, тело с
  теми же полями. Хранение - в памяти, как у счетов.
- Поля плана:
  - `name` - название, обязательно, до 200 символов; `description` - описание для клиента,
    необязательно, до 2000 символов (те же пределы, что у карточки продукта в CRM);
  - `externalCode` - код плана в CRM, обязателен;
  - `ownerTeamId` - команда-владелец, обязательна;
  - `kind` - вид плана: `Standard`, `Promo`, `Internal`;
  - `channels` - каналы уведомлений о счетах по плану, любой набор из `Email`, `Sms`, `Push`, хотя
    бы один;
  - `monthlyFeeMinor` и `currency` - абонентская плата (ADR-0004), не отрицательная;
  - `trialDays` - пробный период в днях; клиент API обязан указать его явно, `0` - без пробного,
    поле не прислано - ошибка;
  - `validFrom`, `validTo` - период действия плана; это моменты времени, клиенты API в разных часовых
    поясах; `validTo` необязательно;
  - `discountRatio` - скидка долей, необязательно;
  - `webhookUrl` - адрес клиента, на который Billing отправит уведомление о смене плана;
  - `rules` - правила тарификации, список; правило одного из видов, вид - поле `type`:
    `flat` (`amountMinor`), `tiered` (`tiers` - список ступеней `upTo`, `priceMinor`),
    `usage` (`meter` - имя счётчика, `unitPriceMinor`).
- Неверный запрос - 400 с кодом, как у счетов.

Вне задачи: применение плана к счетам, удаление плана.
