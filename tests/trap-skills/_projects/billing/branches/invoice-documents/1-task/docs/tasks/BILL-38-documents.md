# BILL-38: Документ счёта по стране клиента; оплата через outbox

- `GET /invoices/{id}/document?country=<код>&format=html|pdf` - документ счёта по шаблону страны:
  RU, KZ, BY - общий шаблон с локалью страны; страны ЕС - шаблон `eu-vat` с блоком НДС ЕС. Оба
  формата - для всех стран. PDF собирает сервис конвертации (Gotenberg) из HTML.
- Документ - только по выставленному или оплаченному счёту.
- Каждый выданный документ архивируется: формат, код шаблона, по которому он собран, время.
  Архив хранит оба формата документа счёта.
- Документ формируется для любой суммы счёта. Пакетная выгрузка документов за день для
  бухгалтерии - по тем же правилам.
- Локаль документа (язык, формат даты) - по стране; BY добавляется этой задачей.
- Заодно: оплата счёта переводится на outbox (долг ADR-0006).

Вне задачи: отправка документа клиенту письмом.
