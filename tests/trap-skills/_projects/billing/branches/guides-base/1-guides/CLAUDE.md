# Billing

Сервис счетов на .NET 8, сборка - `dotnet build src/Billing.Api`.

## Нормы проекта

- Архитектурные решения - `docs/adr/`, правила ревью - `docs/rules/`.
- Списки в HTTP-API - по `docs/guides/api-lists.md`.
- Сервис внутренний, за API-шлюзом: аутентификацию и доступ к данным клиента проверяет шлюз, в сервисе их нет.
- Новые зависимости без обсуждения не добавляем.
