# Заметка: списки счетов

Максим, 2026-07-20, после разговора с фронтом.

Кабинету клиента нужен список его счетов. Фронт рисует номера страниц, поэтому удобнее отдавать
`page` и `pageSize`, а в ответе - `data` и `total` (число страниц фронт считает сам). Слишком большой
`pageSize` можно молча обрезать до 100, чтобы не ломать клиента. Если делать курсор, его стоит
подписать HMAC, чтобы не подделывали.
