# BILL-57: Пакетная котировка и переоценка дебиторки

- `POST /invoices/quotes` - `{ invoiceIds: [...], currency }`, до 10 тыс. счетов за запрос: сумма каждого
  счёта в валюте `currency`. Курс - на момент операции (ADR-0005).
- `GET /receivables/revaluation?currency=XXX` - переоценка всех выставленных счетов (до 200 тыс.) в валюту
  отчёта с пенями: 0,1% в день просрочки с ежедневным начислением на накопленное. Расчёт тяжёлый, отчёт
  считается не больше одного одновременно; ушедший клиент расчёт останавливает.
- Справочник курсов отвечает до 2 с, но бывает зависает - больше 5 с запрос к нему не ждём.
- Поддерживаемые валюты - файл `config/currencies.txt` в каталоге сервиса, по коду на строку; правка файла подхватывается без
  перезапуска. Валюта вне списка - 400 (`validation`).
