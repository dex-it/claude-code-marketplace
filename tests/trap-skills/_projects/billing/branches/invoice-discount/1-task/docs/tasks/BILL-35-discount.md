# BILL-35: Скидка на выставленный счёт

Менеджер даёт клиенту скидку на выставленный, ещё не оплаченный счёт.

- `POST /invoices/{id}/discount`, тело - сумма скидки в минорных единицах, больше нуля.
- Скидка - только по выставленному счёту; по оплаченному, отменённому или черновику - отказ 409 с кодом.
- Одна скидка на счёт; повторная - отказ 409 `invoice.discount_exists`.
- Скидка меньше суммы счёта: к оплате остаётся хотя бы одна минорная единица; иначе - отказ 409
  `invoice.discount_too_large`.
- Валюта скидки - валюта счёта.
- К оплате и в котировке - сумма за вычетом скидки. Проводки скидка не создаёт: счёт ещё не оплачен.

Вне задачи: скидка процентом, отмена скидки.
