# BILL-42: Счёт по тарифу клиента из CRM

Сейчас сумму счёта передаёт вызывающий. Нужно, чтобы Billing сам брал тариф клиента.

- Тариф клиента (цена за единицу услуги, скидка клиента) ведёт CRM (команда Sales):
  `GET /v1/customers/{id}/tariff`. Менеджер меняет тариф несколько раз в месяц; новый тариф
  действует для счетов, созданных после изменения.
- `POST /invoices` принимает клиента и количество единиц; сумму Billing считает по тарифу.
- Выставление счетов - около 300 тысяч в сутки, из них 200 тысяч в ночной пачке; создание счёта не
  должно зависеть от доступности CRM: CRM уходит в обслуживание на 1-2 часа по ночам и падает на
  десятки минут пару раз в месяц.
- CRM публикует в RabbitMQ событие `CustomerTariffChanged` (id клиента, новый тариф, время
  изменения), доставка at-least-once, порядок не гарантирован.

Что сдать: проектное решение - откуда Billing берёт тариф при создании счёта, что хранит, как
ведёт себя при недоступности CRM.
