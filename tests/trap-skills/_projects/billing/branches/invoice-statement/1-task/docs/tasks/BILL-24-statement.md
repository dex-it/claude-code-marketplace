# BILL-24 Акт сверки клиента

Бухгалтерия запрашивает акт сверки по клиенту за период: `GET /customers/{id}/statement?from&to&currency`.

В акте - счета клиента, созданные в периоде (обе границы включительно): номер, дата, сумма в валюте
счёта и в валюте акта. Итог акта - сумма по счетам в валюте акта. Черновики и отменённые счета в акт
не входят.

Формат ответа - JSON.

Вне задачи: выгрузка акта в Excel с группировкой по месяцам обсуждается на следующий квартал
(BILL-27), решения по ней нет.
