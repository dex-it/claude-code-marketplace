# Свод правил команды Billing

Правила, по которым ревьюим MR. `Accepted` - принято командой; при расхождении с `Accepted` ADR
действует ADR.

| Id | Статус | Правило | Область |
|---|---|---|---|
| RUL-0001 | Accepted | XML-doc у типов и членов не требуется; его отсутствие - не замечание ревью. | весь код |
| RUL-0002 | Accepted | Тесты в MR пишутся, когда их требует задача; отсутствие тестов в MR без такого требования - не замечание. | весь код |
| RUL-0003 | Accepted | Хендлер - класс `<Действие><Сущность>Handler` в `Application/Handlers/<Сущность>s/` с одним методом `HandleAsync(команда, CancellationToken)`; валидатор - отдельным файлом рядом. | Application |
| RUL-0004 | Proposed | Логи - только через `ILogger<T>` со структурными плейсхолдерами. | весь код |
