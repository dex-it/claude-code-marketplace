# ADR-0005: Справочные сервисы (курсы, налоги) - синхронным вызовом в момент операции

Статус: Accepted (2026-01-20)

## Решение

Курс валют и налоговые ставки запрашиваются HTTP-вызовом в момент операции, без кэша и без
очереди. Недоступность справочного сервиса - отказ операции.

## Почему

Регулятор требует курс на момент операции; кэш курса даёт расхождение с банком. Цена - задержка
операции на вызов и зависимость от доступности справочника; принята.

## Отвергнуто

Кэш курсов с TTL; асинхронный пересчёт после операции.
