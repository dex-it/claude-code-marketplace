# ADR-0004: Деньги - целыми минорными единицами

Статус: Accepted (2025-11-03)

## Решение

Сумма - `Money(long Minor, string Currency)`; `decimal` для сумм не хранится и не передаётся
между слоями. Пересчёт по курсу округляется банковским округлением до минорной единицы в месте
пересчёта.

## Почему

Ledger принимает целые минорные единицы; `decimal` с дробными копейками расходился с проводками.
