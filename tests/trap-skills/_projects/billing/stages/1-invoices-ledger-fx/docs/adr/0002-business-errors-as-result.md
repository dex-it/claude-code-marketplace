# ADR-0002: Бизнес-ошибки - значением Result, не исключением

Статус: Accepted (2025-11-03)

## Решение

Хендлеры Application возвращают `Result<T>`; бизнес-отказ (нет сущности, недопустимое состояние,
нарушение правила) - наследник `BillingError` со своим `Code`. Исключение остаётся для сбоя
инфраструктуры и ошибки программиста. Эндпоинт переводит ошибку в ProblemDetails по типу
(`ResultHttpExtensions`).

## Почему

Отказ - ожидаемый исход операции, клиент API различает его по `code`. Исключение на ожидаемом
пути прячет исход от сигнатуры и дорого на горячем пути.
