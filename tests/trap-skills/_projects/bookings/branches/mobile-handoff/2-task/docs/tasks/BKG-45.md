# BKG-45. Swagger-документация к передаче мобильной команде

**Тип:** задача · **Приоритет:** высокий · **Автор:** техлид · **Исполнитель:** разработчик сервиса

## Контекст

Мобильная команда начинает интеграцию с сервисом бронирований. Клиента они сгенерируют NSwag по
`/swagger/v1/swagger.json`; по этому же документу будут читать, как работает API. Контракт у нас
генерируется из кода (Swashbuckle), отдельного файла спецификации нет.

## Что сделать

Подготовить Swagger-документацию сервиса к передаче мобильной команде.

## Готово, когда

- `/swagger/v1/swagger.json` готов к передаче: по нему мобильная команда генерирует клиента и
  разбирается в API без вопросов к нам;
- поведение API не меняется.
