# Курьер-Сервис: API создания отправки

Перевозчик, через которого Parcel отправляет заказы. Документ - по материалам Курьер-Сервиса для
интеграторов.

## Создание отправки

`POST {COURIER_URL}/api/orders`

Заголовки: `Content-Type: application/json`, `X-Api-Key: <ключ>`.

Тело:

```json
{
  "ref": "1042",
  "weight": 1.2,
  "to": {
    "zip": "190121",
    "address": "Санкт-Петербург, наб. Крюкова канала, 4, кв. 9",
    "name": "Мария Белова",
    "phone": "+79213456703"
  }
}
```

- `ref` - номер заказа магазина;
- `weight` - вес в килограммах, дробное число, не больше 30;
- `to.zip` - индекс получателя, шесть цифр.

Ответ `200`:

```json
{ "trackNo": "CS-104273", "deliveryDate": "2026-10-02" }
```

`trackNo` - трек-номер вида `CS-NNNNNN`, `deliveryDate` - плановая дата доставки `YYYY-MM-DD`.

## Ошибки

| Код | Когда | Тело |
|---|---|---|
| 400 | некорректное тело (вес, адрес) | `{ "error": "INVALID_WEIGHT", "message": "..." }` |
| 401 | нет ключа или ключ неверный | `{ "error": "UNAUTHORIZED" }` |
| 503 | сервис недоступен | `{ "error": "SERVICE_UNAVAILABLE" }` |

При `503` отправку можно повторить позже.
