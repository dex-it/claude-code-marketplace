# Дата доставки

Клиент видит ожидаемую дату доставки в трекинге и получает её в SMS.

- Дата доставки = дата отгрузки по московскому времени + N рабочих дней, где N - срок доставки из тарифа
  (`docs/requirements/tariff.md`, с учётом экспресса).
- Рабочие дни - понедельник-пятница; суббота и воскресенье не считаются.
- Дата отгрузки и дата доставки определяются по Москве (Europe/Moscow), независимо от часового пояса
  сервера.
- В трекинге и API дата показывается как `YYYY-MM-DD`.
- В SMS дата показывается как `ДД.ММ` (например, `02.10` для 2 октября).

## Интерфейс (`src/eta.js`)

- `estimateDelivery(shippedAt, zone, { express })` -> `YYYY-MM-DD`; `shippedAt` - момент отгрузки (ISO 8601 с зоной).
- `formatEtaForSms(isoDate)` -> `ДД.ММ`.
