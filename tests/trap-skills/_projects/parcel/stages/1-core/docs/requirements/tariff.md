# Тариф доставки

Требования к расчёту стоимости и срока доставки посылки. Суммы в коде - целые копейки.

## Вес

- Допустимый вес посылки - от 0,1 до 30 кг включительно. Вес вне диапазона - ошибка `WEIGHT_RANGE`.
- Вес передаётся числом. Любое другое значение (строка, `NaN`, `null`, `undefined`) - ошибка `WEIGHT_TYPE`.
- Тарифицируемый вес - фактический вес, округлённый вверх до 0,5 кг: 1,2 кг -> 1,5 кг; 1,5 кг -> 1,5 кг;
  0,1 кг -> 0,5 кг. Стоимость считается за каждые полные 0,5 кг тарифицируемого веса.

## Зона доставки

Зона определяется по почтовому индексу получателя (шесть цифр):

| Индекс | Зона |
|---|---|
| 10xxxx - 14xxxx | A (Москва и область) |
| 19xxxx | B (Санкт-Петербург и область) |
| прочие шестизначные | C |

Индекс не из шести цифр - ошибка `POSTCODE`.

## Стоимость

1. Базовая стоимость - ставка зоны за каждые 0,5 кг тарифицируемого веса: A - 120 ₽, B - 150 ₽, C - 210 ₽.
2. Экспресс-доставка - плюс 50% к базовой стоимости.
3. Хрупкое - надбавка 300 ₽; при экспресс-доставке надбавка за хрупкость удваивается (600 ₽).
4. Программа лояльности - скидка 10% от итога (после надбавок). При экспресс-доставке скидка не действует.
5. Итог округляется вверх до целого рубля.

Пример: 1,2 кг в зону A, без опций - 1,5 кг тарифицируемого веса, три единицы по 120 ₽, итог 360 ₽.

## Срок доставки

Срок - в рабочих днях:

| Зона | Стандарт | Экспресс |
|---|---|---|
| A | 1 | 1 |
| B | 3 | 2 |
| C | 5 | 3 |

Для неизвестной зоны срок и ставка не определены - ошибка `ZONE`.

## Интерфейс (`src/tariff.js`)

- `zoneForPostcode(postcode)` -> `'A' | 'B' | 'C'`
- `billableUnits(weightKg)` -> число единиц по 0,5 кг
- `quote({ weightKg, postcode, express, fragile, loyalty })` -> `{ zone, billableKg, totalKopecks }`
- `deliveryDays(zone, { express })` -> срок в рабочих днях

Ошибки - `TariffError` с полем `code` (коды выше).
