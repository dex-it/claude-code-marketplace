# Поиск заказов для поддержки (PAR-31)

Клиент звонит в поддержку и называет имя получателя, номера заказа не помнит. Оператор ищет заказ по
имени.

- `GET /api/support/orders?q=<строка>` - заказы, у которых имя получателя (`customer.name`) содержит
  строку без учёта регистра: «котова», «Котова» и «КОТОВА» находят заказ Анны Котовой.
- Строка короче 2 символов - `400 { "type": "query-too-short" }`.
- Ответ - массив ресурсов заказа в том же виде, что `GET /api/orders/:id`, новые сверху, не больше 50.
- Поиск идёт в базе: на проде около 400 тыс. заказов, выгружать их в память сервиса нельзя.
