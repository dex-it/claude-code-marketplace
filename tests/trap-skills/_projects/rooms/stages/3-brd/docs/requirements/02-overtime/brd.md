# BRD: Часы сверх пакета (фича 02)

Источник: `docs/brief/02-overtime/brief.md`, интервью 03.09.2026, решения - `decision-log.md`.

- **BR-2001** Сотрудник проводит встречу в переговорной, даже когда часов пакета компании не хватает.
  Мера: доля отказов «пакет исчерпан» среди попыток брони снижается с 12% до 3% за 3 месяца после
  запуска.
- **BR-2002** Площадка получает выручку за часы сверх пакета. Мера: 1,2 млн руб. в месяц через 6
  месяцев после запуска.
- **BR-2003** Компания-резидент держит расходы сотрудников сверх пакета в заданных ею пределах.
  Мера: ни одного списания сверх месячного лимита компании; обращений администраторов компаний по
  спорным списаниям - не больше 2 в месяц.
- **BR-2004** Финансы площадки сверяют поступления от провайдера с выручкой сверх пакета без ручного
  разбора выписок. Мера: сверка месяца занимает 1 рабочий день вместо 3.
