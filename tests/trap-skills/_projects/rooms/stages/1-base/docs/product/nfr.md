# Продуктовые меры

Меры, общие для всех фич. Фичи ссылаются на них по номеру.

- **NFR-0001** API сервиса отвечает не дольше 300 мс на 95-м перцентиле при нагрузке до 50 запросов
  в секунду. Замер: на балансировщике, скользящее окно 1 ч, в счёт идут все запросы API, кроме
  выгрузок. Проверка: нагрузочный прогон на стенде перед выпуском; мониторинг на проде.
- **NFR-0002** Доступность API - не ниже 99,5% за календарный месяц. Доступность - доля запросов,
  получивших ответ не 5xx, среди всех запросов к API; замер на балансировщике. Проверка: отчёт
  мониторинга за месяц.
