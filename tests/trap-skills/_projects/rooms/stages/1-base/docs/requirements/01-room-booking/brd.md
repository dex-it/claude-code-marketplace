# BRD: Бронирование переговорной (фича 01)

- **BR-1001** Сотрудник компании-резидента бронирует переговорную на нужное время сам, без звонка
  администратору площадки. Мера: доля броней, сделанных через сервис, растёт с 40% до 85% за квартал
  после запуска.
- **BR-1002** Часы пакета компании расходуются на состоявшиеся встречи. Мера: доля неявок (бронь не
  отменена, комната не занята) снижается с 18% до 8% за квартал после запуска.
