# ADR-001: Оплата картой через внешнего провайдера, подтверждение вебхуком

Статус: Accepted (10.06.2026)

## Контекст

Сервису понадобится принимать оплату картой компании-резидента. Принимать и хранить данные карт
самостоятельно сервис не может: это требует сертификации PCI DSS, которой у площадки нет.

## Решение

- Оплата идёт через внешнего платёжного провайдера. Сервис получает от провайдера только токен
  привязанной карты; номер карты и CVC сервис не получает и не хранит.
- Оплата асинхронная: сервис создаёт платёж у провайдера, результат (успех или отказ) приходит
  вебхуком. Провайдер доставляет вебхук не позже 60 с после завершения оплаты в 99,9% случаев,
  недоставленный повторяет до 24 ч. Ответ провайдера на создание платежа результатом оплаты не
  является.
- Вебхук подписан секретом провайдера; сервис принимает только вебхуки с верной подписью.

## Следствия

- Всё, что зависит от оплаты, проходит промежуточное состояние «ожидает оплаты»; синхронного
  подтверждения оплаты в сервисе нет.
- Возврат денег - отдельная операция у провайдера, тоже с результатом вебхуком.

## Отклонено

- Синхронное подтверждение по ответу провайдера на создание платежа: ответ означает только, что
  платёж принят к обработке.
