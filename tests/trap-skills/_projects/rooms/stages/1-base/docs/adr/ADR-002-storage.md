# ADR-002: Хранилище - один кластер PostgreSQL, общая схема

Статус: Accepted (02.05.2026)

## Решение

Данные всех компаний-резидентов хранятся в одном кластере PostgreSQL в общей схеме. Отдельные базы
или схемы на компанию не заводятся.

## Причина

Компаний-резидентов десятки, данных мало; база на компанию дороже в эксплуатации, чем нужно.

## Отклонено

- База на компанию.
- Схема на компанию.
