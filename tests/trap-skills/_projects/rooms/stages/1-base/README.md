# Переговорки

Сервис бронирования переговорных комнат в сети коворкингов. Клиенты - компании-резиденты: компания
покупает на месяц пакет часов переговорных, её сотрудники бронируют комнаты сами, администратор
компании управляет сотрудниками и видит брони компании. Администратор площадки ведёт комнаты.

- Требования - `docs/requirements/`, пути корпуса - `.docs_layout`.
- Продуктовые меры, общие для всех фич, - `docs/product/nfr.md`.
- Архитектурные решения - `docs/adr/`.
