# Данные

- `accounts.parquet`: `account_id`, `snapshot` (месяц среза), `tenure_months`, `plan` (3 значения),
  `store_id` (около 1 200 уникальных), `n_tickets`, `revenue`, `churned` (0/1, доля единиц 5%). `n_tickets` пуст у 18% строк: магазины, ни разу не обращавшиеся в поддержку.
  По одному магазину несколько срезов в разные месяцы.
- `sku.parquet`: `sku_id`, 40 числовых признаков, `category` (10 классов, примерно поровну).
- `reviews.parquet`: `text` (русский, до 600 токенов), `label` (0/1/2).
- `shelf/`: фото полок 640x480 (BGR при чтении через OpenCV), 600 штук, три класса; разметка
  товаров - YOLO, `class cx cy w h`.
