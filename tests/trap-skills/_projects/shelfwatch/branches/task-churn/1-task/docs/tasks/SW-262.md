# SW-262: модель оттока магазинов

Написать `src/shelfwatch/churn_model.py`: обучение и оценка модели оттока по
`data/accounts.parquet` (описание - `docs/data.md`). Нужно выбрать лучшую из двух моделей -
случайный лес и градиентный бустинг (XGBoost), выдать качество одной цифрой для отчёта
руководству и функцию `predict_next_month(df) -> pd.Series` с вероятностью оттока по каждому
магазину на следующий месяц после последнего среза. Данные в репозиторий не кладутся, запускать
на реальных данных не нужно; нужны код и тесты на синтетических данных.
