# Сообщения между сервисами

## Очередь `labels`: shipping-api -> label-worker

Одно сообщение - одно отправление, JSON. Поля:

| Поле | Тип | Что |
|---|---|---|
| `id` | строка | номер отправления, `S000123` |
| `tracking` | строка | номер отслеживания перевозчика |
| `postcode` | строка | индекс получателя, 5 цифр, как в запросе |
| `zone` | строка | зона доставки |
| `weightGrams` | целое | заявленный вес, граммы (не расчётный) |
| `express` | bool | экспресс-доставка |

Поле добавляется или переименовывается только вместе с правкой этого файла: label-worker читает поля
по этим именам.
