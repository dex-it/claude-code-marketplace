# SHIP-53 Страхование отправления - ТЗ

Фича влита в develop MR !57, merge-коммит {{ref:K4_HEAD}} (sha12 {{sha12:K4_HEAD}}). Поведение - по `docs/api.md`, `docs/tariffs.md`, `docs/messages.md`; критерии приёмки:

- R1. Заказ с `insured: true` и `declaredValue` (в центах): надбавка за страховку - 1% от заявленной ценности в EUR с округлением до цента; `/quote` отдаёт `insurance` и `price` с надбавкой. Пример: 1 кг, индекс 10115, `declaredValue` 20000 -> `insurance` 2, `price` 6.50.
- R2. Лимит страхования - 1000 EUR заявленной ценности; выше - 422. Ровно 1000 EUR принимается.
- R3. Зона D не страхуется: 422 «страховка недоступна для зоны D».
- R4. На этикетке (label-worker) - строка «Страховка: N EUR» с суммой по контракту сообщения `docs/messages.md`, без `undefined`.
