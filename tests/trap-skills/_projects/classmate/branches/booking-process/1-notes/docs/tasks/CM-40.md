# CM-40: Модель процесса бронирования урока (TO-BE)

По заметкам `docs/process/booking-notes.md` нарисовать процесс бронирования урока в BPMN 2.0 и положить
в `docs/process/booking.bpmn` (BPMN 2.0 XML, без диаграммной части DI). Рядом - `docs/process/booking.md`:
участники, ход процесса текстом, условия на ветках.
Модель нужна Ивану и Петру для реализации и поддержке - чтобы понимать, что видит ученик.
