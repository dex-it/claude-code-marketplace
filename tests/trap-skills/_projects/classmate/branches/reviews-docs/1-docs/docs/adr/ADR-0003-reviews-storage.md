# ADR-0003: Хранение отзывов - события в booking_events

Статус: Proposed (2026-10-13)

## Контекст
Нужны отзывы с текстом и ответами репетитора; рейтинг считается из оценок и отзывов.

## Drivers
- В общей БД платформы события брони уже лежат в таблице `booking_events` - туда пишет отмены и переносы сервис расписания; повторяем тот же подход.

## Решение
1. Отзыв и ответ на него - события `review_posted` и `review_replied` в таблице `booking_events`.
2. Рейтинг репетитора считается из событий `review_posted` за 12 месяцев.

## Последствия
- Плюс: одна таблица для всей истории урока.
- Плюс: не нужна новая миграция схемы под отзывы.
- Плюс: рейтинг считается одним запросом.
