# CM-31: Ревью документов фичи «Отзывы о репетиторах»

Перед согласованием с Мариной нужно ревью трёх документов фичи: PRD `docs/prd/reviews.md`, tech spec
`docs/specs/reviews.md`, ADR `docs/adr/ADR-0003-reviews-storage.md`. По итогам ревью документы либо уходят на
согласование, либо возвращаются авторам.
