# PRD: Отзывы о репетиторах

## Введение

Этот документ описывает отзывы о репетиторах. В нём описано, что такое отзывы, зачем они нужны и как они будут
работать в продукте Classmate.

## Проблема

Ученик выбирает репетитора по цене и фото: 3 900 учеников в сентябре открывали страницу репетитора, 2 050 оплатили
первый урок. Из опроса поддержки - ученики не доверяют рейтингу без текста: «пять звёзд, а за что - непонятно».

## Цель

Увеличить число отзывов на 40% к концу Q1 2027 (сейчас отзывов нет, есть только оценки 1-5; база - число оценок
за декабрь 2026).

## Требования

1. Отзыв. После урока. 7 дней. Текст 20-1000 символов.
2. Модерация. Мат, контакты - скрыть.
3. Ответ репетитора на отзыв. Один. Редактирование - 24 часа.
4. Показ на странице репетитора, новые сверху.

## Рейтинг

Рейтинг на странице репетитора считается так:

| Компонент | Вес |
|---|---|
| Оценка урока (1-5) | 0.6 |
| Доля уроков без отмены по вине репетитора | 0.3 |
| Скорость ответа на первое сообщение | 0.1 |

## Резюме

Отзывы о репетиторах помогут ученикам выбирать репетиторов, а нам - увеличить число отзывов на 40%.
