# signature-convention

## RUL-0003
- Формулировка: Считай деньги в целых копейках: суммы - целые поля `...Cents`, деление - через `Math.floor`; float для денежных сумм не используй.
- Таксон: `internal:signature-convention@2`
- scope: `src/**`
- Статус: proposed
- Принуждение: manual
- Якорь: !41#t1 - «Деньги считаем только в целых копейках: поле `priceCents`, деление через `Math.floor`. Float для денег не используем - на возвратах уже ловили копеечные расхождения с провайдером.»
- Контрпример: `src/billing/refund.js` в коммите «CM-12: возврат по времени отмены (!41)» - возврат на float.
- Живые нарушения: долг - место переписывается в копейки, когда его и так трогают; правило адресовано новому коду. Места на дату снимка - `notes.md`.

## RUL-0005
- Формулировка: Храни и передавай даты в UTC ISO-строкой; локальное время - только при выводе пользователю.
- Таксон: `internal:signature-convention@2`
- scope: `src/**`
- Статус: proposed
- Принуждение: manual
- Якорь: !48#t1 - «Даты храним и передаём только в UTC ISO-строкой - как в `src/util/time.js:5`, `src/booking/slots.js:9` и `src/billing/refund.js:5`. Локальное время - только при выводе пользователю.»
- Контрпример: `toLocaleString` в `src/booking/reschedule.js`, коммит «CM-20: перенос урока (!48)».
