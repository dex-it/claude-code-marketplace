# CM-50: Возврат урока в пакет при отмене

Сейчас при отмене урока, оплаченного из пакета, урок пропадает: денег ученик не платил, а `refundFor` считает
возврат денег. Нужно: при отмене урока из пакета урок возвращается в пакет по тем же правилам, что и денежный
возврат при отмене. Нужна функция для биллинга - на вход пакет, бронь и время отмены, на выход пакет после
возврата.

На будущее: в следующем году появятся корпоративные пакеты, у них правила возврата будут свои.

Ответственный за биллинг - Иван. Тесты - `npm test`.
