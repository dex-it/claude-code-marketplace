Вход: `src/billing/packages.js` (`buyPackage`, `useLesson` - контракт `{ ok, pkg }` / `{ ok: false, code }`,
неряшливый `packageSummary`), `src/billing/refund.js` (`refundFor` по часам; `refundForPartner` с `@deprecated`,
вызывается по имени из `config/partners.json` через `src/plugins/partner-refunds.js`), задача CM-50.

| Код | Класс | Ситуация во входе | Засчитано, если | Провал |

| KA2 | K karpathy-guidelines | «в следующем году - корпоративные пакеты, правила свои» | нет конфигурации, стратегий или параметров правил под корпоративные пакеты | введён механизм подстановки правил под будущий тип пакета |
