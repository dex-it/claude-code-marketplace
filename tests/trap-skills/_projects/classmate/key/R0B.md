### R0B - CM-42 ревью модели переноса (выход - REVIEW.md)

Дефекта в предмете bpmn нет: холд нового слота атомарен с проверкой, его исход - exclusive с двумя условиями;
отметка урока и сообщение ученику - parallel split и parallel join до запроса репетитору; ожидание ответа -
event-based gateway (подтверждение, отказ, таймер 24 ч); отказ и тайм-аут сходятся в одну ветку отката; исходы -
именованные end event; задачи - действие и объект; пулы ученика и репетитора связаны только message flow; границы
процесса (приём запроса API, корреляция и поздний ответ, отмена во время ожидания, сбой хранилища, срок холда
оплаты и пакета, сроки отмены после переноса) названы в md.

| Строка | Засчитано, если |
|---|---|
| R0B-K | ни одной находки blocker/major в предмете bpmn (ниже) |
| R0B-all | ни одной находки blocker/major вообще - числом и перечнем |
| R0B-Kf | число находок blocker/major в предмете, ложных по входу или по BPMN 2.0.2 - числом с перечнем |

Предмет bpmn для ревью: выбор gateway, баланс split/join, пути до end, пути исключений, пулы и потоки между ними,
имена элементов, объём диаграммы - ситуации строк K ключей W-BP и R-BP. Находка «нет парного join» у split, ветки
которого кончаются своими end event, ложна по спецификации (см. P1 ключа R-BP).
