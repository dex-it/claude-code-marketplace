### R-DS - CM-31 ревью PRD, спеки и ADR отзывов (выход - REVIEW.md)

Вход: `docs/prd/reviews.md`, `docs/specs/reviews.md`, `docs/adr/ADR-0003-reviews-storage.md`; дом формулы
рейтинга - `docs/product/rating.md` (веса 0.7 / 0.2 / 0.1).

| Код | Класс | Засеяно | Засчитано, если |
|---|---|---|---|
| DR1 | K doc-standards | в PRD нет раздела «вне охвата» | находка: не сказано, что не входит в фичу |
| DR2 | K doc-standards | в PRD нет требований качества (скорость модерации и показа, защита данных, доступность) | находка: нет NFR / требований качества |
| DR3 | K doc-standards | цель «+40% отзывов» без ограничения побочного эффекта | находка: метрика успеха без ограничения (качество отзывов, накрутка, доля скрытых, конверсия) |
| DR4 | K doc-standards | требования 1-3 PRD номинативными обрывками («Отзыв. После урока. 7 дней.») | находка: требования не читаются однозначно / записаны обрывками |
| DR5 | K doc-standards | «Введение» пересказывает заголовок, «Резюме» повторяет цель | находка хотя бы по одному из двух разделов: пустой или повторяющий |
| DR6 | K doc-standards | таблица рейтинга в PRD (0.6 / 0.3 / 0.1) скопирована и разошлась с `rating.md` (0.7 / 0.2 / 0.1) | находка указывает на таблицу рейтинга PRD и называет расхождение с `rating.md` либо требует ссылку вместо копии |
| DR7 | K doc-standards | спека: перенос ~14 000 оценок в `booking_events` и удаление поля `rating` без плана выката и отката | находка: нет плана выката, отката или миграции для переноса и удаления поля |
| DR8 | K doc-standards | ADR-0003 без рассмотренных вариантов | находка: решение без альтернатив |
| DR9 | K doc-standards (дом - design-quality DQ6) | ADR-0003: в последствиях только плюсы | находка: нет минусов / цены решения |
| DR10 | K doc-standards | driver ADR-0003 - «в общей БД события брони уже лежат в `booking_events`... повторяем тот же подход» | находка: прецедент реализации выдан за основание решения |
| P1 | P | спека ссылается на `rating.md`, формулу не копирует | 0, если находка с severity blocker/major требует перенести формулу рейтинга в спеку |
| O1 | O | ADR-0003: «не нужна новая миграция схемы» - спека переносит оценки и удаляет поле `rating` | находка о противоречии ADR и спеки |
