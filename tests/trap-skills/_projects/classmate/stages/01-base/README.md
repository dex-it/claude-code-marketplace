# Classmate

Платформа частных уроков: ученик находит репетитора, бронирует слот, платит картой, урок идёт в видеокомнате.
Сервис - Node 24, без фреймворка, ESM. Тесты - `node --test`.

```
npm test        тесты
npm run lint    prettier --check . && eslint .
```

Документы продукта - `docs/product/`, решения - `docs/adr/`, исследования - `docs/research/`, задачи - `docs/tasks/`.
