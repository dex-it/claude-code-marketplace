# Рейтинг репетитора

Рейтинг - среднее взвешенное оценок за последние 12 месяцев; оценка старше 6 месяцев идёт с весом 0.5.
Репетитор без 5 оценок рейтинга не имеет и показывается с меткой «новый».

| Компонент | Вес |
|---|---|
| Оценка урока (1-5) | 0.7 |
| Доля уроков без отмены по вине репетитора | 0.2 |
| Скорость ответа на первое сообщение | 0.1 |
