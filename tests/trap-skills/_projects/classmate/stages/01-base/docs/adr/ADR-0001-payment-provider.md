# ADR-0001: Платёжный провайдер - PayFlow

Статус: Accepted (2026-06-10)

## Контекст
Нужна оплата картой с холдированием и возвратами, выплаты физлицам-репетиторам.

## Рассмотренные варианты
- PayFlow - холдирование, возвраты, выплаты самозанятым; комиссия 2.4%.
- CardHub - холдирование и возвраты есть, выплат самозанятым нет; комиссия 2.1%.
- Свой эквайринг через банк - выплаты есть, срок подключения 4 месяца.

## Решение
1. Оплата урока - холдирование при брони, списание после урока, через PayFlow.
2. Возврат - через API возвратов PayFlow; повторы запросов делает шлюз PayFlow, клиентский код не ретраит.

## Последствия
- Минус: комиссия выше CardHub на 0.3 п.п.
- Минус: рекуррентных платежей в нашем тарифе PayFlow нет; подключение - отдельный договор.
