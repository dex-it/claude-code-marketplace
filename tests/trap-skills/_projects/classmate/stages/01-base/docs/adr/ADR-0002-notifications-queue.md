# ADR-0002: Уведомления идут через очередь

Статус: Accepted (2026-08-20)

## Контекст
Письма и пуши отправлялись прямо из обработчиков; при сбое SMTP-шлюза бронь создавалась, а письмо терялось.

## Решение
1. Любое исходящее уведомление (письмо, пуш, SMS) ставится в очередь `notifications`; отправку делает воркер.
2. Обработчик запроса не обращается к SMTP-клиенту и к API пушей напрямую.

Проверка: ревью - импорт SMTP-клиента или клиента пушей вне `src/workers/` блокирует MR.

## Последствия
- Плюс: сбой шлюза не теряет уведомление, воркер повторяет отправку.
- Минус: задержка письма до 30 с; локальная отладка требует запущенного воркера.
