# Привязка карты

Владелец: команда кошелька. Решения - `decisions.md` рядом.

- **CB-1** Покупатель привязывает карту через страницу банка-эквайера, данные карты сервис не хранит.
- **CB-2** У покупателя не больше 5 привязанных карт.
- **CB-3** Одна из карт помечается основной и подставляется при оплате по умолчанию.
