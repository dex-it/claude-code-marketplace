# История платежей

Владелец: команда кошелька. Решения - `decisions.md` рядом.

- **PH-1** Покупатель видит список своих платежей за последние 24 месяца, новые сверху.
- **PH-2** У платежа показаны дата, сумма, способ оплаты и номер заказа.
- **PH-3** Список фильтруется по периоду и способу оплаты.
- **PH-4** Список открывается не дольше 1 секунды при 500 платежах у покупателя.
