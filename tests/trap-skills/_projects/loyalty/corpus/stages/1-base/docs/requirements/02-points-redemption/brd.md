# BRD: Оплата заказа баллами (фича 02)

- **BR-2001** Покупатель тратит накопленные баллы при оплате заказа. Мера: доля заказов с оплатой баллами - не меньше 15% заказов участников.
- **BR-2002** Оплата баллами не создаёт убытка по заказу. Мера: ни одного заказа с отрицательной маржой из-за списания баллов.
