# BRD: Начисление баллов (фича 01)

- **BR-1001** Покупатель получает баллы за оплаченные заказы, чтобы возвращаться за следующей покупкой. Мера: доля повторных заказов в течение 90 дней растёт с 22% до 27%.
- **BR-1002** Обязательства по баллам ограничены во времени, чтобы резерв под них оставался предсказуемым. Мера: резерв под неизрасходованные баллы не превышает 1,5% месячной выручки.
- **BR-1003** Покупатель оставляет отзывы о товарах. Мера: доля заказов с отзывом растёт с 4% до 7%.
