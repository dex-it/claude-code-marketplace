# SRS: Уровни участника (фича 03)

## Функциональные требования

- **FR-3001** У участника один из уровней: «Базовый», «Серебро», «Золото». Основание: BR-3001, D-1.
- **FR-3002** Уровень «Золото» присваивается при сумме полученных заказов от 40 000 руб. за последние 12 месяцев. Основание: BR-3002, D-2.
- **FR-3003** На уровне «Золото» начисление по FR-1001 удваивается. Основание: BR-3001, D-3.
