# BRD: Уровни участника (фича 03)

- **BR-3001** Активные покупатели получают уровень с повышенным начислением. Мера: средний чек участников уровня «Золото» выше среднего по программе на 30%.
- **BR-3002** Уровень пересматривается, чтобы оставаться наградой за активность. Мера: не больше 10% участников на уровне «Золото».
