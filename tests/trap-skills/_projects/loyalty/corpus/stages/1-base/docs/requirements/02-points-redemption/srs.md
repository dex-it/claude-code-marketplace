# SRS: Оплата заказа баллами (фича 02)

## Функциональные требования

- **FR-2001** Покупатель может оплатить баллами часть заказа по курсу 1 балл = 1 руб. Основание: BR-2001, D-1.
- **FR-2002** Оплата баллами недоступна для заказа, который оплачивается подарочным сертификатом. Основание: BR-2002.
- **FR-2003** Минимальное списание - 100 баллов. Основание: D-2.
- **FR-2004** Баллы списываются в момент подтверждения оплаты; при отмене оплаты возвращаются на счёт. Основание: BR-2001.

## Нефункциональные требования

- **NFR-2001** Отказ в списании показывается покупателю не позже 2 секунд после нажатия «Оплатить». Основание: BR-2001.
