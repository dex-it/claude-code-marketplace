# FUL-15: Поиск по каталогу

## Требования

1. Каталог - `ICatalogSource` (3 миллиона товаров, ночью обновляется целиком), названия и
   описания на русском и английском. Нужен индекс в Elasticsearch и поиск.
2. Поиск `GET /search?q=&category=&minPrice=&maxPrice=&sort=&page=`: текст ищется по названию и
   описанию, названию вес выше; фильтры по категории и цене; сортировка по релевантности, цене или
   названию.
3. Рядом с выдачей - список категорий с числом товаров по текущему запросу.
4. Выгрузка `GET /search/export?q=` отдаёт все найденные товары (до 200 тысяч) постранично
   (потоком) для партнёра.
5. Схема индекса меняется от релиза к релизу (новые поля, смена анализатора); поиск на витрине
   не должен останавливаться на время пересборки индекса.
6. Ночная загрузка 3 миллионов товаров должна укладываться в час.
7. Elasticsearch - один узел из `docker-compose.yml`, клиент по ADR-0001.

## Вне задачи

Тесты, подсказки при вводе, синонимы.
