# FUL-34: MongoDB - архив заказов

Переношу хранение заказов в MongoDB (`orders`), без изменения API.

- `OrderStore` сохраняет заказ с адресом и данными клиента для письма, отдаёт страницы заказов клиента и список «мои заказы».
- `OrderEvents` ведёт ленту событий заказа, `StockTransfer` переносит остатки между складами.
- `ShippedWatcher` замечает статус `Shipped` и отправляет письмо через `IMailer`.
- `ArchiveInitializer` создаёт индексы, `CartDraftCleaner` чистит черновики корзин старше 30 дней.
