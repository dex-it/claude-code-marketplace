# FUL-39: Синхронизация каталога и заказов

Сводный MR по интеграциям сервиса: поток заказов из Kafka (учёт клиентов, импорт, статусы),
платёжный процесс и склад в RabbitMQ, кэш цен в Redis, архив заказов в MongoDB и поиск
по каталогу в Elasticsearch. Регистрация - расширения `AddXxx` в `Program.cs`.
Настройки и адреса берутся из `FulfilOptions`.
