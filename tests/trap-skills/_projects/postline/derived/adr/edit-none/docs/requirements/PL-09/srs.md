# SRS: превью изображений (PL-09)

Статус: принят. Журнал решений - `decision-log.md`, записи судьи - `srs.checks.md`.

## Рамка

Автор загружает изображения и видео к постам; для изображений платформа строит уменьшенные превью. Предмет - загрузка
изображений и превью. Вне рамки: видео.

## Требования

- **FR-1** Ответ на загрузку изображения не ждёт построения превью.
- **FR-2** Пост с изображением, у которого превью ещё нет, публикуется.
- **FR-3** Превью строятся для изображений размером не более 20 МБ; видео загружается по частям отдельно.
- **NFR-1** В пик (70 загрузок в секунду) превью готово в течение минуты после загрузки.
- **FR-4** Автор видит прогресс загрузки видео по частям в процентах и оставшееся время. Закрывает PL-38, не PL-09.
