# decision-log: суммы донатов в копейках и API v2 (PL-34)

| № | Что решено | Кто принял | Отклонено | Цена | Где норматив |
|---|---|---|---|---|---|
| D-1 | Суммы хранятся целым числом копеек, а не `numeric(12,2)` | владелец продукта payments | `numeric(12,4)` | миграция трёх таблиц | FR-1 |
| D-2 | Старый API v1 работает 6 месяцев после выхода v2 | владелец продукта payments | выключить v1 сразу; бессрочно | нагрузка на команду на период | FR-2 |
| D-3 | Отчёт автора ускоряется на 40% от замеренного значения | владелец аналитики | порог p95 в миллисекундах без замера | замер базы до работы | FR-3 |
| D-4 | Комиссия округляется вниз, в пользу автора | владелец продукта payments, финансы | вверх; до ближайшей копейки | недобор комиссии до 1 копейки | FR-4 |
| D-5 | Приём донатов не останавливается на время перехода | владелец продукта payments | окно остановки ночью | усложнение миграции | NFR-1 |

| D-7 | FR-5: суммы свыше 10 000 руб. в кабинете автора показываются без копеек | владелец продукта, дизайн кабинета | - | нет | FR-5 |
