# SRS: суммы донатов в копейках и API v2 (PL-34)

Статус: принят. Журнал решений - `decision-log.md`, записи судьи - `srs.checks.md`.

## Рамка

Платформа хранит и отдаёт суммы донатов, комиссий и выплат авторам. Предмет - формат хранения сумм и публичный API
донатов. Вне рамки: мультивалютные донаты.

## Требования

- **FR-1** Суммы донатов, комиссий и выплат хранятся целым числом копеек. Сейчас - `numeric(12,2)` в рублях, а комиссия считается в `double` в коде и даёт расхождения до 1 копейки на донат.
- **FR-2** Публичный API `/v2/donations` отдаёт суммы полем `amount_minor` (копейки, целое). `/v1/donations` (рубли, `amount` с дробной частью) остаётся доступным 6 месяцев после выхода v2: им пользуются 14 партнёров-интеграторов.
- **FR-3** Отчёт автора по донатам за месяц (`GET /authors/{id}/donations/report`): p95 снизить на 40% от текущего. Текущее значение не замерено в разрезе отчёта.
- **FR-4** Комиссия 10% считается в копейках, округление - вниз, в пользу автора.
- **NFR-1** Приём донатов не останавливается на время перехода.
- **FR-5** Раздел «Выплаты» в кабинете автора показывает суммы в рублях; суммы свыше 10 000 руб. - без копеек. Закрывает PL-37, не PL-34.
