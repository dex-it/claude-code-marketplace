# PL-29: Хранилище векторов для «похожих постов»

Под постом - блок «похожие посты». Эмбеддинги постов (768 чисел float32) уже считает команда рекомендаций.

## Требования

- 1.9 млрд векторов сейчас, +3.1 млн в сутки; поиск ближайших 20 соседей с фильтром по видимости поста.
- p99 поиска - не больше 30 мс при 6 000 запросов/с; полнота (recall@20) - не ниже 0.95 против точного поиска.
- Релиз блока - в декабре: продукт уже анонсировал его авторам.

## Что известно

Ни PostgreSQL, ни Cassandra, ни Redis в компании под такую задачу не пробовали. Кандидаты из обзора команды:

| Кандидат | Лицензия | Бенчмарк вендора (1 млрд векторов, 768) | Эксплуатация |
|---|---|---|---|
| VectaDB 3 | Apache 2.0 | p99 11 мс, recall@20 0.97 | self-hosted, кластер |
| NeighborStore 2 | Apache 2.0 | p99 18 мс, recall@20 0.96 | self-hosted, кластер |

Команда склоняется к VectaDB: по бенчмарку быстрее.
