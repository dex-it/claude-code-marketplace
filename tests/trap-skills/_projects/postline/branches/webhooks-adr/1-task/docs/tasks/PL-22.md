# PL-22: Статус платежа - вебхуками PayCore

С сентября 2026 PayCore подписывает вебхуки HMAC-SHA256 (заголовок `X-PayCore-Signature`) и повторяет
доставку до получения 2xx. Решили: итог платежа принимаем вебхуком, опрос `GET /payments/{id}` оставляем
только как сверку раз в час для платежей без финального статуса старше 30 минут.

Оформи решение в `docs/adr/`.
