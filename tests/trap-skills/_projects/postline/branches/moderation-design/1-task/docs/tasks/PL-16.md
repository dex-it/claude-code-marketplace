# PL-16: Очередь жалоб для модераторов

Внутренний инструмент. Модераторов 14, в смене до 6. Жалоб - 3 000 в сутки, пик 1 в секунду. Хранение - 1 год.

## Требования

- FR-1. Очередь жалоб: старые первыми, фильтр по типу (спам, оскорбления, авторское право).
- FR-2. Модератор берёт жалобу в работу; одну жалобу не берут двое.
- FR-3. Решение модератора (оставить / скрыть пост / заблокировать автора) применяется к посту или автору
  и пишется в журнал с причиной.
- FR-4. Доступ - только сотрудникам с ролью «модератор», вход через корпоративный SSO.
- NFR-1. Доступность - рабочие часы смен, допустим простой до 30 минут.
