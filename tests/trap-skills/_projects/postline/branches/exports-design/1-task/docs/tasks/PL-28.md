# PL-28: Выгрузка отчётов автора

## Требования

- FR-1. Автор заказывает выгрузку за период до года: CSV с просмотрами по постам и PDF со сводкой донатов.
  Подготовка файла - 1-5 минут, до 300 МБ; заказов - до 4 000 в сутки.
- FR-2. Готовый файл автор скачивает по ссылке в течение 7 дней.
- FR-3. В сводке донатов - суммы по дням и комиссия платформы.
- FR-4. Ссылку на файл может открыть только автор-владелец.

## Предложения команды analytics

- Файл готовить во временном каталоге пода (`/var/exports`) и отдавать по ссылке с того же пода: analytics
  работает в 4 подах с автоскейлом, диск у пода есть.
- Донаты для сводки читать прямо из таблиц сервиса payments (`donations`, `commissions`): у analytics есть
  доступ на чтение к базе payments.
