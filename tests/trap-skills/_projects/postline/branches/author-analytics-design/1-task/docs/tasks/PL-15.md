# PL-15: Хранилище аналитики авторов

## Контекст

События просмотров и реакций: 2.2 млрд в сутки (в среднем 25 тыс./с, пик 80 тыс./с), событие ~180 байт.
Один автор даёт 9% всех событий; 310 авторов с аудиторией больше 1 млн - 45%.
Хранилище - PostgreSQL-шарды (одна база на узел), маршрутизация - в приложении analytics. Сейчас 6 узлов;
за год их станет 18, узлы добавляются по мере роста без остановки сервиса.

## Требования

- FR-1. Дашборд автора: просмотры и реакции по дням и по постам за последние 13 месяцев; p95 - 500 мс.
- FR-2. Ежедневный отчёт платформы к 06:00: топ-1000 авторов по росту аудитории за сутки, по всем авторам.
- FR-3. Сырые события сохраняются для перерасчёта агрегатов при ошибке в формуле.
- FR-4. Автор видит агрегаты, но не идентификаторы зрителей.
