# PL-12: Донаты и выплаты авторам

## Требования

- FR-1. Зритель отправляет донат автору с карты через провайдера PayCore: `POST /payments` (синхронный ответ
  с `payment_id`), итог - вебхуком статуса. PayCore принимает заголовок `Idempotency-Key` и подписывает вебхуки HMAC.
- FR-2. После успешного платежа баланс автора пополняется на сумму за вычетом комиссии платформы 10%; автор видит баланс.
- FR-3. Раз в сутки накопленный баланс выплачивается автору на карту через PayCore Payouts (`POST /payouts`,
  принимает `Idempotency-Key`). Отправленную выплату отменить нельзя.
- FR-4. После доната автор получает уведомление, событие уходит в analytics.
- NFR-1. Мобильный клиент при тайм-ауте 10 с повторяет запрос доната, до 3 раз.
- NFR-2. Донаты принимают оба ДЦ (active-active).
- NFR-3. Баланс автора не уходит в минус; выплата за сутки не уходит дважды.
- NFR-4. p95 создания доната - не больше 800 мс.
- NFR-5. Уведомление автору о донате - не позже 1 минуты.

## Предложения команды

- Хранить баланс автора в Cassandra рядом со счётчиками: кластер уже есть в обоих ДЦ.
- Списание баланса при выплате и запись в notifications делать одной распределённой транзакцией, чтобы не терять уведомления.
- Планировщик выплат - по образцу остальных фоновых задач payments: cron в каждом поде (6 подов в двух ДЦ),
  перед запуском - блокировка в Redis `SET payouts-lock NX PX 60000`; выплата всех авторов идёт 20-40 минут.
