# PL-19: Компоненты Postline Studio 5

Studio 5 - enterprise-редакция (см. «Редакции и ограничения» в `docs/system.md`). Нужно выбрать три компонента:

1. Полнотекстовый поиск по постам (русская морфология).
2. Хранилище событий аналитики. В SaaS-редакции то же хранилище реплицируется во второй регион - 4 ТБ в сутки.
3. Библиотеку генерации PDF-отчётов для .NET 8, линкуется в бинарь Studio.

Кандидаты и то, что о них известно, - `docs/sources/studio-candidates.md`.

## Результат

Выбор по каждому компоненту с обоснованием и сравнением стоимости - `docs/design/PL-19.md`.
