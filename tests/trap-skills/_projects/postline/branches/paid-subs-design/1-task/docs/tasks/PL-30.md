# PL-30: Платные подписки на автора

## Требования

- FR-1. Зритель оформляет месячную подписку на автора по цене автора (от 99 до 9 999 руб.) через PayCore.
- FR-2. Подписка продлевается автоматически каждый месяц списанием с сохранённой карты. PayCore предоставляет
  API рекуррентных подписок (`/subscriptions`: расписание и списания на стороне PayCore) и разовые списания по токену карты.
- FR-3. Платные посты автора видят только активные подписчики.
- FR-4. Сразу после оплаты подписчик открывает платный пост, с которого пришёл на оплату.
- FR-5. Подписчик отменяет подписку; доступ сохраняется до конца оплаченного периода.
- FR-6. Автор видит список своих подписчиков и доход по месяцам.
- NFR-1. Проверка доступа к платному посту - p95 не больше 20 мс.
- NFR-2. Неудачное продление: 3 попытки за 7 дней, затем подписка приостанавливается.
- NFR-3. Доступность оформления подписки - 99.9% в месяц.
