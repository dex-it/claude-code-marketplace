# PL-18: Очередь для рассылок

Команда рассылок (4 разработчика .NET, своего DevOps нет) выносит отправку писем в очередь.

## Требования

- 150 писем/с в среднем, до 900/с при массовой рассылке; задержка постановки в отправку - до нескольких минут.
- Письмо в очереди хранится до 3 суток (повторы при недоступности почтового провайдера).
- Отписавшимся рекламные письма не отправляются.

## Предложение лида команды

Kafka: индустриальный стандарт, на рынке её ждут в резюме; по бенчмарку вендора - 2 млн сообщений/с на кластер.
