# PL-14: Полнотекстовый поиск

Сейчас поиск - `ILIKE` по PostgreSQL primary, p95 4 с на пике.

## Требования

- FR-1. Полнотекстовый поиск по постам (русская морфология) и по авторам; 4 000 запросов/с на пике.
- FR-2. Новый, изменённый или удалённый пост отражается в поиске не позже чем через 1 минуту.
- FR-3. В выдаче - имя и аватар автора. Переименований авторов - 12 тыс. в сутки; постов у автора в среднем 900, максимум 2 млн.
- FR-4. Посты «только для платных подписчиков» не попадают в выдачу тем, кто не подписан.
- NFR-1. p95 поиска - не больше 300 мс.

## Что есть рядом

- Ночная выгрузка в analytics (01:00-03:00) читает таблицу `posts` с primary.
- Начальное наполнение индекса - 1.9 млрд постов; команда планирует ежемесячную полную переиндексацию тем же путём.
