# PL-05: Ежедневный дайджест автору

Статус: реализовано (2026-06)

Письмо автору в 09:00 по его часовому поясу: новые подписчики, донаты, лучшие посты за сутки.

- Сборка - задача analytics в 03:00-06:00, результат - сообщение в очередь `notifications.digest`.
- Отправка - через notifications, канал email; повторы - по ADR-0004 п.1-2, ответ 4xx - по ADR-0004 п.3.
- Журнал отправки дайджестов хранится столько же, сколько журнал доставки, - ADR-0004 п.5.
