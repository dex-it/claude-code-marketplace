# ADR-0001: Публикации хранятся в PostgreSQL

Статус: Accepted (2025-11-10)

## Контекст

Публикация - текст до 10 000 символов, ссылки на медиа в S3, автор, время, видимость (все / подписчики / платные).

## Решение

1. Публикации хранятся в PostgreSQL, таблица `posts`, первичный ключ - `post_id` (UUIDv7).
2. Медиа в базе не хранится: в посте - только ключи объектов S3.
3. Удаление поста - мягкое: `deleted_at`, физическое удаление - через 30 дней фоновой задачей.

## Последствия

- Транзакционность публикации и её видимости даётся одной базой.
- Объём `posts` растёт на ~3 млн строк в сутки; секционирование по месяцам - при превышении 2 ТБ.
