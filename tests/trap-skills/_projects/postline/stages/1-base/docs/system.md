# Postline - описание системы

Замер нагрузки - сентябрь 2026, Prometheus.

## Пользователи и контент

- Зарегистрированных 18 млн, DAU 4.2 млн. Авторов с публикациями за месяц - 600 тыс.
- Подписчиков у автора: медиана 40, среднее 310. 98.5% авторов - меньше 5 000 подписчиков; 2 400 авторов -
  от 100 тыс. до 1 млн; 310 авторов - больше 1 млн, максимум 14 млн.
- Публикации: 3.1 млн в сутки, в среднем 36/с, пик 260/с (20:00-22:00). Правки постов - 0.8 млн в сутки.
- Открытия ленты: в среднем 9 000/с, пик 31 000/с.
- Донаты: 410 тыс. в сутки, пик 60/с.
- api в целом: в среднем 48 000 RPS; час пик (20:00-22:00) - 2.9x среднего.

## Компоненты

| Компонент | Что делает | Масштаб |
|---|---|---|
| api (.NET 8) | REST для клиентов | 24 пода, автоскейл 16-40; сессия входа хранится в памяти пода, балансировщик - sticky-cookie |
| feed | лента: сейчас собирается на чтение запросом к PostgreSQL по списку подписок | 8 подов |
| payments | донаты, баланс авторов, выплаты; провайдер PayCore | 6 подов в двух ДЦ |
| search | поиск по постам и авторам: сейчас `ILIKE` по PostgreSQL primary | 4 пода |
| notifications (TypeScript) | push, email, SMS, Telegram, вебхуки партнёров | 6 подов |
| live | прямые эфиры: видео - внешний CDN, события эфира - пока нет | - |
| analytics | дашборд автора, отчёты | 4 пода |

## Хранилища и инфраструктура

- PostgreSQL 16: primary и 3 асинхронные реплики, отставание реплик p99 1.5 с. Primary выдерживает 12 000 записей/с,
  реплика - 70 000 чтений/с (нагрузочный тест 2026-08). `max_connections` primary - 500.
- Cassandra 4.1: профили и счётчики (лайки, просмотры), два ДЦ, RF 3 в каждом, запросы по умолчанию `LOCAL_QUORUM`.
- Redis 7 Cluster - кэш. RabbitMQ 3.13 - очереди, выдерживает 60 000 сообщений/с.
- S3-совместимое хранилище - медиа.
- Два ДЦ, оба принимают трафик (active-active), RTT между ДЦ 11 мс.
- Kubernetes; деплой api - до 12 раз в сутки, rolling.
- Наблюдаемость: метрики Prometheus, трейсы OpenTelemetry, логи в OpenSearch.

## На один запрос api (среднее)

1.2 чтения PostgreSQL (реплики), 0.08 записи в primary, 2 операции Redis, 0.3 публикации в RabbitMQ.

## Команды

Семь продуктовых команд по 5-7 человек, стек .NET 8 и TypeScript. Платформенная команда (5 человек)
эксплуатирует PostgreSQL, Redis, RabbitMQ, Cassandra и дежурит по ним. Kafka в компании не эксплуатируется,
опыта эксплуатации нет.

## Редакции и ограничения

- SaaS - в облаке провайдера X: трафик между регионами $0.02/ГБ, между зонами $0.01/ГБ.
- Postline Studio - enterprise-редакция, поставляется клиентам on-prem: закрытый код, бинарная поставка, у части
  клиентов нет доступа в интернет, поддержка версии обещана на 5 лет.
