# Postline

Платформа авторов: публикации, подписки, лента, донаты, поиск, уведомления, прямые эфиры, API партнёров,
аналитика для авторов. Описание системы и нагрузки - `docs/system.md`. Решения - `docs/adr/` (ADR) и
`docs/decisions.md` (журнал решений). Задачи - `docs/tasks/`, дизайн - `docs/design/`, планы - `docs/plans/`.
