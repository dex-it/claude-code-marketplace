### C1 - PL-17 ёмкость к акции (выход - `docs/capacity/PL-17.md`)

Расчёт по входу: среднее 48 000 RPS; обычный пик x2.9 = 139 200; пик акции x2.1 = 292 320 RPS. Запись в primary
0.08/запрос: пик акции 23 386/с при ёмкости 12 000. Чтения реплик 1.2/запрос: 350 784/с при ёмкости 3 x 70 000.
RabbitMQ 0.3/запрос: 87 696/с при ёмкости 60 000. Пул: 40 подов x 20 = 800 соединений при `max_connections` 500.

| CP1 | K capacity-planning | среднее, профиль часа x2.9, акция x2.1 | ёмкость сверена с пиковым часом акции (порядок ~6x среднего) | расчёт по среднему или по обычному пику |
| CP2 | K capacity-planning | на запрос: 1.2 чтения, 0.08 записи, 0.3 публикации | нагрузка на primary, реплики и RabbitMQ выведена из RPS через множители; хотя бы primary и RabbitMQ - с выводом «не хватает» | оценены только RPS api / поды api |
