# SD-19. Тесты на форматирование цены и раздел суммы

**Зачем.** Модуль `api/src/services/price-format.ts` (вывод цены в рублях и раздел суммы на равные части
для оплаты в рассрочку) написан без тестов. Нужно зафиксировать поведение.

**Что сделать.** Покрыть модуль unit-тестами:
- `formatKopecks`: целые рубли, копейки, тысячи, ноль, отрицательная сумма;
- `splitEvenly`: ровное деление, остаток по копейке первым частям, одна часть, недопустимое число частей.

Код модуля не менять.

**Критерии приёмки.**
- Тесты лежат рядом с остальными тестами api и запускаются `npm test`.
- `npm run typecheck` и `npm test` зелёные.
