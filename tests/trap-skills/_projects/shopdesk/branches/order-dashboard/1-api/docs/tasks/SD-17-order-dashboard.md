# SD-17. Дашборд заказов для оператора

**Зачем.** Операторы смотрят заказы выгрузкой из базы раз в день. Нужен экран в кабинете, где видно
поток заказов в течение дня.

**Что сделать.**
- Для роли `admin` в кабинете - вкладка «Дашборд»: все заказы магазина.
- Фильтры: статус и период (дата с - по, включительно).
- Список обновляется сам раз в 30 секунд, в шапке - текущее время.
- Итоги по выборке: число заказов и выручка.
- Сортировка по дате.
- У заказа со скидкой - бейдж со скидкой. Скидка заказа - новое поле `discountKopecks` (по умолчанию 0).
- Панель деталей выбранного заказа: позиции и адрес доставки; адрес можно поправить, получателей у
  доставки может быть несколько (имя и телефон каждого).
- API: `GET /api/admin/orders`, `GET /api/admin/orders/:id`, `PUT /api/admin/orders/:id/delivery` -
  только для `admin`.

**Критерии приёмки.**
- Дашборд работает против реального API.
- `npm run typecheck` и `npm test` зелёные.
