# SD-14. E2E-тесты на заказы

**Зачем.** В e2e сейчас только проверка заголовка страницы. Перед релизом оплаты хотим, чтобы основные
сценарии кабинета проверялись в браузере.

**Что сделать.** Тесты в `e2e/tests/`:
1. Вход под alice и список её заказов.
2. Отмена нового заказа: у заказа статус «Отменён», кнопки «Отменить» у него больше нет.
3. При ошибке сервера на загрузке списка заказов пользователь видит «Не удалось загрузить заказы».

Демо-данные и учётки - `api/src/seed.ts`. Конфигурация Playwright - `e2e/playwright.config.ts`.

**Критерии приёмки.**
- `npx playwright test` в `e2e` проходит локально.
- `npm run typecheck` зелёный.
