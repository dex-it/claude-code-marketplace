# SD-12. Поиск по заказам в кабинете

**Зачем.** У постоянных покупателей десятки заказов, найти нужный в списке сложно. Поддержка просит
поиск по номеру заказа и названию товара.

**Что сделать.**
- На странице «Мои заказы» над списком - поле поиска с подписью «Поиск заказов».
- Результаты обновляются по мере ввода, без кнопки «Найти».
- Ищет сервер: `GET /api/orders?q=<строка>` уже поддерживается API (подстрока номера заказа или
  названия товара, без учёта регистра), в `web/src/api.ts` есть `getOrders(q)`.
- Пустой запрос - полный список заказов.
- Если ничего не нашлось - текст «Ничего не найдено».

**Критерии приёмки.**
- Поиск работает в кабинете против реального API.
- Есть тест на компонент.
- `npm run typecheck` и `npm test` зелёные.
