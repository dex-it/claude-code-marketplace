# SD-15. E2E в CI

**Зачем.** E2E-тесты запускаются только у разработчиков локально и регулярно ломаются незаметно.

**Что сделать.**
- E2E запускаются в CI (GitHub Actions, Linux) на каждый PR и на push в `main`.
- Если e2e упали, в сборке должны быть материалы для разбора артефактами сборки: отчёт и пошаговая
  запись упавших тестов (что происходило на странице на каждом шаге, запросы, консоль).

**Критерии приёмки.**
- Пайплайн e2e описан в `.github/workflows/`.
- Падение e2e делает сборку красной.
- По красной сборке можно скачать отчёт и понять, на каком шаге упал тест.
