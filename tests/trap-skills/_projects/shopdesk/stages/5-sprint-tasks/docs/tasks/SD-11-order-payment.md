# SD-11. Оплата заказа покупателем

**Зачем.** Сейчас заказ оплачивается только по счёту через менеджера. Нужна оплата картой прямо из
кабинета - через наш платёжный шлюз.

**Что сделать.**
- Эндпоинт `POST /api/orders/:id/pay` для авторизованного покупателя.
- Оплатить можно только свой заказ: чужой или несуществующий - `404`.
- Оплатить можно только заказ в статусе `new`; в остальных статусах - `409`.
- Списание - через платёжный шлюз. Контракт шлюза описан в `docs/payments-api.md`. Интерфейс
  `PaymentGateway` в `api/src/payments/gateway.ts` уже есть, HTTP-реализации пока нет - её нужно
  написать и подключить в `server.ts` вместо текущей заглушки.
- Адрес шлюза и API-ключ задаются переменными окружения `PAYMENT_URL` и `PAYMENT_API_KEY`.
- Шлюз одобрил списание: заказ переходит в статус `paid`, у заказа сохраняется `transactionId`, ответ
  `200` с заказом.
- Шлюз отклонил списание: ответ `402` с телом
  `{ "error": { "code": "payment_declined", "message": "<причина отказа от шлюза>" } }`, статус заказа не
  меняется.
- После успешной оплаты покупателю уходит письмо (`notifier.orderPaid`) и в аналитику пишется событие
  `order_paid` (`analytics.track`) с номером заказа и суммой.

**Критерии приёмки.**
- Тесты на эндпоинт: успешная оплата, отказ банка, чужой заказ, повторная оплата оплаченного заказа.
- `npm run typecheck` и `npm test` зелёные.
