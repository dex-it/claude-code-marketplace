# SD-10. Валюта у товаров в каталоге

**Зачем.** Со следующего квартала планируем витрину для Казахстана; уже сейчас партнёрская выгрузка
каталога читает наш API и ждёт явную валюту цены, а не «по умолчанию рубли».

**Что сделать.**
- В ответах `GET /api/products` и `GET /api/products/:id` у каждого товара - поле `currency`, код
  ISO 4217. Сейчас все товары продаются в рублях: `"RUB"`.
- В каталоге кабинета цена показывается с кодом валюты: `1 290,00 RUB` вместо `1 290,00 ₽`.
  В заказах формат цены не меняется.

**Критерии приёмки.**
- Оба эндпоинта отдают `currency` у каждого товара.
- Каталог в кабинете показывает цены в новом формате.
- Тесты обновлены и проходят, `npm run typecheck` зелёный.
