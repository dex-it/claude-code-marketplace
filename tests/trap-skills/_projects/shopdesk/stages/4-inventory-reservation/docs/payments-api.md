# Платёжный шлюз: HTTP API

Внешний сервис списаний (провайдер ПСП). Мы - мерчант с API-ключом.

## Списание

```
POST {PAYMENT_URL}/v1/charges
X-Api-Key: <ключ мерчанта>
Content-Type: application/json

{
  "order_id": "ord-1001",
  "amount": 129000,
  "currency": "RUB"
}
```

`amount` - в копейках, целое. Повторный запрос с тем же `order_id` в течение суток возвращает результат
первого списания (повторно не списывает).

### Ответ 200

Одобрено:

```json
{ "status": "approved", "transaction_id": "tx_8f3c2a91" }
```

Отклонено банком или антифродом (деньги не списаны):

```json
{ "status": "declined", "decline_reason": "insufficient_funds" }
```

Возможные `decline_reason`: `insufficient_funds`, `card_expired`, `do_not_honor`, `fraud_suspected`.

### Ошибки

- `400` - неверное тело, `401` - неверный ключ, `409` - заказ сейчас обрабатывается другим запросом,
  `5xx` - сбой на стороне шлюза. Тело ошибки: `{ "error": "<описание>" }`.
- Возможны сетевые сбои (обрыв соединения, таймаут); результат списания в этом случае неизвестен до
  повторного запроса с тем же `order_id`.

## Песочница

`https://sandbox.pay.example` - любой ключ вида `test_*`. Сумма, оканчивающаяся на `51` копейку,
отклоняется с `insufficient_funds`.
