  раздела B: метку `quality-checks` ставит узел, не писавший артефакт), самоконтроль автора идёт в `self-check`. Шапка
  держит строку реестра `quality-mark.md` («автор плана - никогда») и вызов самопроверкой в `/implement`.
- **Заголовки пяти разделов и сноска-граница** (`design-quality`, `adr-quality`, `requirement-quality`,
  `requirement-set-quality`) - не ловушки, сняты без прогона. Граница с `design-quality` осталась во вводной.
- **Дубли.** Внутри группы и с соседними оракулами - нет: `design-quality` 1.1.2 сам отсылал раскладку на шаги сюда.
  «Открыто» других групп с адресом #302 нет (греп по develop, #327, #329 - пуст).
- **Первоисточник исхода** - нормы каталога (`node-contract`: кто судит, метка); для ловушек плана стандарта нет,
  пункты - названия. Порогов без источника в 1.0.1 нет.
