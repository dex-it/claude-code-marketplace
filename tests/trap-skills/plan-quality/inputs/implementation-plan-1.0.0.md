# План реализации - форма автора

<!-- skill-type: process -->

План раскладывает принятое решение на шаги. Здесь - что пишет у шага автор плана.

## Поля шага

Шаг записан, когда у него заполнены все поля; поле, которое к шагу не относится, несёт `-` с причиной.

| Поле | Что пишется |
|---|---|
| Закрывает | требования, которые шаг закрывает, их идентификаторами; вспомогательный шаг называет шаг, которому служит |
| Предмет правки | что шаг меняет: таблица, схема, модель, модуль, контракт, документ, конфигурация. Чтение предметом не является |
| Исход | результат, наблюдаемый без автора: тест, запрос, метрика, файл. «Реализовано», «работает», «покрыто тестами» исходом не являются |
| Проверка | что прогоняется сразу после шага и подтверждает его исход |
| Зависит от | шаги, после которых шаг начинается, либо `-` |

## Параллельность

Шаги без зависимости между собой идут параллельно. Шаги с общим предметом правки параллельными не
объявляются: между ними стоит зависимость, и порядок назван.
