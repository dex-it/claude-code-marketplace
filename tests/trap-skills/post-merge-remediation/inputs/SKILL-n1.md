# Ремедиация после мерджа

<!-- skill-type: process -->

Фикс бага в уже слитой фиче, с которой развёрнут общий стенд.

## Порядок

1. Фикс - в follow-up ветке и MR (или hotfix по политике проекта), общая ветка не правится.
2. По одному багу на коммит, корневой первым; баг-следствие закрывается фиксом своей причины.
3. До выката: порядок выката по сервисам и план отката.
4. После выката: воспроизводящая проба на стенде, где баг найден, красная до фикса и зелёная после.
5. Регрессионная проба соседей, делящих с фиксом код, контракт, конфиг или таблицу, - до объявления
   закрытым.
