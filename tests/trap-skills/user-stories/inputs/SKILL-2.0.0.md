# User Stories - чек-лист

Пункт называет ситуацию, которую истории проверяются на присутствие.

- История без ценности для пользователя
- Полнота считается с одной стороны: каждое расширение сценария, включая отказ актора, после которого система ничего не меняет, сверяется с критериями всех историй, ветка без критерия - находка
- Пороговое правило без критериев на границе
- Общий ресурс без критерия на одновременный расход
