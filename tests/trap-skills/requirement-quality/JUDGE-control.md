## Засевы, не найденные ни в одном прогоне

- **r1:**
  - FR-2010: метод не доказывает требование. В c1 есть только «слить с FR-2006».
  - Отсутствуют классификация данных и модель авторизации. Изоляцию назвали оба прогона.
- **r2:**
  - FR-2020: мера без второй стороны.
- **r3:**
  - шаг 1: проверка без исхода. Оба прогона флагнули его иначе, за отсутствие основания.
  - шаг без актора и if/else в основном ходе. UI оба нашли.
  - шаг 7: правило числом в шаге и два действия. Оба прогона флагнули иначе.
  - 2a/2b как вариации данных. Оба флагнули иначе.
  - 7a без терминала. Оба написали только «слишком общее».
- **r4:**
  - ST-2001: только счастливый путь.
  - ST-2003: AC без границы. Случай «стоимость равна остатку» не назван.
  - Не покрыты параллельный расход лимита и ветки UC-2001 2a/3a.

Ложные находки по приманкам:
- r3 UC-2008: оба прогона.
- r4 ST-2009: оба прогона, мягко (единицы «2 дня» против SP).
