# Слепой вердикт по перепрогону: r1, r2, r4 (набор v)

Судья - отдельный субагент; прогоны `*-v1`, `*-v2` (ревизия 1: пункты FR, RQ, RSQ, US подняты на ступень «исход») под метками x/y. Раскрытие меток:

| Метка | Прогон |
|---|---|
| `r1-x` | `r1-v1` |
| `r1-y` | `r1-v2` |
| `r2-x` | `r2-v2` |
| `r2-y` | `r2-v1` |
| `r4-x` | `r4-v1` |
| `r4-y` | `r4-v2` |

Текст вердикта - ниже без правки; ASCII-приведение пунктуации.


Все шесть DIFF.patch пустые (0 байт). Это совпадает с ответами: оба исполнителя пишут «Файлы не менял».

Приманки:
- **ST-2008**: оба повесили на неё находки. ### Засевы, которых не нашёл ни x, ни y

- **r1, FR-2010**: метод «пример на данных» не доказывает требование. x считает единицу годной.
- **r1, FR-2008**: модальность «может» прямо не названа (оба только частично).
- **r2, FR-2020**: односторонняя мера, нет второй стороны (полноты выгрузки). Оба отметили FR-2020 по другим основаниям.
- **r2, FR-2009**: шаг 0,25 ч против округления до получаса. x видит форму записи против D-7, y молчит.
- **r2, FR-2012**: термин «лимит» в двух смыслах назван только как противоречие (частично).
- **r2, «Сроки»**: план в требованиях. Оба судят только выполнимость (частично).
- **r4, ST-2001**: только счастливый путь.
- **r4, UC-2001 2a**: отказ сотрудника без критерия.

Отличие x от y в найденном: в r2 только x связал FR-2006 с NFR-0001 и только x вообще тронул FR-2009. В r1 y полнее по FR-2002 (метод) и FR-2007 (условия меры). В r4 x и y практически равны.
