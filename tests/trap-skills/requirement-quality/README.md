## Открыто

- «Метод не наблюдает результат» на названии: NFR-2006 метод `f` 1/2 при контроле 0/2 - название не держит.
  Ступень «исход» (`g`) взяла 2/2, но в r2 уронила FR-2012 и FR-2020 до 0 из 4 (`k`) и тянула находки о методе
  туда, где ключ дефекта метода не засевал (`r1-g2`: две мягкие ложные - FR-2005, FR-2014; `c0-g1` - словесное
  замечание о мере BR-1002). Исход без вреда на чужих строках не найден; решение за владельцем - другая
  формулировка исхода с перепрогоном r1, r2, c0 либо название как есть.
- FR-2008 (модальность «может», нет случая): `s`, `v`, `f`, `g` называют только метод и основание. Контроль
  судил другой судья и засчитал ту же формулировку («проверки нет»); сравнение по якорям - не регресс, а
  разошедшаяся калибровка. Отдельного кейса на форму нет.
