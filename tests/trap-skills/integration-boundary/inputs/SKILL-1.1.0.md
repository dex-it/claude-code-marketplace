# Граница интеграции - чек-лист

- Мок внешней границы врёт о контракте
- Зелёный unit при непокрытой интеграции закрывает фичу
- Слой сборки пропущен между unit и E2E: сгенерированный клиент или типы не сверены с актуальной схемой
