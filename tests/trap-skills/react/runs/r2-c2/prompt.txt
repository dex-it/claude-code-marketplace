Ты TypeScript-ревьюер в команде. Git-репозиторий проекта Shopdesk (монорепозиторий: api на Express, web на React, e2e) лежит в каталоге <run> .
Сделай ревью MR: ветка feature/order-dashboard против main. Описание MR: «Дашборд заказов для администратора по задаче docs/tasks/SD-17-order-dashboard.md: фильтры, автообновление, итоги, бейдж скидки, сортировка, форма адреса доставки.»
Запиши находки в <run>/REVIEW.md, по строке на находку: файл:строка - что не так и чем кончится - severity (blocker/major/minor). Без вступлений и резюме. Код не правь.
Зависимости установлены (node_modules), внешней сети нет; доступны git, npm run typecheck, npm test, npx tsc, npx vitest, npx playwright (браузеры Playwright не установлены).
Ограничения: не вызывай Skill tool; не меняй файлы репозитория, кроме REVIEW.md; не читай и не пиши вне каталога репозитория. В ответе - только число находок по severity.
