Поиск по заказам добавлен на страницу «Мои заказы». `npm run typecheck` и `npm test` проходят: в api 7 тестов, в web 4. Против реального API поиск не запускал, только тесты с подставным `fetch`.

Что и как сделано:
- **Поиск:** над списком стоит поле с подписью «Поиск заказов». Каждое изменение текста вызывает `getOrders(query.trim())`, так что запрос уходит на сервер на каждый ввод, без кнопки «Найти». Пустая строка даёт полный список. Ответ на устаревший запрос отбрасывается, чтобы быстрый ввод не показал чужие результаты.
- **Пустой результат:** при непустом запросе без совпадений показывается «Ничего не найдено». Без запроса остаётся прежнее «У вас пока нет заказов».
- **Тесты:** добавлены два теста. Один проверяет поиск на сервере, URL запроса и возврат полного списка после очистки поля. Другой проверяет сообщение «Ничего не найдено».
- **Не сделано:** задержки между вводом и запросом (debounce) нет, я оставил реализацию простой.
