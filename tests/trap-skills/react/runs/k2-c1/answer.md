Поиск заказов добавлен на страницу «Мои заказы». `npm run typecheck` и `npm test` проходят (api 7 тестов, web 3 теста). Против реального API и в Playwright я его не запускал: браузеров нет.

Изменённые файлы:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- Над списком добавлено поле с подписью «Поиск заказов». Запрос уходит на сервер через `getOrders(q)` с задержкой 300 мс после последнего ввода. Пробелы по краям обрезаются, пустой запрос возвращает полный список.
- Устаревшие ответы игнорируются, чтобы медленный ответ на старый запрос не затёр новый. Список при новом запросе не сбрасывается, поэтому поле не теряет фокус.
- Если по запросу ничего нет, показывается «Ничего не найдено». Если заказов нет вообще, остаётся прежний текст «У вас пока нет заказов».

Новый тест в компонентном файле проверяет три шага: ввод запроса, пустой результат и очистку поля. Он использует подменённый `fetch`.
