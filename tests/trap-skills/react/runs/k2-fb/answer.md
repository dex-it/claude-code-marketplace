Поиск заказов добавлен. `npm run typecheck` проходит, `npm test` зелёный (в web 4 теста, в api 7). В реальном браузере и против живого API я его не запускал: браузеры Playwright не установлены.

Изменённые файлы:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- **Запросы при вводе.** Строка поиска уходит на сервер через `getOrders(q)` только после паузы 300 мс (debounce), так что на каждое нажатие клавиши запроса нет. Устаревшие ответы игнорируются, чтобы медленный ответ на старый запрос не перезаписал новый.
- **Пустые результаты.** Пустой запрос возвращает полный список. Если запрос задан и ничего не нашлось, показывается «Ничего не найдено», иначе остаётся «У вас пока нет заказов».
- **Тесты.** Два новых теста компонента: debounce с одним запросом на введённую строку и «Ничего не найдено» с восстановлением списка после очистки поля. Memo-компонентов с новыми функциями или объектами в props в изменённом коде нет, так что второй пункт чек-листа не затронут.
