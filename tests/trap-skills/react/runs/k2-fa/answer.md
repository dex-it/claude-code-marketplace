Поиск заказов на странице «Мои заказы» готов. `npm run typecheck` и `npm test` проходят, включая 2 новых теста. Против реального API и в браузере я его не запускал: браузеры Playwright не установлены.

Изменённые файлы:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- **Запросы при вводе.** Запрос к серверу уходит через 300 мс после последнего нажатия клавиши, а не на каждое. Ответ на устаревший запрос отбрасывается, поэтому старый результат не перезапишет новый.
- **Состояния списка.** Пустая строка (после `trim`) загружает полный список. Если ничего не нашлось, показывается «Ничего не найдено», а при пустом списке без поиска остаётся «У вас пока нет заказов». Поле поиска не пропадает на время загрузки.
- **Тесты.** Новые тесты проверяют, что запрос уходит один раз после паузы в наборе (`/api/orders?q=xyz`), что показывается «Ничего не найдено» и что после очистки поля возвращается полный список.

Пункт чек-листа про `memo`-компоненты здесь не применялся: в странице их нет.
