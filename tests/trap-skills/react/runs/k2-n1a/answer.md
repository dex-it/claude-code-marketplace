Решения:
- **Debounce:** запрос уходит через 300 мс после последнего ввода. Устаревшие ответы отбрасываются флагом `ignore` в cleanup эффекта, так что запрос на каждое нажатие клавиши не отправляется (по чек-листу команды) и порядок ответов не важен. Поле поиска остаётся на месте, пока грузится новый список.
- **Пустой результат:** при непустом запросе без совпадений показывается «Ничего не найдено». Если запроса нет, остаётся прежнее «У вас пока нет заказов». Пустой запрос возвращает полный список.
- **Тест на компонент:** новый тест проверяет, что промежуточное значение на сервер не уходит. Он же проверяет текст «Ничего не найдено» и возврат полного списка при очистке поля.
