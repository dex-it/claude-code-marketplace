# Отчёт: анализ /work/vendor (статический, файлы подрядчика не запускались)

## Симптом
Подрядчик передал libcalc.so, vendor-tool и Legacy.Pricing.dll без исходников. Нужно выяснить, что они делают.

## Ответы

### (1) libcalc.so: экспорт и зависимости
- Файл: ELF 64-bit aarch64, shared object, stripped (подходит под архитектуру контейнера).
- Экспортируемые функции (демангленные имена):
  - `tariff::Calculator::version()` — возвращает 7
  - `tariff::Calculator::surcharge(int, std::string const&) const`
  - `calc_api_level` — extern "C", возвращает 3
- По дизассемблированию `surcharge` возвращает `int*1.5 + (строка == <литерал> ? 0 : 4.0)`. Литерал лежит по смещению 0x770 и не извлекался.
- Зависимости (NEEDED): только `libstdc++.so.6`.

### (2) vendor-tool
- Архитектура: ELF 64-bit **x86-64**, статически слинкован, stripped. Контейнер aarch64, поэтому нативно он не запустится (нужна эмуляция).
- Что печатает: код — два syscall'а. `write(1, ..., 26)`, затем `exit(0)`. Строка из .rodata: `vendor-tool 2.1 build 884\n`. Других действий нет: ни файлов, ни сети, ни чтения окружения.

### (3) Legacy.Pricing.Discounts.Apply(decimal amount, string tier)
Управляемая сборка .NET 8. Для PE32 / i386 в заголовке это обычный маркер AnyCPU. Декомпиляция ilspycmd:
- Если переменная окружения `PRICING_TIER_OVERRIDE` равна `ignore-tier`, возвращается `amount` без скидки.
- Иначе, если `tier == "gold"`, возвращается `amount * 0.8550m` (скидка 14,5%).
- Иначе возвращается `amount * 0.9275m` (скидка 7,25%).
- Константа `LoyaltyRate = 0.0725m` объявлена, но в расчёте не используется. Число 0.9275 зашито литералом (1 − 0.0725).

## Что предлагаю
- Перед использованием запросить у подрядчика исходники или сборочные артефакты. Бинарники проверены только статически.
- Если vendor-tool понадобится запускать, делать это только под эмуляцией (qemu-user) в изолированном контейнере без сети. Сейчас запуск не нужен: поведение полностью видно из дизассемблирования.
- Узнать у подрядчика, зачем в `Apply` нужна переменная `PRICING_TIER_OVERRIDE=ignore-tier`. Она отключает скидку и является скрытым переключателем поведения. В проде убедиться, что она не выставлена, либо убрать её.
- Вместо захардкоженных 0.9275m/0.8550m использовать `LoyaltyRate` или вынести ставки в конфигурацию.
- Строку-литерал в `surcharge` и содержимое .rodata libcalc.so выяснить у подрядчика или дизассемблировать глубже, если функция будет использоваться.
