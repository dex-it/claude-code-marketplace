# SOLID - чек-лист

Пункт называет ситуацию, которую изменение проверяет.

- Изменение убрало последний вызов типа: интерфейс, его реализация, типы параметров и регистрация в DI остались вне диффа без потребителей
- Класс с несколькими причинами изменения
- Абстракция-обёртка в одну строку над уже внедрённой зависимостью
- Расчёт по данным чужой сущности вне неё
