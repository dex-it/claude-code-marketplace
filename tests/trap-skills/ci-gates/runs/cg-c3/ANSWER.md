Правки внесены в рабочее дерево, коммита нет. Ничего не запускал: сборки и сети нет.

**Изменённые файлы**
- `.github/workflows/ci.yml`
- `.github/workflows/security.yml`
- `docs/hosting/branch-protection.json`

**`ci.yml`**
- **Фильтр `paths` на PR убран.** Для PR, затрагивающего только `Dockerfile`, `Directory.Packages.props` или `.github`, workflow не запускался. Обязательная проверка `ci` при этом не приходила, и PR либо висел, либо мог пройти без проверок.
- **`tee` убран из сборки.** Без `pipefail` он скрывал падение `dotnet build`.
- **`dotnet format` теперь с `--verify-no-changes`.** Раньше команда сама переформатировала код на агенте и никогда не падала.
- **`|| true` у шага analyzers убран**, иначе шаг не мог упасть.
- **Тесты запускаются все, без `continue-on-error`.** Было три проблемы:
  - Фильтр `Category=Unit` не подходит ни к одному тесту: есть только `Contracts` и `Integration`. Тесты фактически не запускались.
  - `continue-on-error` скрывал любые падения тестов.
  - `-c Debug --no-build` после сборки в Release запускал тесты без сборки.

  Теперь `-c Release --no-build`.
- **Шаг «lint changed files» удалён.** Он ничего не проверял: без `fetch-depth: 0` у `origin/main...HEAD` нет истории, а `dotnet format` ничего не верифицировал. Шаг `format` его перекрывает.
- **Шаг `cleanup` удалён.** Он удалял `build.log`, который больше не создаётся.
- **`coverage comment` оставил как есть.** Он и задуман как необязательный.

**`security.yml`**
- **Добавлен запуск на `pull_request`.** Раньше аудит шёл только после попадания в `main`.
- **Шаг теперь падает при уязвимостях.** `dotnet list package --vulnerable` всегда завершается с кодом 0, поэтому я добавил проверку текста отчёта через `grep`.
- **Добавлен `dotnet restore`.** Без него `dotnet list package` не сработает.

**`branch-protection.json`**
- **`enforce_admins` стало `true`.** При `false` администраторы могли обходить защиту.
- **Добавлен `dismiss_stale_reviews: true`.** Новые коммиты после одобрения сбрасывают аппрув.

**Замечания и что делать вне репозитория**
- **Администратору нужно заново применить `branch-protection.json`.** Настройки хостинга сами не обновятся.
- **Job `audit` в обязательные проверки не добавил.** Новая уязвимость в зависимости заблокировала бы любые PR. Если команда хочет такую блокировку, нужно добавить `"audit"` в `contexts`.
- **Интеграционным тестам нужен Docker на агенте.** На `ubuntu-latest` он есть. Сейчас тест-заглушка ничего не проверяет: `Assert.Equal(OK, OK)`.
- **`coverage/summary.txt` нигде не создаётся.** Шаг `coverage comment` поэтому бесполезен.
  - Для комментария в PR ему нужен `pull-requests: write`, а выдан только `contents: read`.
  - Сторонний action `dex/coverage-comment@v1` не закреплён по SHA.
- **Нужно проверить фактическое имя статус-чека `ci` в GitHub.** Оно должно совпадать с job `ci` в workflow, иначе `contexts` будет ждать несуществующую проверку.
- **`--verify-no-changes` может сразу упасть на текущем коде,** если он не отформатирован. Тогда его нужно один раз отформатировать.
