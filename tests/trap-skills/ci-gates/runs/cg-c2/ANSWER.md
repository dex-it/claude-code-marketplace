**Что исправлено в `ci.yml` и почему**
1. **Тесты ничего не проверяли.** Фильтр `Category=Unit` не подходит ни под один тест: в репозитории есть только категории `Contracts` и `Integration`. Ещё и `continue-on-error: true` скрывал любое падение. Убрал фильтр и `continue-on-error`, теперь идут все тесты. Интеграционным нужен Docker, он есть на `ubuntu-latest`.
2. **Конфигурация не совпадала.** Сборка шла в Release, а тесты запускались с `-c Debug --no-build`. Теперь тесты тоже идут в Release.
3. **`dotnet format` только переформатировал код на агенте и ничего не проверял.** Добавил `--verify-no-changes`. Шаг «lint changed files» удалил: он повторял format, ничего не проверял и не работал без полной истории (`origin/main`).
4. **Шаг analyzers заканчивался на `|| true`.** Убрал, теперь он может упасть.
5. **`build | tee` скрывал падение сборки**, потому что в bash по умолчанию нет pipefail. Задал `shell: bash` для всех шагов, это включает pipefail.
6. **Фильтр `paths` на `pull_request`.** Если PR не трогает `src/` и `tests/`, обязательная проверка `ci` не запускается, и такой PR нельзя смержить. Фильтр убрал. Из-за него же в `main` могла попасть правка, например `Directory.Packages.props` или `global.json`, без проверки.
7. **Cleanup:** `|| true` заменил на `rm -f`.
