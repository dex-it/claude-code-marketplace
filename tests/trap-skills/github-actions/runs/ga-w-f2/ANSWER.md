Я добавил два workflow, но не проверял их: запустить сборку, `actionlint` или GitHub здесь нельзя. Ничего не закоммичено.

**Новые файлы**
- `.github/workflows/ci.yml`
- `.github/workflows/pr-size.yml`

**Что сделано**
- **Тесты (`ci.yml`):** на PR и push в `main` идут сборка и тесты на .NET 8 (версия из `global.json`). На ubuntu запускаются все тесты, включая Testcontainers. На windows запускается только `Category=Contracts`. Шаги идут `restore` → `build --no-restore` → `test --no-build`.
- **Артефакты:** результаты тестов (trx) и покрытие (coverlet) сохраняются на 14 дней (`retention-days`).
- **Гейты:** добавлен аудит уязвимых зависимостей. Статический анализ даёт `TreatWarningsAsErrors` на шаге сборки.
- **Форматирование:** `dotnet format` работает как отчёт и не блокирует релиз (`continue-on-error`). Отчёт сохраняется артефактом.
- **Лицензии:** `license-check` вызывает reusable workflow `@v2` после тестов.
- **Образ и деплой на `main`:** образ собирается и пушится в `registry.example.com/depot/api:<sha>`, но только после тестов, аудита и проверки лицензий. После этого запускается `deploy.yml` в `dex/depot-infra`.
- **Метка размера (`pr-size.yml`):** работает на `pull_request_target`, поэтому ставит метки и на PR из форков. Код PR не извлекается и не исполняется.
- **Прочее:** повторные push в PR отменяют старые прогоны; права по умолчанию только `contents: read`.

**Замечания**
1. **Actions закреплены тегами, не SHA.** Дисциплина требует SHA, но без сети я его не узнаю и не стал выдумывать. В файлах стоят TODO; это касается и `license-check@v2`.
2. **Нужен ещё один секрет.** Стандартный токен не может запускать workflow в другом репозитории, поэтому деплой читает `DEPOT_INFRA_DISPATCH_TOKEN` с правом `actions:write` на `dex/depot-infra`. Создайте этот секрет, иначе деплой не сработает.
3. **Неизвестно, какой образ деплоится.** Входы `deploy.yml` в задаче не описаны, поэтому я ничего не передаю. Если workflow принимает тег образа, добавьте `-f`.
4. **Нет лок-файлов `packages.lock.json`.** Режим `--locked-mode` я не включал: он упал бы, а сгенерировать файлы без dotnet я не могу. Нужно включить `RestorePackagesWithLockFile`, закоммитить файлы и добавить `--locked-mode` в restore.
5. **Обязательность проверок для мержа** настраивается в защите ветки `main`, а не в репозитории. Сделайте обязательными `test (ubuntu)`, `test (windows-contracts)`, `audit` и `license-check`. `format` не добавляйте.
6. **Self-hosted раннеры `depot-linux` не использованы.** Требование 1 прямо называет `ubuntu-latest`. Кроме того, PR из форков на раннерах внутри сети компании небезопасны.
7. **Пороги меток я выбрал сам:** `size/S` до 50 изменённых строк, `size/M` до 250, дальше `size/L`. Подправьте, если нужны другие.
8. Запуск образа `Dockerfile` с `USER 1654` и интеграционные тесты в `StockTests.cs` пока заглушки, это не относится к CI.
