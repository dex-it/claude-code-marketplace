## Ревизия 3 по ревью владельца (PR #368): поле активации

`GITHUB_TOKEN`, `matrix`, `concurrency`, `permissions` в `description` оставлены без пунктов в теле: это якорь технологии. Активация
`github-actions-in` дала 1/3 на первой формулировке (без них) и 3/3 после расширения; снять слова значит менять измеренную активацию.
Активаторы шире тела намеренно.
