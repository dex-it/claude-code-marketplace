## Факты, по которым ловушки признаны неверными

- Модификатор `required` к валидации биндинга options отношения не имеет: биндер создаёт объект и
  заполняет свойства без object initializer. Проверка на старте - `[Required]` + `ValidateOnStart`
  (документация .NET, options validation).
- Конфигурация .NET не раскрывает `${VAR}` в значениях: секрет из окружения подаётся переменной с
  именем ключа (`ConnectionStrings__Db`), а не плейсхолдером.
