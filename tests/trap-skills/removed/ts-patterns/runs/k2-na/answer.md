Поиск по заказам добавлен на страницу «Мои заказы». `npm run typecheck` и `npm test` проходят (4 теста в web). Против реального API я его не запускал, потому что сети нет, а браузеры Playwright не установлены.

Изменённые файлы:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- **Запросы при вводе.** Поле «Поиск заказов» отправляет запрос через `getOrders(q)` только после паузы в 300 мс, а не на каждое нажатие (чек-лист react). Устаревшие ответы отбрасываются флагом `cancelled`, по тому же образцу, что в `ProductsPage.tsx`. Прецедента для самого значения 300 мс в коде нет, это моё допущение.
- **Пустой запрос и «Ничего не найдено».** Пустой запрос возвращает полный список. «Ничего не найдено» показывается, когда непустой запрос ничего не вернул, а «У вас пока нет заказов» остаётся для пустого списка без запроса.
- **Тесты.** Два новых теста с fake timers: один проверяет один запрос после паузы и адрес `/api/orders?q=...`, другой — текст «Ничего не найдено» и возврат полного списка после очистки поля.

Серверную часть и `api.ts` не менял: `q` уже поддерживается.
