Поиск по заказам добавлен на страницу «Мои заказы». `npm run typecheck` и `npm test` проходят: в api 7 тестов, в web 4, из них 2 новых. Я не проверял поиск вручную в браузере против реального API.

Изменённые файлы:
- `web/src/components/OrdersPage.tsx`
- `web/src/components/__tests__/OrdersPage.test.tsx`

Решения:
- **Запросы:** запрос к серверу уходит с паузой 300 мс после последнего нажатия, через хук `useDebouncedValue` в том же файле (пункт чек-листа react про запрос на каждое нажатие). Устаревшие ответы отбрасываются, поэтому медленный старый ответ не затрёт свежий. Для этого нужен флаг `stale` в эффекте. Предыдущий список остаётся на экране, пока грузится новый.
- **Пустые состояния:** если запрос пустой, показывается полный список через `getOrders('')`. Если по непустому запросу ничего нет, текст «Ничего не найдено», иначе прежнее «У вас пока нет заказов». Пробелы по краям строки обрезаются.
- **Прецеденты:** у `getOrders(q)` и серверной части `q` прецедент в `web/src/api.ts` и в API, их я не менял. Таймаут 300 мс — допущение, прецедента в репозитории нет.

Сервер валидирует `q` или нет, я не проверял, серверный код не трогал.
