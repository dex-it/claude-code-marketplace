# clean-architecture: сжатие по свидетельству, группа 1.2 - снят

Скилл `dex-skill-clean-architecture` 1.4.1 ([`inputs/SKILL-1.4.1.md`](inputs/SKILL-1.4.1.md)) снят
целиком, эпик #291, группа 1.2 (#294). Промежуточные редакции - n1
([`inputs/SKILL-n1.md`](inputs/SKILL-n1.md)) и 1.5.0 ([`inputs/SKILL-1.5.0.md`](inputs/SKILL-1.5.0.md),
пять названий без кейса); 1.5.0 снята на ревью PR #316 - ниже, «Без кейса».

Вход, исполнитель (`claude-sonnet-5-5`, effort medium, MCP нет), промпты, наборы и правило
засчитывания - общие для группы, в протоколе [solid](../../solid/README.md#заход-группы-12-2026-10-05).
Кейс - A2 (кредит-ноты, BILL-33: первое хранение в БД, EF Core + SQLite), выходы - в протоколе
[ddd](../../ddd/README.md) (`runs/a2-*`).

Тринадцать измеренных ловушек контроль ловит 2/2 - все сняты; n2 (набор без них) берёт их тоже 2/2,
сужения охвата нет. Противоречие «один `SaveChanges`» (`clean-architecture`) и «один агрегат на
транзакцию» (`ddd`) снято вместе с C-n.

**Без кейса.** Пять ситуаций требуют масштаба или основы, которых в Billing нет: многопроектный
solution (циклическая ссылка, Shared/Common), 100+ сценариев (папка-на-слой), тесты (RUL-0002, задача их
не требует), specification-база репозитория. Редакция 1.5.0 держала их пятью названиями; ревью PR #316
сняло скилл, потому что предмета Clean Architecture (правило зависимостей, размещение логики) среди них
не осталось - он измерен и снят 13 ловушками выше:

- папка-на-слой и Shared/Common - раскладка решения, конвенция команды: исход эпика «единица ушла в свод
  правил проекта»;
- тесты только через HTTP - стратегия тестирования, не архитектура; в тест-скилл без свидетельства не
  перенесена, открыто;
- узкий метод рядом со specification-базой противоречил названию `ddd` «Specification для простого
  запроса», оба грузились на одной оси - снят;
- цикл `ProjectReference` сборка отвергает сама (`MSB4006`, .NET SDK 10.0.112, проба 05.10.2026); скрытая
  связь Infrastructure -> Application вызовами - предмет C-b и C-l, контроль 2/2.

**Приманки и охват.** A2: PQ (`QuoteInvoiceHandler` -> `FxRatesClient` вне диффа), PD (три `DbSet` -
не God DbContext), PL (DTO списка) - не подняты blocker/major ни в одном наборе; O1, O2 - 2/2.

## Открыто

- Тесты только через HTTP: дом по предмету - тест-скиллы; кейса нет.
- `diagram-creator` и `adr-writer` грузили скилл для диаграмм слоёв и валидации паттернов; эти
  поручения не мерились, загрузка снята вместе со скиллом.
