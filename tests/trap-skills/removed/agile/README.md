[`key-ledger.md`](../../_projects/classmate/key-ledger.md). Исполнитель - `claude-sonnet-5-5`, effort medium,

нули сверены вручную - [`control-c.md`](../../_projects/classmate/control-c.md). Контроль `c1`-`c4` - без
скиллов бэклога; в наборах `s`-`z` agile в дисциплине нет, и его клетки - тоже прогоны без скилла.
