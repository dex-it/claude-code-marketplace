## Возврат названиями

Дом - оси агентов ревью кода, которые раньше грузили скилл по содержимому diff: `mr-reviewer` -
строка Regressions and ops («Недоделки: TODO без тикета, отключённый тест, debug-вывод»),
`mr-check-reviewer` - то же для дельты, находки - в блоки код-осей. У `self-reviewer` ось
`loose-ends` безусловна и уже называет TODO/FIXME, отключённые тесты и debug-вывод - правки нет.
Форма - шаг 1 «Формы пункта»: названия ситуаций без решения.

Проверка - тот же промпт, строки осей `mr-reviewer` поданы файлом дисциплины
([owasp-security/inputs/AXES-named.md](../owasp-security/inputs/AXES-named.md)):

| Ловушка | Контроль medium | С названием |
|---|---|---|
| TODO без тикета (S1 LT) | 1/4 | 4/4 (`m-S1-n1`..`n4`) |
| Отключённый тест (S2 LS) | 2/4 | 2/2 (`m-S2-n1`, `n2`) |
| Debug-вывод (S2 LP) | 2/4 | 2/2 |

Остальные ловушки S1, S2 в прогонах `n` пойманы, приманки чисты, E0 (`m-E0-n1`) - без blocker/major.
Дом - оси агентов ревью (решение 2026-10-05, тред PR #314): так же автор решил для R-f в PR #316 -
название в агенте, без восстановления скилла ради одной ситуации.

Сторона автора (`bug-fixer`): кейса с соблазном недоделки нет. Кодерские прогоны F1 без скилла
([codebase-conventions](../../codebase-conventions/README.md), `f1-mc1`, `f1-mc2` - `claude-sonnet-5-5`,
effort medium) - 2/2 без хвостов: 0 строк `+` с TODO, `NotImplemented`, `Console.Write`, пустым
`catch`; `f1-c1`, `f1-c2` первого захода (effort не записан) - справочно, тоже без хвостов. Засчитывается
ли контроль ревью снятием для стороны автора: решение 2026-10-05 (тред PR #314) - открыто для стороны автора без возврата текста; кейс-поручение на код ставится в группе разработки эпика (группа 2).

Синхронизации: запись каталога, шесть бандлов и README двух из них, загрузка в пяти агентах и README
трёх, сноски `karpathy-guidelines`, `completeness-mapping` (строка «Хвосты» - «дома нет, проверяй
сам»), `post-merge-remediation`, кейс активации `no-loose-ends-in`, витрина README. Ось `loose-ends` в
`self-reviewer` остаётся безусловной - снята только загрузка скилла.
