мини-проекта, коммит `d9a5e4b0` (2026-10-11 09:23 +0300) до первого прогона. Кейсы: G-S (контракт под новые

`claude-sonnet-5-5`, `skills` и `mcp_servers` в init-событии пусты во всех прогонах. Каталог прогона -
