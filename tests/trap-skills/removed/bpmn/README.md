засчитывание и первоисточник исхода (BPMN 2.0.2, formal/13-12-09) - README мини-проекта; ключ зафиксирован

`claude-sonnet-5-5`, effort medium, Claude Code 2.1.302, `claude -p --restricted --strict-mcp-config` без MCP;
суд - второй оценщик вслепую `claude-opus-5-5` medium (`judge-blind.sh`), нули и «ничего не менять» сверены
вручную - [`control-c.md`](../../_projects/classmate/control-c.md). База - роль одной строкой: тело
`process-modeler` в плечо не подаётся (README мини-проекта, «W-BP и роль одной строкой»). Прогоны
`runs/{wbp,rbp,r0b}-c1,c2` - контроль без скилла; со скиллом прогонов нет: снятие по контролю.
