**ET0 («ничего не менять»).** Контроль `c1`, `c2` на первой фикстуре нашёл настоящие расхождения со спецификацией (`Number()` пропускает `1e1`, `0x10`; `id` `0x3`; пустой `--ref`; флаг без
значения): фикстура не была чистой. Правка кейса и критерий (дефект = противоречие пункту спецификации с воспроизведением; «вопрос к спецификации» и «наблюдение» дефектом не считаются) -
коммит `63b82f19` до пары `d`. Пара `d1`, `d2` нашла два противоречия, внесённые самой правкой (проверка полей раньше `--ref`; `--status ""`) - вторая правка, коммит `3828609e`, пара `e1`,
`e2`: **ноль дефектов по спецификации 2/2**, замечания низкой серьёзности («уточнить»), `parseMoney` (`n == NaN`) вне CLI. Прогоны `c`, `d` в ET0 справочно.
