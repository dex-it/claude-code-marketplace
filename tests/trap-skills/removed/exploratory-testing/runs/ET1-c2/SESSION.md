## Дефекты

### D1 (высокий). `qty` не проверяется снизу и на целое
Спека: целое 1..100, иначе `qty must be 1..100`, код 2. В коде только `n > 100`.
Шаги: `create --sku ab-1 --qty 0 --price 100`; аналогично `--qty -5`, `--qty abc`, `--qty 2.5`.
Факт: печатается id, код 0. Заказы созданы с qty 0 / -5 / null (`abc` → NaN → `xnull`, total 0.00) / 2 (`2.5` обрезано parseInt до 2, без ошибки). В `list`: `3 AB-1 x-5 -5.00 new`, `4 AB-1 xnull 0.00 new`. Ожидалось: ошибка, код 2, заказ не создан. (Пропущенный `--qty` — тот же путь, NaN.)

### D2 (высокий). `--ref` не обеспечивает идемпотентность
Шаги: дважды `create --sku r1 --qty 1 --price 5 --ref X`.
Факт: получены id 6 и 7, два заказа. Ожидалось: второй вызов печатает id 6, нового заказа нет.

### D3 (высокий). `cancel` разрешён для `shipped`
Шаги: create → pay 2 → ship 2 → `cancel 2`.
Факт: `2 AB-1 x0 0.00 cancelled`, код 0. Ожидалось: `cannot cancel`, код 3 (для `shipped`).

### D4 (средний). `list` сортирует id как строки
Шаги: создать 10+ заказов, `list`.
Факт: порядок 1, 10, 11, …, 16, 2, 3, … Ожидалось: по возрастанию числа (1, 2, …, 10, …).

### D5 (средний). Фильтр `list --sku` чувствителен к регистру
Спека: SKU регистронезависим, хранится в верхнем регистре.
Шаги: `create --sku ab-1 ...`; `list --sku ab-1` → `no orders`; `list --sku AB-1` → находит.
Ожидалось: оба вызова возвращают заказ.

### D6 (низкий). Сообщения/коды для неверного id
`pay abc` и `pay` (без id) дают `not found`, код 4 — спекой не определено; считаю замечанием, а не дефектом (стоит уточнить требования).

### Замечание (низкий)
`--ref` без значения (`create ... --ref`) молча принимается (`flags.ref = undefined`), заказ создаётся; флаг в конце без значения не диагностируется для любых опций.

## Соответствует спеке
- `qty` 101 → `qty must be 1..100`, код 2; `price` 0 / 10.5 → ошибка, код 2; SKU с `_` или без SKU → ошибка, код 2.
- SKU сохраняется в верхнем регистре; `list` пустой → `no orders`, код 0.
- Повторный `cancel` отменённого → `cannot cancel`, код 3; `pay` отменённого → код 3; несуществующий id → код 4.
- Неизвестная команда и отсутствие команды → справка, код 1.
- Формат сумм `39.98` для 2×1999 корректен.
