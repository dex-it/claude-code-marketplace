**Critical (5):**
- **Нет общей транзакции:** `EnqueueAsync` открывает своё соединение и коммитит сразу, хотя контракт обещает транзакцию вызывающего. Заказ и outbox-запись могут разойтись.
- **Повторная отправка:** после успешного POST в payments отметка `sent_at` ставится отдельным шагом. При сбое между ними сообщение уходит повторно, и защитой остаётся только `Idempotency-Key` на стороне payments.
- **Lease короче обработки:** lease на 30 с, а батч из 50 сообщений идёт последовательно, и таймаут HTTP по умолчанию 100 с. Хвост батча теряет lease, и его забирает другая реплика.

- **Падение при сбое БД:** `TakeBatchAsync` вызывается вне try/catch. Сбой БД выходит из `ExecuteAsync` и по умолчанию останавливает весь хост.
