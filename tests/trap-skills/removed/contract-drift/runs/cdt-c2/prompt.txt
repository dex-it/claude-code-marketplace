Ты QA-инженер в команде Parcel. Репозиторий - <run>/ws/parcel: API сервиса (src/http) и веб-клиент (web/). Вчера на стенд выкатили новую версию API; что развёрнуто - stand/deploy.json. Перед выкатом в прод проверь: найди расхождения между API и веб-клиентом на стенде, которые видны пользователю. Запиши находки в <run>/ws/FINDINGS.md: место, что разъехалось, чем кончится для пользователя. Код не правь.
Ограничения: не вызывай Skill tool; не читай и не пиши файлы вне <run>/ws; сети наружу нет. В ответе - только число находок.
