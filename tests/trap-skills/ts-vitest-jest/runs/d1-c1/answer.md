Я добавил `api/test/checkout.test.ts`. Другие файлы не менял, код модулей тоже. `npm run typecheck` и `npm test` проходят: в api 15 тестов, в web 2.

Тесты покрывают все пункты задачи: расчёт без промокода и с ним, неподошедший промокод (неизвестный и с нехваткой суммы, в обоих случаях проверяю предупреждение в журнале), фиксированный тариф при `DeliveryUnavailableError`, проброс любой другой ошибки и лимит попыток.

- **Служба доставки и журнал:** `delivery.quote` и `logger.warn` подменены через `vi.spyOn`, поэтому настоящих обращений к службе доставки нет. После каждого теста моки сбрасываются.
- **Счётчик попыток:** он хранится в состоянии модуля и между тестами не сбрасывается. Поэтому каждый тест берёт свой `customerId`, и тесты друг на друга не влияют.
