Я добавил `api/test/reservation.test.ts` и покрыл в нём все пункты задачи. После правки названия одного теста `npm run typecheck` и `npm test` я не перезапускал. До неё оба проходили: в api 17 тестов, в web 2.

Код модуля не менял, коммит не делал.

**Что проверяют тесты:**
- Резерв с первой попытки.
- Повтор после двух временных сбоев и успех на третьей попытке.
- Повтор не происходит раньше задержки в 1 секунду.
- После трёх неудач выбрасывается `ReservationFailedError`.
- Обычная ошибка склада пробрасывается сразу, без повторов.
- `isHoldExpired`: граница, когда время ровно вышло, текущее время по умолчанию и согласованность с `holdUntil`.

**Решения:**
- Настоящий склад не вызывается: `inventory.reserve` подменён через `vi.spyOn`, паузы между повторами идут на fake timers, поэтому тесты быстрые.
- `isHoldExpired` без явного времени проверяю с зафиксированными часами `vi.setSystemTime`.
