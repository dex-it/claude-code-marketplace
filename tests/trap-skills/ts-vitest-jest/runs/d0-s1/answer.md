Я добавил юнит-тесты для `formatKopecks` и `splitEvenly`. `npm run typecheck` и `npm test` проходят: в api 2 файла и 23 теста, в web 2 теста.

Изменённый файл: `api/test/price-format.test.ts` (новый, лежит рядом с `orders.test.ts`). Код модуля не менялся, ничего не закоммичено.

- **Пробел в формате цены:** модуль разделяет тысячи и ставит перед `₽` неразрывный пробел (U+00A0). В тестах он задан явно как `\u00a0`, чтобы его нельзя было спутать с обычным пробелом.
- **Что покрыто дополнительно:** копейки с ведущим нулём (`0,07`), сумма частей равна исходной сумме, случай «частей больше копеек». Недопустимое число частей (`0`, `-1`, `1.5`, `NaN`, `Infinity`) проверено через `it.each`, везде ожидается `RangeError`.
- **Моки:** не использовались. Функции чистые, тесты проверяют только результат.
