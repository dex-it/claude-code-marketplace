Я добавил тесты для модуля резервирования. `npm run typecheck` и `npm test` проходят: в api 16 тестов, в web 2.

**Изменённые файлы:** новый `api/test/reservation.test.ts`. Код модуля не менял, ничего не коммитил.

**Решения:**
- **Склад:** `inventory.reserve` подменён через `vi.spyOn`, так что настоящий склад не вызывается. Логгер заглушён.
- **Паузы между попытками:** время фейковое (`vi.useFakeTimers` и `advanceTimersByTimeAsync`), поэтому тесты не ждут реальные 1 и 2 секунды. В тесте повтора проверяется и сама задержка: после 1000 мс идёт вторая попытка, после ещё 2000 мс третья.
- **`isHoldExpired`:** проверены граница (ровно `holdUntil` — ещё не истёк), значение `now` по умолчанию и согласованность с `holdUntil`.
