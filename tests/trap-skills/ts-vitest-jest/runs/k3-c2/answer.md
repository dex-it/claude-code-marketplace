Тесты на резервирование написаны. `npm run typecheck` проходит с кодом 0. `npm test -w api` зелёный (14 тестов, из них новых 7), а полный `npm test` дошёл до web, где тоже всё зелёное.

**Изменённые файлы:**
- `api/test/reservation.test.ts` (новый)

**Решения:**
- `inventory.reserve` и логгер замоканы через `vi.mock`, поэтому настоящего склада и сети нет. `TemporaryInventoryError` оставлен настоящим, чтобы `instanceof` в модуле работал. Паузы между повторами проверяются на fake timers, так что тесты идут мгновенно: после 1000 мс идёт вторая попытка, после ещё 2000 мс — третья.
- Покрыты пять случаев из задачи: успех с первой попытки, повтор после сбоя и успех, `ReservationFailedError` после трёх попыток, обычная ошибка склада без повторов и `isHoldExpired`. Для `isHoldExpired` проверены граница (в момент `holdUntil` ещё не истёк), значение `now` по умолчанию и согласованность с `holdUntil`.
- Код модуля не менялся. Тест лежит в `api/test/`, рядом с `orders.test.ts`, и подхватывается существующим `vitest.config`.
