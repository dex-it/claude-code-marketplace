Я добавил unit-тесты для `formatKopecks` и `splitEvenly`. `npm run typecheck` и `npm test` проходят: в api 22 теста, в web 2. Код модуля не менял, ничего не коммитил.

Изменённые файлы:
- `api/test/price-format.test.ts` (новый, рядом с `orders.test.ts`; vitest подхватывает его по маске `test/**/*.test.ts`)

Решения:
- В `price-format.ts` разделитель тысяч и пробел перед `₽` — неразрывный (U+00A0). В тестах он задан константой `\u00a0`, чтобы его нельзя было заменить обычным пробелом при правке.
- Моков нет: обе функции чистые, проверяются только возвращаемые значения.
- Недопустимое число частей (0, -1, 1.5, NaN, Infinity) покрыто через `it.each` с проверкой `RangeError`. Отдельно проверены сумма частей, равная исходной, и случай, когда сумма меньше числа частей: `splitEvenly(2, 4)` даёт `[1, 1, 0, 0]`.
