## Заход #321: V3, V9, V10 (запись до прогонов)

Ключ, мины, эталоны (ok: 10 из 10 мутантов KILLED; trap: 10 из 10 SURVIVED, shuffle seed=3 FAIL) и раннер
`run-group-321.sh` закоммичены до первого прогона.

Исполнитель: `claude -p`, `claude-sonnet-5-5`, effort medium, `--restricted --strict-mcp-config`, без `Skill` tool,
Bash в песочнице Claude Code без внешней сети (как в группе 2.3, `sandbox.json`), каталог прогона вне репозитория. Node 24.20.0 и
vitest 4.1.7 на машине есть и исполняются в песочнице: мины гоняет оператор после прогона, засчитывание по мутантам и по коду.
Jest в проекте нет (Jest-половина V3 остаётся `unverifiable`, как у V1).

Число прогонов. Решение 2 эпика (добор до 5) не принято: единица снимается, если верна во всех прогонах контроля. Контроль K3D
- 4 прогона (два плюс два добора, как K3 в этой группе, цена прогона около $0.1); вердикт «снята» - только 4/4, при этом
