## Шаг 0

- **Числа ловушек** («1% пользователей создают 80% трафика», «в 10000× раз больше», «scatter-gather на 100 shards») -
  иллюстрации без источника; в пункт не пишутся.
- **Дубли внутри группы.** SC5 «дом и SC2» - одна ситуация: состояние зрителя или сессии в памяти пода при деплое и
  автоскейле (D3). SC9 «дом и SC7» - длинный хвост нагрузки на одном узле: крупный автор в ключе шардирования (D5);
  SC7 отдельно меряет горячий ключ поста крупного автора в D1.
- **Снятые в группе 1.2** - общая база двух сервисов ([microservices](../removed/microservices/README.md)) - справка;
  «Shared mutable state между сервисами» (SC6) судится заново своим кейсом.
- **Кейс D7** заведён после контроля D1-R0P: единицы «File system как state» и «Shared mutable state» оставались без
  кейса. Ключ D7 - `db4ad49b`, до прогона D7.

## Итоговая редакция

крупных (`f1`).
