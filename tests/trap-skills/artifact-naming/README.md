# artifact-naming: сжатие по свидетельству, группа 3.2

Скилл `dex-skill-artifact-naming` 1.3.2 ([`inputs/SKILL-1.3.2.md`](inputs/SKILL-1.3.2.md)), эпик #291,
группа 3.2 (#301). Итог - 2.0.0, process-skill ([`inputs/SKILL-2.0.0.md`](inputs/SKILL-2.0.0.md);
промежуточная n1 - [`inputs/SKILL-n1.md`](inputs/SKILL-n1.md)), строка в реестре
[`tests/README.md`](../../README.md).

Вход, исполнитель, раннер и кейсы - общие для группы, описаны в протоколе
[decision-log](../decision-log/README.md); прогоны лежат там же. Скилл мерится кейсами N1 (новая фича в
Loyalty - пустое место, дефолт) и N2 (новая фича в чужом репозитории Wallet - занятый корпус), плюс
K2 (единица в существующую фичу).

## Потребители

- Агенты зоны требований: `requirements-analyst`, `usecase-analyst`, `user-story-analyst`,
  `business-requirements-analyst`, `domain-analyst` - «границу применения конвенции к занятому корпусу
  держит `artifact-naming`».
- `project-docs-map` (раскладки под фичи нет - когда конвенция не применяется), `docs/CORPUS.md`
  (раздел «Границы конвенции»).
- Бандлы: `architect`, `bug-lifecycle`, `code-review`, `devops`, `dotnet-developer`, `dotnet-fullstack`,
  `infrastructure`, `market-editor`, `ml-engineer`, `product-manager`, `qa-engineer`,
  `runtime-diagnostics`, `system-analyst`, `ts-fullstack`. Кейс активации `artifact-naming-in`.

Входящие ссылки сверены грепом по `dex-skill-artifact-naming` и названиям разделов 1.3.2: по имени
адресуется один раздел - «Границы конвенции» (`docs/CORPUS.md`), в 2.0.0 он есть.

## Тип единиц и дубли (шаг 0)

Содержание - конвенция раскладки и границы её применения, видимые из соседних файлов: кейсы на
корпусе. Решение принято до прогонов.

Дубли и снятые без прогона:
- «Дерево развернули, не записав куда» (A3) = `project-docs-map` п.1-п.2 (завести `.docs_layout`
  найденным, запись - пунктом выхода).
- «Недостижимый корень обходят молча» (A6) = `project-docs-map` п.4 (`unverifiable` + причина) и
  терминалы составителей (`status: blocked` с названным путём).
- «Путь разрешают заново на каждом узле» (A4) = тела составителей («Путь пришёл сквозным полем -
  берётся как есть»); кейсом одного исполнителя не вынуждается - `unverifiable`.
- «Место назначают строкой в теле узла» (A5) - норма авторства агентов каталога, не поведение
  исполнителя: исполнитель тело агента не правит. Снята; дома в нормах авторства нет - #328.
