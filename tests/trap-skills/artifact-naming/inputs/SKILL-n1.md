# Именование артефакта

<!-- skill-type: process -->

Место артефакта разрешается процедурой, а не берётся из класса: сквозное поле входа, потом корень корпуса из `.docs_layout` (`dex-skill-project-docs-map:project-docs-map`), потом сложившаяся раскладка корпуса. Дерево и имена файлов классов - дефолт норматива раскладки `dex-skill-docs-layout:docs-layout`.

## Границы конвенции

Дефолт - для пустого места: корпус пуст либо артефакт этого класса в нём ещё не встречался. Артефакт класса в корпусе уже есть - каталог и форма имени берутся с образца, второе дерево по конвенции рядом не заводится. Уже лежащее ради конвенции не переносится и не переименовывается: это решение владельца корпуса, не побочный эффект прогона.

## Имя и слаг

Имя файла несёт класс и принадлежность фиче; версия, статус и дата живут внутри файла, в `decision-log` и в истории репозитория. Раскладка - по классам и фичам, не по номерам единиц: у класса в фиче одно место. Слаг фичи выводится из темы один раз, при заведении, дальше читается из существующего пути `<NN>-<слаг>`.

Дерево разворачивает вызывающая сторона зоны; составитель без дерева на входе каталогов сам не создаёт и называет это состоянием выхода. Служебное состояние прогона (`auto-ledger` и иные носители хода работы) в дерево корпуса не входит.
