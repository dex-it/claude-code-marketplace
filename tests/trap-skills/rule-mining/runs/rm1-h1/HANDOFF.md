**C1. `!41#t1`: деньги в целых копейках**
- Формулировка: «Денежные суммы хранить и считать в целых копейках (поле `<имя>Cents`), деление - через `Math.floor`; float для денег не использовать».
- Цитата (olga): «Деньги считаем только в целых копейках: поле `priceCents`, деление через `Math.floor`.»
- Коммит: 05325cb. Он тронул `src/billing/refund.js` через 4 ч 48 мин после замечания: `price` → `priceCents`, `* 0.5` → `Math.floor(/ 2)`.
- Таксон: `internal:signature-convention@2`, соответствие слабое. В схеме нет значения для представления денег. Если вызывающий его не примет, это нехватка норматива, а не повод брать соседнее значение.
- Принуждение: только ревью, инструмента нет. Область: все денежные суммы.
- Живое нарушение в дереве: `src/reports/revenue.js:4-6` считает `(b.priceCents / 100) * 0.85` во float и округляет через `Math.round`. Файл добавлен в !49 без замечаний.
