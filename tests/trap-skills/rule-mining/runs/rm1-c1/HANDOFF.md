**C1 — !41#t1 → коммит 05325cb (2026-09-04 15:00, после треда в 10:12; refund.js, refund.test.js)**
- Формулировка: денежные суммы хранить и считать в целых копейках (поле `<имя>Cents`), делить через `Math.floor`; float для денег не использовать.
- Цитата: «Деньги считаем только в целых копейках: поле `priceCents`, деление через `Math.floor`.»

- Принуждение: ревью-замечание, инструментом не удерживается (eslint его не проверяет).
