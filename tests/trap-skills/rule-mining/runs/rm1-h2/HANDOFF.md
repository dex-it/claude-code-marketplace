## Кандидаты

**C-1. Деньги в целых копейках** (`!41#t1`)
- Формулировка: суммы денег хранить и считать в целых копейках, поле с суффиксом `Cents`. Деление выполнять через `Math.floor`, `float` для денег не использовать.
- Цитата (язык источника): «Деньги считаем только в целых копейках: поле `priceCents`, деление через `Math.floor`.»
- Тред `!41#t1`, коммит `05325cb` (правка `src/billing/refund.js` после замечания).
- Таксон: `internal:signature-convention@2` (суффикс поля). Запасной вариант: `internal:naming@2`.
- Принуждение: ревью; в линтере правила нет.
- Область: код, работающий с денежными величинами.
