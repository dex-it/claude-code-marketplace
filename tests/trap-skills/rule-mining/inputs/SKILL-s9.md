# Добыча правил из истории ревью - чек-лист

Пункт называет ситуацию, которую кандидат и исход треда проверяются на присутствие.

- Норма владельца корпуса из треда на MR со сводом закрыта исходом без правила или замечанием к своду; такая норма - источник правила наравне с тредом истории
- Живые нарушения правила в текущем дереве не квалифицированы
