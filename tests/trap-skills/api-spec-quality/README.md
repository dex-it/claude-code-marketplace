## Правка по ревью

Ревью PR #330 (оси `artifact-review`), правка выводом, без прогона - перемер в «Открыто».

- **Пункты оракула - не сверх норматива.** Все пять стоят в `interface-definition-openapi`: Q6 - §2 «Идемпотентность
  и повтор»; Q9 - §4 п.1-2, §5 `approved`; Q10 - §3 `deprecation`; Q12 - §2 «Примеры», §5 `review`; Q13 - §3
  `traced from`, §6. Фраза «сверх него» снята в оракуле и в нормативе; пункты остаются названиями ситуаций норматива,
  которые судья без них пропускает (контроль RV-Q).
- **Сужение «у новой операции» (`u`) снято.** Единственный судья оракула - `design-reviewer` - судит документ целиком
  («ревью одного документа истории MR не имеет») и грузит норматив вместе с оракулом; норматив требует пример ошибки и
  `traced from` у каждой операции. «Новая операция» есть только в рамке дельты MR кейсов RV-Q/N-Q, у потребителя её
  нет: ложные major N-Q2 - следствие рамки кейса, не дефект нормы.
- **Чистота N-Q3 решена нормативом.** Изменённая операция обслуживает FR-13, §3 требует `traced from` на обслуживаемое
  требование - major контроля «`x-traced-from` не дополнен» верен; N-Q3 не чист, `passed` редакции `u` на нём - пропуск
  дефекта, а не «не хуже контроля».
- Оракул предписывает вызов норматива полной формой (бандлы с оракулом несут норматив); адрес `node-contract` - раздел B
  п.7.
