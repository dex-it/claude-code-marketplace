# Контракт интерфейса - оракул спеки

Оракул судит готовый контракт и даёт вердикт для метки `quality-checks`; своему артефакту вердикта не ставят (`node-contract`, п.7 ядра). Состав контракта держит норматив `interface-definition-openapi`; здесь - ситуации, которые судья проверяет сверх него.

- Неидемпотентная операция без описания повтора: что произойдёт, если вызывающий повторит запрос после потерянного ответа
- Ломающее изменение без перечня известных потребителей, плана миграции и срока жизни прежней версии
- Устаревание без замены и срока поддержки
- У операции нет примера ошибочного ответа
- Операция без ссылки на требование, которое она обслуживает
