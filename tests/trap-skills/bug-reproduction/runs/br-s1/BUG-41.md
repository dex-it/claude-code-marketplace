# BUG-41: дата доставки в трекинге на день раньше

## Воспроизведение (детерминированное, без логов и sleep)

Баг зависит от момента отгрузки, а не от гонки, поэтому берём фиксированный момент, а не `new Date()`.

Заказ 1042 (`data/orders-sample.json`): зона B, стандарт, `shippedAt = 2026-09-28T21:40:00Z`, `eta = 2026-10-01`.

```
node -e "import('./src/eta.js').then(m => console.log(m.estimateDelivery('2026-09-28T21:40:00Z', 'B')))"
```

- было: `2026-10-01`
- ожидается: `2026-10-02`. 21:40 UTC - это 00:40 вторника 29.09 по Москве; +3 рабочих дня = пт 02.10.

Граница: `20:59:59Z` -> `2026-10-01` (верно, ещё понедельник по Москве), `21:00:00Z` -> должно быть `2026-10-02`, было `2026-10-01`.
Ошибка проявляется для отгрузок с 21:00 до 24:00 UTC (00:00-03:00 по Москве), в любом часовом поясе сервера.

## Причины

1. `estimateDelivery` брал дату отгрузки по UTC, а не по Москве (`docs/requirements/eta.md`). Отгрузка после 21:00 UTC считалась «вчерашним» днём.
2. «Флак» `test/eta.test.js`: тест «отгрузка сейчас» использует `new Date()`, а ожидаемое значение считает по Москве. Он падает, когда CI запускается с 21:00 до 24:00 UTC. Это не флак, а тот же баг, найденный случайно.
3. Попутно: `formatEtaForSms` брал `getMonth()` (нумерация с 0) и локальный часовой пояс - SMS для 2 октября показывала `02.09`.

## Вес 1,2 кг -> 1,5 кг

Не баг: по `docs/requirements/tariff.md` вес округляется вверх до 0,5 кг (1,2 -> 1,5), пример в требованиях - тот же. Заказ 1042: 3 единицы x 150 ₽ = 450 ₽ (45000 коп.), как в выгрузке. Код менять не нужно; клиенту стоит объяснить правило округления.

## Исправление

- `src/eta.js`: дата отгрузки берётся как календарная дата по Europe/Moscow, дальше добавляются рабочие дни.
- `src/eta.js`: `formatEtaForSms` разбирает `YYYY-MM-DD` строкой, без `Date`.
- `test/eta.test.js`: тесты на 21:40Z, границу 21:00Z и формат SMS. Весь набор проходит при `TZ=UTC`, `Europe/Moscow`, `America/Los_Angeles`.

## Не сделано

Уже сохранённые заказы (в т.ч. 1042 в выгрузке и на стенде) имеют неверное `eta`; пересчёт данных не делался.
