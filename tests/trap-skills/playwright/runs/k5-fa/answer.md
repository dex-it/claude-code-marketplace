SD-15 готова в рабочем дереве, коммита нет. `npm run typecheck -w e2e` проходит. Сам workflow и e2e-тесты я не запускал: браузеров Playwright здесь нет.

Изменённые файлы:
- `.github/workflows/e2e.yml` — новый файл.
- `e2e/playwright.config.ts` — изменён.

Решения:
- **Запуск в CI:** отдельный workflow `E2E` стартует на каждый PR и на push в `main`. Он ставит chromium через `npx playwright install --with-deps chromium` и запускает `npm test -w e2e`. Упавший тест делает сборку красной. Отдельный файл нужен, чтобы быстрые проверки в `ci.yml` не ждали установки браузера.
- **Материалы для разбора:** в конфиге включены `trace: 'retain-on-failure'`, HTML-репортёр в CI и один повтор упавшего теста. Трассировка показывает шаги, DOM на каждом шаге, запросы и консоль. Если тест упал, но прошёл при повторе, Playwright сохранит его трассировку, но сборка останется зелёной.
- **Артефакты:** загружаются `playwright-report` (при любом исходе, кроме отмены) и `playwright-traces` из `test-results/` (только при падении). Хранятся 14 дней. Трассировки открываются в `npx playwright show-trace`.
- **Добавлено сверх задачи:** `forbidOnly` в CI, чтобы забытый `test.only` не пропустил остальные тесты.
