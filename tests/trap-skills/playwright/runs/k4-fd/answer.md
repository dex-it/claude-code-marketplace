Я написал три e2e-сценария из SD-14, но не запускал их. Браузеры Playwright не установлены, поэтому проверки `npx playwright test` нет. `tsc` и `npm run typecheck` проходят, а `npx playwright test --list` находит все тесты.

Изменённые файлы (оба новые):
- `e2e/tests/orders.spec.ts`: три сценария — вход alice и список заказов, отмена нового заказа, ошибка сервера на списке.
- `e2e/tests/fixtures.ts`: фикстура `aliceSession` и функция `createOrder`.

Решения:
- Через форму входа заходит только первый тест. В остальных токен берётся из `/api/login` и кладётся в `localStorage` через `addInitScript`, как требует практика про вход без формы.
- Тест отмены каждый раз создаёт свежий заказ через `POST /api/orders`. Сервер при `reuseExistingServer` хранит состояние между запусками, так что отмена демо-заказа ломала бы повторный запуск. Я не проверял, что `createOrder` читает из ответа `id` и `number`.
- Ошибку списка подменяет `page.route` на `**/api/orders`, она отдаёт 500. Проверка идёт по `getByRole('alert')`. Локаторы везде по роли и подписи, без CSS.
