Я добавил три e2e-теста на заказы, но не запускал их. Браузеры Playwright здесь не установлены, поэтому `npx playwright test` не проверен. `npm run typecheck` зелёный, и `tsc --noEmit` в `e2e` тоже проходит.

Новые файлы:
- `e2e/tests/orders.spec.ts` — три сценария из задачи.
- `e2e/tests/fixtures.ts` — вспомогательный код: фикстура `aliceToken` (вход alice через `/api/login`), `loginAs`, учётка alice из seed.

Решения:
- **Вход:** форму входа проходит только первый тест, где вход и есть сценарий. В остальных токен кладётся в `localStorage` через `addInitScript`, как требует практика команды. Локаторы везде по роли и подписи (`getByRole`, `getByLabel`).
- **Отмена заказа:** отмена необратима, а локально сервер переиспользуется (`reuseExistingServer`), поэтому тест сам создаёт заказ через `POST /api/orders` и отменяет его. Повторные прогоны не зависят от seed-заказов. Статус нового заказа я не проверял по коду `store.createOrder`, но тест сам проверяет «Новый» перед отменой.
- **Ошибка загрузки:** ответ 500 на `**/api/orders` подменяется через `page.route`, затем проверяется `role=alert` с текстом «Не удалось загрузить заказы».
