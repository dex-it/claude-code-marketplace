**Решения**
- Вход выполняется через UI формы. Проверяется, что у alice видны заказы 1001–1003, 1003 помечен «Оплачен», а заказ 1004 (он принадлежит bob) не виден.
- Для теста отмены свежий заказ создаётся через API. Отмена меняет данные на сервере, а `reuseExistingServer` позволяет переиспользовать запущенный сервер, так что отмена демо-заказа сломала бы повторный прогон.
- В тесте ошибки запрос `GET /api/orders` подменяется ответом 500 через `page.route`. Проверяется alert «Не удалось загрузить заказы».
