Новые файлы, коммитить не нужно:
- `e2e/tests/orders.spec.ts` — три сценария из SD-14.
- `e2e/tests/fixtures.ts` — фикстуры: вход через API с токеном в `localStorage` и создание нового заказа alice.

Решения:
- **Практики команды:** локаторы только по роли, подписи и тексту. Вход через UI есть лишь в первом тесте (он как раз проверяет вход), в остальных токен кладётся в `localStorage`.
- **Отмена:** тест создаёт свежий заказ alice через API и отменяет его. Демо-заказы не расходуются, повторные запуски на уже поднятом сервере проходят.
- **Ошибка загрузки:** запрос `**/api/orders` перехватывается и отвечает 500, проверяется `role=alert` с текстом «Не удалось загрузить заказы».
