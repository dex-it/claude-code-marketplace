Я добавил три e2e-сценария, но в браузере их не запускал, потому что браузеры Playwright не установлены. `npm run typecheck` зелёный, `playwright test --list` видит все тесты. Критерий «`npx playwright test` проходит локально» поэтому не проверен.

Изменённые файлы (оба новых):
- `e2e/tests/fixtures.ts` — фикстура `alicePage`.
- `e2e/tests/orders.spec.ts` — три сценария из задачи.

Решения:
- **Вход и локаторы:** по практикам команды вход через форму сделан только в тесте входа. В остальных тестах фикстура логинится через `POST /api/login` и кладёт токен в `localStorage`. Локаторы только по роли, подписи и тексту, без CSS и id.
- **Ошибка загрузки:** тест перехватывает `**/api/orders` и отдаёт 500 через `page.route`.
- **Отмена заказа:** тест отменяет заказ #1001 и меняет данные в памяти api. Сервер переиспользуется (`reuseExistingServer`), поэтому при повторном запуске api надо перезапустить, иначе тест упадёт. Эндпоинта создания заказа нет, так что сбросить состояние по-другому нельзя.
