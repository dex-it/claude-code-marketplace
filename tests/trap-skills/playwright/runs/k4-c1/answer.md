Я добавил три теста, но запустить их в браузере не удалось. В этой среде не установлены браузеры Playwright, поэтому `npx playwright test` падает на запуске Chromium. Падает и существующий смоук-тест, так что причина в среде, а не в тестах. Прогон `npx playwright test` из критериев приёмки не выполнен. Проверен только `npm run typecheck`, он зелёный.

**Изменённые файлы:**
- `e2e/tests/orders.spec.ts` (новый)

**Решения:**
- **Отмена заказа:** сервер хранит состояние между запусками, а отмена необратима. Поэтому тест сам создаёт заказ через API под alice и отменяет его в интерфейсе. Демо-заказы не меняются, тест можно запускать повторно.
- **Список заказов:** тест проверяет, что у alice видны заказы #1001–#1003 и нет заказа #1004, принадлежащего bob. Точное число заказов не проверяется, потому что отмена-тест добавляет новые.
- **Ошибка загрузки:** запрос `**/api/orders` перехватывается и отвечает 500 до входа. После входа тест проверяет, что виден alert «Не удалось загрузить заказы».

После `npx playwright install chromium` стоит прогнать `npx playwright test` в `e2e`.
