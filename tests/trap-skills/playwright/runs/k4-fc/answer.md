Критерий «`npx playwright test` проходит локально» остаётся непроверенным, его нужно прогнать на машине с браузерами.

Изменённые файлы (оба новых):
- `e2e/tests/orders.spec.ts` — три сценария из задачи.
- `e2e/tests/helpers.ts` — вход по API с токеном в `localStorage` и создание свежего заказа.

Решения:
- **Вход и локаторы:** форму входа проходит только первый тест. В остальных токен кладётся в `localStorage` через API, как велит практика команды. Локаторы везде по роли, подписи и тексту.
- **Отмена заказа:** тест сначала создаёт новый заказ alice через API и отменяет его. Так он не портит демо-заказы и проходит повторно на уже запущенном сервере.
- **Ошибка загрузки:** запрос `**/api/orders` подменяется ответом 500, после чего проверяется alert «Не удалось загрузить заказы».
