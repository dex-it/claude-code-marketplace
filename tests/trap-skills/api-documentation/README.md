команды, документ - `swagger.json` Swashbuckle 6.6.2) и N0 (правка правила длительности - вне предмета). Выбор пакета
документа: Swashbuckle 6.6.2 - скилл написан под Swashbuckle, оба пакета (и `Microsoft.AspNetCore.OpenApi` 10.0.10) в
кэше. Bash исполнителя - `git`, `dotnet`; сборка исполнялась в прогонах G-D (по журналам `dotnet build`, в `g-d-u2`
приложение запускалось фоном для проверки старта и остановлено по лимиту времени), `dotnet test` в G-D не звался; в
`n0-u2` исполнитель завёл тестовый проект и прогнал тест границы. CLI 2.1.296, `skills`/`mcp_servers` пусты, каталог
прогона вне репозитория, `CLAUDE.md` на пути нет. Прогоны 2026-10-11. Наборы: `c` - контроль; `n` (редакция
[`SKILL-n1.md`](inputs/SKILL-n1.md)), `f`, `t`, `u` - с итоговой 1.2.0 (`f` - рядом итоговая оракула, `t`, `u` - итоговые
трёх).

## Шаг 0

Коды: A1 «Schema drift», A2 «Нет `[ProducesResponseType]`», A3 «GenerateDocumentationFile не включен», A4 «`<example>`
отсутствует на request моделях», A5 «Сгенерированный клиент не в CI», A6 «Enum как int в OpenAPI», A7 «Nullable не
отражён в spec», A8 «Один Swagger doc на все версии», A9 «Deprecated endpoints без пометки»; чек-лист.

- **A1** - решение «порождать spec из кода» конфликтует с нормативом этапа `interface-definition-openapi` §1 (контракт
  порождается вместе с решением, рядом с кодом): снята без прогона.
- **A6** - дубль D18 `dotnet-api-development` (группа 2.2, PR #327: enum в схеме, контроль 0/2, 0/2, пункт возвращён
  там) - дом там, здесь снята; в G-D - клетка-наблюдение (enum уже строками, смена сериализации - ложь).
- **A3** ~ D16 #327 (G-A 2/2): мерится в G-D своей ситуацией, исход сводится с #327.
- **A5, A8** - `unverifiable`: генераторов клиента (NSwag, Kiota) и `Asp.Versioning` в локальном кэше нет, мини-проект
  одной версии, CI в раннере нет. Остаются названиями. **ib-layer** (`integration-boundary`, «Открыто» с адресом #303:
  сгенерированный клиент против актуальной схемы) - это A5: закрыт здесь как `unverifiable` с той же причиной.
