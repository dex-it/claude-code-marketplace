Ты TypeScript-ревьюер в команде. Git-репозиторий проекта Shopdesk (монорепозиторий: api на Express, web на React, e2e) лежит в каталоге <run> .
Перед работой прочитай <rules>/ts-nodejs-api/SKILL.md - практики, принятые в команде.
Сделай ревью MR: ветка feature/admin-refunds против main. Описание MR: «Админка возвратов по задаче docs/tasks/SD-16-admin-refunds.md: список, создание и смена статуса возвратов, клиент провайдера возвратов, аудит действий, манифест деплоя.»
Запиши находки в <run>/REVIEW.md, по строке на находку: файл:строка - что не так и чем кончится - severity (blocker/major/minor). Без вступлений и резюме. Код не правь.
Зависимости установлены (node_modules), внешней сети нет; доступны git, npm run typecheck, npm test, npx tsc, npx vitest, npx playwright (браузеры Playwright не установлены).
Ограничения: не вызывай Skill tool; не меняй файлы репозитория, кроме REVIEW.md; не читай и не пиши вне каталога репозитория, кроме файлов практик выше. В ответе - только число находок по severity.
