`POST /api/orders/:id/pay` готов. `npm run typecheck` и `npm test` проходят (api: 14 тестов, web: 2). Playwright не запускал, браузеров нет.

- `README.md` — описание новых переменных.

**Решения**
- **Переменные окружения.** Обе проверяются при старте, как велит SKILL.md: без них сервис не запустится. Поэтому в запуск api в e2e добавлены тестовые значения.
- **Сбои шлюза.** Сетевой сбой, таймаут, `409` и `5xx` повторяются до 3 раз с тем же `order_id`, шлюз при этом повторно не спишет. Если подтверждения нет, отвечаем `502 payment_unavailable`, и заказ остаётся в статусе `new`.
- **Побочные действия и параллельные запросы.** Ошибки письма и аналитики после успешного списания только логируются, ответ остаётся `200`. Параллельный запрос на оплату того же заказа получает `409`, потому что внутри процесса заказ помечается как «оплачивается».
- **Тесты.** Кроме четырёх обязательных сценариев, проверены `502`, сбой письма и аналитики и параллельная оплата.
