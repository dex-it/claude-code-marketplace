## Пересмотр по существу (стек на #370)

Ключ K-HYG судил H2 по букве: `W` в `select`. По существу дефект - правило, спорящее с форматтером, которое действует; на ruff 0.17.1 W191 действует против форматтера только при `[tool.ruff.format] indent-style = "tab"`. Правило засчёта записано коммитом до пересчёта (`_projects/shelfwatch/README.md`, «Пересмотр по существу: H2, C9, C10»); `c1`, `c2` однозначны, но критерий писан по ним, поэтому по ревью #379 контроль добран до n=4 (`k-hyg-c3`, `k-hyg-c4`, слепые к критерию: выходы сняты после записи правила).

| Код | Кейс | По ключу | По существу | Основание |
|---|---|---|---|---|
| H2 | K-HYG | 1/4 (`c4` без `W`) | 4/4 | `c1`, `c2`, `c3`: `select = ["E", "F", "W", "I", "B", "UP"]`; `c4`: `["E", "F", "I", "UP"]`; `indent-style` не задан, D/Q/COM/ISC нет ни в одном (выходы `c3`, `c4` сняты 21.10.2026 раннером `run-group-4-5.sh`, `claude-sonnet-5-5` effort medium, $0.07 + $0.07). Проверка на ruff 0.17.1 (20.10.2026, конфигурации `c3` и `c4` - 21.10.2026): `ruff check` и `ruff format --check` на этой конфигурации молчат; с добавленным `indent-style = "tab"` `ruff format` выдаёт предупреждение о несовместимости с W191 |
| H2 | RV-HYG | 2/2 | 2/2 | ключ RV содержит `indent-style = "tab"`, находка поднята обоими контролями |

**Исход.** До ревью #379 H2 была снята на `c1`, `c2` по критерию, записанному по ним же; ревью принято (HIGH): пункт H2 возвращён в `SKILL.md` (1.1.0) отдельным коммитом до прогонов, контроль добран `k-hyg-c3`, `k-hyg-c4` (слепые к критерию). Счёт по строке правила: 4/4 по существу в K-HYG, RV-HYG 2/2 по ключу - H2 снята, пункт убран из `SKILL.md` (1.1.0 -> 1.2.0, 4 пункта), из `description` и `plugin.json` убраны `ruff` и «линтер»; в `description` остаётся 12 триггеров (пол валидатора - 10). Кейс активации `python-hygiene-in` переписан: прежний запрос про линтер спрашивал о снятом предмете. Каталог разошёлся генератором. Ограничение: слепых к критерию прогонов два из четырёх, на n=4 с одним выбором конфигурации результат устойчив к `W`, но выборка мала; решение 2 эпика (число прогонов) не принято. Альтернатива (отклонить стек): H2 остаётся пунктом-названием 1.1.0, вердикт по ключу.
