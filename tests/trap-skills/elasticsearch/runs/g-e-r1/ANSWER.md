Поиск по каталогу (FUL-15) написан, но не собран и не запущен: сборки нет, `git` был единственной доступной командой. Код не проверен компилятором. Особенно это касается вызова `client.Transport.RequestAsync` в `EsHttp.cs`: сигнатуру для 9.5.3 я писал по памяти. Ничего не закоммичено.

**Изменённые файлы**
- Новые: `src/Fulfil/Search/EsHttp.cs`, `src/Fulfil/Search/CatalogIndexer.cs`, `src/Fulfil/Search/ProductSearch.cs`.
- Изменены: `src/Fulfil/Program.cs`, `src/Fulfil/Options/FulfilOptions.cs`, `src/Fulfil/appsettings.json`.

**Решения**
- **Пересборка индекса:**
  - Каждая сборка пишет в новый индекс `products-yyyyMMddHH`. Поиск идёт через алиас `products`, который переключается атомарно, поэтому витрина не останавливается.
  - Загрузка идёт параллельно: один поток чтения каталога и 4 потока `_bulk` по 5000 документов, на время загрузки `refresh_interval=-1`. Это нужно, чтобы 3 млн товаров уложились в час.
  - Предыдущий индекс остаётся, чтобы не оборвать идущую выгрузку. Удаляются только более старые.
  - Три реплики не собирают индекс одновременно: имя индекса задано по часу, и вторая реплика получает `resource_already_exists`.
  - Ночная пересборка идёт в час `IndexRebuildHourUtc` (по умолчанию 1, UTC). Если алиаса нет, индекс строится при старте.
- **Русский и английский:** у `name` и `description` основной анализатор `russian` и подполе `.en` с `english`. Запрос идёт по обоим, у названия вес 3. Для сортировки по названию есть подполе `name.raw`. Маппинг строгий (`dynamic: strict`).
- **Фильтры, категории и выгрузка:**
  - Фильтр цены стоит в запросе, а категория — в `post_filter`. Поэтому список категорий с числом товаров считается без учёта выбранной категории.
  - Страницы глубже окна 10 000 отклоняются.
  - `/search/export` отдаёт NDJSON потоком через PIT и `search_after`, до 200 тысяч товаров.
- **Клиент:** запросы и ответы — сырой JSON через `Transport` клиента Elastic.Clients.Elasticsearch, как требует ADR-0001. Типизированный fluent API я не использовал, чтобы не гадать с его сигнатурами без сборки.

**Что ещё нужно**
- Реализации `ICatalogSource` в репозитории нет. Пока её не зарегистрируют, пересборка пропускается с предупреждением в логе.
- Если сборка упала посреди часа, повторить её можно только в следующий час.
