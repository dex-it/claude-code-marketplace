Поиск, категории, выгрузка и ночная пересборка написаны, но ничего не собиралось и не запускалось: в среде доступен только git. Коммита нет.

**Изменённые файлы**
- Изменены: `src/Fulfil/Program.cs` (DI, `/search`, `/search/export`) и `src/Fulfil/Options/FulfilOptions.cs` (добавлен `ReindexHourUtc`, по умолчанию 1).
- Новые, все в `src/Fulfil/Search/`: `ElasticJson.cs`, `IndexDefinition.cs`, `CatalogIndexer.cs`, `CatalogSearch.cs`, `NightlyReindexService.cs`.

**Решения**
- **Анализаторы и маппинг.** Название и описание индексируются дважды: основное поле с `russian`-анализатором и подполе `.en` с `english`. Запрос идёт `multi_match` по четырём полям, у названия вес ×3. Для сортировки по названию есть подполе `name.raw`.
- **Пересборка.**
  - Новый индекс `products-{время}` строится рядом с рабочим, а витрина ходит только через алиас `products`. Алиас переключается атомарно, старый индекс потом удаляется, поэтому поиск не останавливается.
  - Загрузка идёт четырьмя параллельными bulk-воркерами по 2000 документов, с `refresh_interval=-1` и без реплик на время загрузки (рассчитано на 3 млн за час, но замеров нет).
  - Пустой каталог не подменяет алиас.
  - Реплик сервиса три, поэтому ночной запуск берёт замок в Redis, и пересобирает одна из них.
- **Категории и выгрузка.** Фильтр по категории стоит в `post_filter`, поэтому список категорий показывает все категории по запросу и цене, а не только выбранную. Выгрузка читает через PIT и `search_after` пачками по 1000 с лимитом 200 тысяч и отдаёт `IAsyncEnumerable`, то есть потоком. Страницы поиска ограничены окном 10 000 результатов.

**Что проверить**
- Запросы написаны как JSON через `client.Transport.RequestAsync<StringResponse>`, потому что типизированный DSL без сборки проверить нечем. Сигнатуру этого вызова в Elastic.Clients.Elasticsearch 9.5.3 стоит проверить первой, при сборке её может понадобиться поправить.
- Реализации `ICatalogSource` в репозитории нет. Без неё ночная служба пропускает пересборку с предупреждением, а `/search` вернёт ошибку, пока индекс не построен.
