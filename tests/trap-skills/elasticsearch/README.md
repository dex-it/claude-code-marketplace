## Шаг 0

Дублей с другими скиллами нет. Факт клиента: код скилла - NEST (`BulkAliasAsync`, `IndexMany`, `.Map<T>()`), в
Elastic.Clients.Elasticsearch 9.5.3 (ADR-0001: NEST снят с поддержки) этих имён нет; в сжатом скилле имён API нет.
Факты версии, сверенные с документацией Elasticsearch (19.10.2026, elastic.co): `index.max_result_window` по умолчанию
10000, дальше - `search_after` с PIT; `fielddata` у text по умолчанию `false`, сортировка и агрегация по text не
поддерживаются (ошибка, а не «мусор», как в формулировке E5 версии 1.1.1). Кейсы: G-E (код, `docs/tasks/FUL-15.md`:
3 млн товаров, русские и английские тексты, фасеты, выгрузка 200 тысяч, пересборка без простоя), RV-E (ревью
`catalog-search`: E1-E11, приманки P1 `StatsAggregation` по числу и P2 `From`/`Size` на первых страницах, вне скилла O1
пустой `q`, O2 смещение страницы).
