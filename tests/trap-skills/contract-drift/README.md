## Шаг 0: тип, дом, дубли

9 H3-ловушек и чек-лист из 6 пунктов. Процедур нет.

- **Контракт.** Дом - этот скилл: `integration-boundary` «Двусторонний контракт проверен только со стороны
  потребителя» и контрактная часть «Слоя сборки и контракта» наследуют вердикт CD-V.
- **Пересечение с #303** (группа 4.2: `api-specification`, `api-spec-quality`, `api-testing`,
  `api-documentation`, не начата): скиллы #303 не трогаются; «Контракт нигде не зафиксирован» и фиксация
  контракта схемой - предмет и `api-specification`, решение - в «Открыто» с адресом #303.

## Единицы и кейсы

| Код | Ловушка 1.1.0 | Кейс (ключ parcel) |
|---|---|---|
| cd-field | Поле или формат сменили на одной стороне | CD-F |
| cd-status | Статус-код изменился | CD-S |
| cd-null | Nullability или обязательность поля изменили | CD-N |
| cd-semantic | Семантический дрейф без изменения формы | CD-U |
| cd-two-paths | Один исход собирается двумя путями в разные значения на проводе | CD-P |
| cd-format | Формат даты, времени или числа разъехался | приманка P-date (дрейф без последствия); K-кейса нет |
| cd-version | Версии API разъехались | CD-V |
| cd-enum | Расширение enum или набора значений | CD-E |
| cd-schema | Контракт нигде не зафиксирован | поручением «найти расхождения» не судится |
| чек-лист | 6 пунктов | повтор названий |
