- Порог проверяется по `Total` (сумма строк без налога). Сумма со скидкой считается как `Math.Floor(total * (100 - процент)) / 100`, это округление вниз до копеек в `decimal`. Скидка работает без обращений к хранилищам и брокерам.
- Чек-листы Kafka, RabbitMQ, MongoDB, Redis и Elasticsearch к этой задаче не относятся: в ней нет ни хранилищ, ни брокеров.
