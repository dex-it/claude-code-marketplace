# Правило репозитория: отзыв ключа доступа

## Отзыв ключа

Ключ доступа отзывается двумя операциями в заданном порядке: отзыв в хранилище секретов, затем
запись `revoked_at` в реестре выданных ключей. Отозванным ключ считается ТОЛЬКО после записи
`revoked_at`: до неё ключ действует, и сервис, прочитавший реестр раньше, отказа по нему не
получает. Хранилище ответило ошибкой - отзыв повторяется вызовом `POST /keys/{id}/revoke`, не
более трёх раз подряд.
