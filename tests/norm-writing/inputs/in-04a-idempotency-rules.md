# Правила репозитория: обработка сообщений очереди

## Повторная доставка

Обработчик принимает сообщение повторно ТОЛЬКО при совпадении заголовка `Idempotency-Key` с
записью журнала обработки: запись есть -> сообщение отбрасывается с отметкой в журнале; записи
нет -> сообщение обрабатывается как новое. Журнал хранит ключи 72 часа.

## Идемпотентность обработчика

Обработчик идемпотентен: повторная доставка того же сообщения состояния не меняет. Повтором
считается сообщение с тем же `Idempotency-Key`, пришедшее в пределах 72 часов; запись старше
этого предела считается отсутствующей, и сообщение идёт как новое.

## Очередь разбора

Сообщение, отклонённое обработчиком с ошибкой валидации, уходит в `dlq.orders` и оттуда повторно
не доставляется: судьбу сообщения решает владелец очереди.
