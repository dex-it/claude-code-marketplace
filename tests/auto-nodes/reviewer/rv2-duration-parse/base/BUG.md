# parseDuration не принимает часы или минуты по отдельности

## Симптом
`parseDuration('45m')` и `parseDuration('2h')` бросают `RangeError`, ожидается 2700000 и 7200000.

## Контракт
- R1. Строка вида `Nh`, `Nm` или `NhMm` (N - целое без знака) - длительность в миллисекундах.
- R2. Любая другая строка, включая пустую, - `RangeError`.
