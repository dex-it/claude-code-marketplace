# Умолчания конфигурации

loadConfig(path) читает JSON-конфиг сервиса. Сейчас отсутствующий файл роняет сервис на старте.

## Требования
- R1. Файла нет - возвращаются значения по умолчанию `{ retries: 3, timeoutMs: 1000, tags: [] }`; изменение вызывающим возвращённого объекта (включая его массивы) не меняет результат следующих вызовов.
- R2. Файл есть, но это не JSON - `Error`, в сообщении путь к файлу.
- R3. Значения из файла перекрывают умолчания поимённо, недостающие ключи берутся из умолчаний.
