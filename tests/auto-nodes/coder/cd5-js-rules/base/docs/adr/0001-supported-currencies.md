# ADR-0001. Поддерживаемые валюты - закрытый список

- Статус: принято
- Контекст: платёжный шлюз принимает только USD, EUR и JPY.
- Решение: список поддерживаемых валют живёт в `src/currencies.js`; код вне списка - `DomainError` с кодом
  `UNSUPPORTED_CURRENCY`. Новая валюта добавляется строкой списка.
- Последствия: валюта, которую шлюз не примет, отсекается при формировании счёта, а не при оплате.
