# ledger

Учёт оплат счетов. Суммы хранятся в копейках (целые числа), в выписке банка и в отчётах - в рублях с запятой.

## Оплата

Счёт оплачен, когда сумма его платежей равна сумме счёта: остаток 0, статус `paid`. Недоплата - `partial`,
переплата - `overpaid`.

## Сверка с банком

Сумма платежей в отчёте совпадает с суммой по выписке банка до копейки: `summary(ledger).paid`.
