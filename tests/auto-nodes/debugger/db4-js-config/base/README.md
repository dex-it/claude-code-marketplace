# services

Реестр сервисов и плагинов. У каждого сервиса и плагина свой конфиг: умолчания (`DEFAULTS`) плюс переопределения (`load`).

## Теги

Тег, добавленный сервису или плагину, виден только ему: другим сервисам, плагинам и умолчаниям (`defaultsLine`)
он не передаётся. Строка отчёта: `describe(unit)` - «имя: теги через запятую».
